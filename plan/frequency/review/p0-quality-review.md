# P0 无泄漏过渡质量审查

- 审查日期：2026-08-23
- 审查类型：第二轮，方法质量、结果真实性与后续可用性
- 结论：**通过，可以进入 F2 频域 MVP 正确性阶段。**

## 总体评价

P0 成功把第一创新点的锁定 Top-5 ST 架构迁移到更严格的数据协议，并在不查看测试指标的情况下恢复了稳定验证收益。它证明后续频域实验有一个可用且可审计的上游对照，但不能被写作频域贡献。

## 独立复算

- 168→6 三个配对 RMSE 改善：0.8031%、1.6292%、1.4350%，平均1.2891%；
- 24→1 三个配对 RMSE 改善：5.6207%、4.4870%、4.9612%，平均5.0230%；
- 两任务 CSV 配对值与独立公式复算一致；
- 每个预测 NPZ 的物理尺度 RMSE 与 `raw_metrics.csv` 一致；
- 同种子锁定 ST 的 `disable_spatial` RMSE 与退化基线逐值一致；
- 训练期筛选均为18站，包含新协议下的1021，不包含旧全序列筛选的1005/1008；
- 两任务的 train/valid/test 目标 timestamp 交集均为0；
- 六个锁定 ST 运行的主干初始化/最终 hash 均一致。

## 偏倚与可重复性检查

- 选择结果只来自验证集，不能作为最终测试结论；
- 2052–2054 既用于早停也用于结构过渡判断，符合 selection 标签，但不提供确认性显著性；
- 两任务 q90 分别为187和185，差异来自各任务训练目标起点不同，不应强制相同；
- 运行时工作树尚未提交，但配置同时保存 Git commit、dirty 标志和四个模型源码的联合 SHA256，可定位本次代码；进入 F2 正式选择前应继续保留源码指纹。

## 剩余风险

- 北京1013验证集仍是内部选择数据，不能支持泛化；
- 尚未实现频域严格退化、分带重构和等容量时域控制；
- F1 的改善只证明 ST 过渡成立，不能预判 F3 会通过。
