# P1 固定频带规范审查

- 审查日期：2026-08-23
- 审查类型：第一轮，P1任务包和F2/F3协议一致性
- 结论：**实现合规；Gate F2通过，Gate F3失败。**

| 检查项 | 证据 | 结果 |
|---|---|---|
| 预测端残差 | 冻结ST预测加 `beta*tanh(adapter)` | 通过 |
| 固定三频带 | 48 h、12 h边界，平滑mask，DC归低频 | 通过 |
| 分割统一与重构 | mask逐频点和为1，奇偶窗口重构误差在单测容差内 | 通过 |
| 等容量时域控制 | 相同编码器、池化、输出头和训练预算 | 通过 |
| 参数匹配 | 时域与频域均3015个可训练参数，差异0% | 通过 |
| 公平初始化 | 每个同种子加载同一P0锁定ST，适配器随机种子重置 | 通过 |
| 严格退化 | 初始输出及训练后禁用残差均逐元素恢复ST | 通过 |
| 冻结不变 | 六个适配器运行的基础ST完整state hash不变 | 通过 |
| 选择边界 | 仅2052–2054验证集，未计算测试指标 | 通过 |
| F3对ST门 | 3/3改善，但平均0.3502%低于0.5% | 失败 |
