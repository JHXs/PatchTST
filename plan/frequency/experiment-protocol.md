# 因果多尺度频域分支实验协议

> 协议版本：FREQ-PROTOCOL-v1（2026-08-23）。本文锁定探索边界；任何变更都必须在查看对应阶段测试结果前写入 `decision-log.md`。

## 1. 证据标签

| 标签 | 用途 | 是否可用于论文最终结论 |
|---|---|---|
| `smoke` | 形状、梯度、输出和管道冒烟 | 否 |
| `selection` | 只使用验证集选择下一阶段结构 | 只能报告选择过程 |
| `internal_confirmation` | 结构锁定后的北京 1013 内部确认 | 可，但必须限定当前站点/城市 |
| `external_generalization` | 新中心站或广州数据 | 可用于扩展泛化边界 |

输出目录名必须包含证据标签。带 `_smoke` 后缀的任何文件不得进入论文表格或统计检验。

## 2. 数据和输入契约

- 主数据：`tsai/data/stations_data/` 北京逐小时站点 CSV。
- 主中心站：1013。
- 候选站：1001–1035，排除不可读或时间索引不合法的文件；候选集的任何数据驱动筛选只使用训练时间段。
- 第一阶段输入：所有入选站 PM2.5，`x_station_pm25: [B,S,L]`。
- 目标：中心站 PM2.5，`y: [B,1,H]`。
- 气象阶段的辅助特征：中心站温度、气压、湿度、风速、风向正弦和余弦；`weather` 类别编码不进入首版门控。
- 原始站点 CSV 只读，不生成或覆盖 `tsai/data/X.npz`、`y.npz` 等通用流程资产。

## 3. 时间划分和无泄漏处理

以对齐后原始时间行数 \(T\) 定义：

\[
b_{train}=\lfloor0.7T\rfloor,
\qquad
b_{valid}=\lfloor0.8T\rfloor.
\]

对目标起点 \(t\)，输入为 `[t-L,t)`，目标为 `[t,t+H)`。样本归属规则：

- train：`L <= t` 且 `t + H <= b_train`；
- valid：`b_train <= t` 且 `t + H <= b_valid`；
- test：`b_valid <= t` 且 `t + H <= T`。

该规则允许验证/测试预测使用边界之前已观测的历史，但保证 train/valid/test 的目标时间点两两不相交。

预处理顺序：

1. 读取并按时间去重、对齐；
2. 在每个站内使用因果 `ffill`；
3. 如序列开头仍缺失，优先丢弃所有所需特征未齐备前的时间行；任何备选填充都必须仅使用训练期统计并单独记录；
4. 仅在 `[0,b_train)` 计算中心站与候选站 Pearson 相关性；
5. 使用预先锁定的相关阈值 0.85 生成候选站集，并在 valid/test 冻结；
6. 标准化均值和标准差只使用 `[0,b_train)`；
7. 峰值 q90 只使用 train 目标；
8. 在 Dataset/Model 前向中对每个历史窗口单独变换，不对完整序列预分解。

协议验证必须将各划分的目标 timestamp 写入元数据或其哈希，并自动断言三组交集为空。

## 4. 任务与主次关系

| 任务 | 角色 | 解释边界 |
|---|---|---|
| 168→6 | 唯一主频域任务 | 可支撑多日、日内与快速波动尺度 |
| 24→1 | 辅助短窗口任务 | 不支撑多日频率结论，主要报告稳健性/非劣性 |
| 168→1 | 可选机理消融 | 区分长历史和多步目标的影响；不在 P1 强制运行 |

不在首轮同时扫描 72/336 历史和 12/24 小时预测。任务扩展只能在主结构锁定后作稳健性实验。

## 5. 模型变体与阶段

| 阶段 | 变体 | 主对照 |
|---|---|---|
| P0 | `degraded_patchtst_clean` | 旧协议退化结果（只作描述） |
| P0 | `locked_st_clean` | `degraded_patchtst_clean` |
| P1 | `st_time_residual_adapter` | `locked_st_clean` |
| P1 | `st_fixed_frequency_residual` | `locked_st_clean` 和 `st_time_residual_adapter` |
| P2 | `st_learnable_frequency_residual` | `st_fixed_frequency_residual` |
| P3a | `st_self_gated_frequency_residual` | P2 胜出的全局门控版本 |
| P3b | `st_meteorology_residual_control` | `locked_st_clean` |
| P3b | `st_meteorology_gated_frequency_residual` | P3a 与气象普通残差 |
| P4 | `st_peak_aware_frequency_residual` | 同结构的普通 MSE 训练 |
| P5 | `st_rolling_vmd_residual` | 固定/可学习 rFFT 胜出版本 |

阶段未通过时，其后续变体不运行。变体 ID 不得重用 ST 历史 ID，不得将频域结果写入 ST 统计汇总。

## 6. 初始化、冻结和公平性

P1–P5 的每个同种子运行遵循：

1. 训练同种子 `degraded_patchtst_clean` 并保存验证损失最优检查点；
2. 用该检查点初始化 `locked_st_clean`，冻结 PatchTST，训练空间分支；
3. 保存同种子 `locked_st_clean` 最优检查点；
4. 所有时域/频域适配器加载完全相同的该 ST 检查点；
5. 冻结 PatchTST 和空间分支，只训练当前适配器以及对应 \(\beta\)；
6. 时域容量控制与频域分支使用相同隐层宽度、时间池化、输出层、dropout、\(\beta_{max}\) 和训练预算；
7. 两者可训练参数差异目标不超过 5%；超过时必须记录并补做参数匹配对照。

共享设置：AdamW、MSE 主损失、相同 batch size、epoch 上限、patience、梯度裁剪、最佳验证损失规则和评估代码。频域特定正则只能加在对应变体上，并单独记录。

## 7. 预定义频域起点

- 变换：`torch.fft.rfft` / `irfft`，float32，沿历史维度。
- 频带数：3，不在 P1 扫描。
- 固定周期边界：12 h 和 48 h，使用平滑过渡。
- 可学习频带：从固定频带初始化，带顺序受约束，逐频率权重和为 1。
- 残差：`beta_max=0.5`，频域最终输出层零初始化。
- 频带融合：P1 使用预定义等权或受限全局权重；实现前在任务包锁定其中一种，不两者都看测试结果。

如出现明显窗口环绕/振铃伪影，只允许在训练/验证上比较“平滑频带”和“历史内反射 padding＋裁剪”两种预定义边界处理；选定后冻结。

## 8. 随机种子与选择边界

- 冒烟：任意单种子，不进入汇总。
- 验证选择种子：2052、2053、2054。
- 最终内部确认种子：2055、2056、2057、2058、2059。
- 外部泛化：在新站点/城市上使用同一锁定结构；默认沿用 2055–2059 以节省计算，但不用外部结果再调整结构。

种子只控制训练初始化和 DataLoader 顺序，数据划分始终相同。如任何预定义种子因技术错误重跑，必须保留原失败日志并用同一种子重跑，不更换为有利种子。

## 9. 指标

### 9.1 主指标

- 反标准化后 PM2.5 RMSE（μg/m³）。
- 配对相对变化分母始终为同种子主对照 RMSE。

### 9.2 必报次指标

- MAE（μg/m³）；
- SMAPE（接近零值时的限制必须报告）；
- 168→6 的逐预测步 RMSE/MAE；
- 最佳 epoch、训练时间、推理时间、总参数和可训练参数；
- 频域残差 RMS / ST 预测 RMS；
- \(\beta\)、频带权重、频带重叠率、动态门控样本标准差。

### 9.3 高污染指标

- train q90 阈值以上 RMSE/MAE；
- 超阈值 precision/recall/F1；
- 峰值幅度偏差；
- 非高污染样本 RMSE/MAE；
- 各预测步的高污染指标。

## 10. 统计与聚合

- 每个变体报告逐种子原始值、mean ± sample std。
- 主比较使用同数据、同种子、同 ST 检查点的配对差值。
- 最终五种子方向检验使用单侧精确符号检验；5/5 改善时 \(p=0.03125\)。
- 五种子检验只表示训练随机性方向一致，不表示时间样本或城市独立重复。
- 对逐预测起点误差做配对移动块 Bootstrap；块长只根据训练期误差/目标自相关预先选择并写入确认配置。
- 探索多变体不做事后显著性挑选；只对预注册主比较给出确认性 p 值，其余报告效应量和置信区间并标为探索。

## 11. 阶段选择和实际收益门

P1 固定频带在 2052–2054 验证种子上必须：

1. 168→6 相对 `locked_st_clean` 3/3 RMSE 改善；
2. 平均配对 RMSE 降幅≥0.5%；
3. 平均 RMSE 严格优于 `st_time_residual_adapter`；
4. 所有预测、残差、权重和梯度为有限值。

P2/P3 新组件必须在相同三种子上超过前一阶段胜出者，且对应机理诊断不退化，才能取代前者。如改善小于日志精度或只有1/3种子改善，保留更简单结构。

最终内部确认的主门：

- 168→6 的 2055–2059 五个种子全部优于同种子 `locked_st_clean`；
- 单侧精确符号检验 \(p=0.03125\)；
- 平均配对 RMSE 降幅≥0.5%；
- 输出完整性、独立指标复算、频域禁用干预和冻结参数检查通过。

24→1 不替代 168→6 主门。其改善可作扩展证据；其中性或小幅退化必须完整报告，并将创新点表述限定为长历史主任务。

## 12. 效率协议

- 记录数据/分解预处理时间、每 epoch 训练时间、最佳 epoch 总训练时间和测试推理时间。
- GPU 推理前同步并预热；使用固定 batch size 重复至少 5 次，报告中位数。
- 报告总参数、可训练参数、峰值显存（如可获取）和频域诊断/缓存磁盘占用。
- VMD 必须将在线逐窗口分解耗时与缓存后耗时分开报告，不能隐去预计算成本。

## 13. 诊断和真实性干预

每个频域变体必须支持：

- `disable_frequency`：同一已训练模型中严格禁用频域残差；
- `fixed_uniform_gates`：用固定等权替换样本门控；
- `permute_gate_context`：全局打乱样本级门控上下文，但保留频带分解；
- `band_only_low/mid/high`：仅启用一个频带作诊断，不作训练选择；
- `zero_frequency_residual`：确认结果恢复锁定 ST。

保存：逐样本门控权重、逐频率掩码、逐样本频域残差、不同频带的 RMS/能量比、预测与目标。

## 14. 输出契约

所有产物写入：

```text
experiments/results/causal_frequency_ablation/<stage>/<history>h_<horizon>h/
```

每个目录最少包含：

- `experiment_config.json`：完整参数、种子、代码提交和证据标签；
- `dataset_metadata.json`：时间边界、站点集、标准化、q90、目标时间交集检查和数据协议版本；
- `raw_metrics.csv`：逐变体逐种子原始指标；
- `summary_metrics.csv`：mean ± std；
- `paired_differences.csv`：同种子主对照配对差；
- `per_horizon_metrics.csv`：逐预测步指标；
- `peak_metrics.csv`：峰值和非峰值指标；
- `frequency_diagnostics/`：频带响应、门控、残差和能量诊断；
- `training_logs/`、`predictions/`、`checkpoints/`；
- `stage_status.json`：阶段门通过/失败与原因；
- `auto_report.md`：自动摘要并显式标出 smoke/selection/confirmation。

检查点受 `.gitignore` 管理，CSV/JSON/小型诊断产物应受版本控制。

## 15. 外部泛化

在查看内部确认结果前，必须在配置中锁定一个外部目标：

- 另一个北京中心站，或
- 广州中心站及其训练期候选邻站。

外部数据重新拟合标准化器、训练期站点筛选和模型权重，但不重新选择频带数、初始周期边界、门控类型或损失。外部结果只验证锁定方法的可转移性，不再反向调整方法。

## 16. 允许的结论层级

| 证据状态 | 允许表述 |
|---|---|
| P1 失败 | 固定频率分解未提供超过等容量时域适配的证据 |
| P1 通过 | 预定义频带在当前验证设置中提供频率特异的增量信息 |
| P2 通过且频带不退化 | 受约束频带学习优于预定义频带 |
| P3 通过 | 样本状态/气象条件化提供额外收益，但不做因果解释 |
| P4 通过 | 峰值感知目标减少当前阈值定义下的峰值过度平滑 |
| 内部确认通过 | 在北京 1013 的锁定任务上跨五种子稳定改善 RMSE |
| 外部泛化通过 | 在预指定新站点/城市中观察到同方向改善，并严格限定已验证范围 |
