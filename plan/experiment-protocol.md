# Alpha 搜索实验协议

## 数据与划分

- 北京多站点空气质量数据，中心站 1013，共 17 个站点、每站 12 个变量。
- 输入窗口 168 小时，预测窗口 24 小时。
- 样本量 8569；训练、验证、测试按时间划分，验证集 852，测试集 1705。
- alpha 仅由验证集选择；测试集不参与参数搜索。

## 模型与搜索变量

- 中心站走 PatchTST 主干。
- 邻站分支使用空间差分、Cross-Attention 和时域卷积预测残差。
- 六个 alpha 分别对应 PM2.5、PM10、NO2、CO、O3、SO2。
- 气象变量不融合邻站残差。

## 评价与停止规则

- 主目标：所有 12 个输出的验证集总体 MSE。
- 辅助指标：六种污染物的验证集 MSE、RMSE、MAE。
- 固定权重后的 alpha 用闭式最小二乘求解，并裁剪到 `[0, 0.4]`。
- 连续迭代的 valid MSE 进入平台区后停止；使用额外 seed 检查稳定性。
- 对训练 alpha 为 0、导致输出通道无梯度的情况必须补做非零 warm-start 消融。

## 公平性边界

- 三轮主搜索固定 seed 20260809，除 alpha 外训练配置不变。
- seed 20260810 用于复核核心训练向量。
- O3 补充消融在第一次查看 test 后追加；其结果只能作为探索性验证，正式论文需新留出集复核。

## 补强实验协议（预注册于运行前）

- 随机种子：`20260809`、`20260810`、`20260811`。
- 训练预算：每个条件最多 30 epoch，早停 patience=15；batch size=16；固定学习率 `1e-4`。单 epoch 烟雾实验约需 16 秒，故本轮采用 30 epoch 完成 12 次配对训练；该消融用于策略间比较，不与先前 50 epoch 搜索结果直接合并计算均值。
- 硬件：统一使用 `cuda:0` 映射的 AMD Radeon RX 7600；第二块集成显卡因 ROCm 内核不兼容未用于正式实验。
- 共同初值：逐污染物与可学习条件均从 `[0.3124, 0.0139, 0.0357, 0.0054, 0.02, 0.0490]` 开始。
- alpha 范围：`[0, 0.4]`。
- 四个条件：
  1. `alpha_zero`：六个 alpha 固定为 0，不进行事后校准；
  2. `uniform_alpha`：六个 alpha 以 0.02 训练，训练后仅校准一个共享标量；
  3. `per_pollutant_alpha`：使用推荐向量训练，训练后逐污染物闭式校准；
  4. `learnable_alpha`：alpha 通过 sigmoid 参数化并与模型共同训练，主结果使用最佳验证权重对应的学习值，不追加闭式校准。
- 主指标：12 个输出的 valid MSE；辅助指标：valid RMSE、MAE、六种污染物 MSE。
- 汇总规则：每个条件报告 3 个种子的均值、样本标准差和 95% t 置信区间；`n=3` 时统计推断能力有限，显著性只作探索性描述。
- 效率记录：单次训练墙钟时间、总参数量、可训练参数量和实际完成 epoch。
- 测试集禁用：本轮所有训练、排序、统计和结论均不读取测试集。

## 严格 PatchTST 基线协议（2026-08-10，运行前锁定）

- 目的：确认 ST-PatchTST 相对原生单站点 PatchTST 的真实验证集提升，而不再只依赖 ST 框架内的 `alpha=0` 退化基线。
- 数据：从现有北京多站点 `X` 按 `model_params.npz` 的 `center_station_idx` 抽取中心站 1013，得到 `[样本, 12, 168]`；标签 `y`、训练/验证/测试索引和已有标准化资产保持不变。
- 隔离约束：不运行当前硬编码广州 9022 且会覆盖 `tsai/data/X.npz` 的 `data_preparation_single.py`；不改写任何现有数据资产。
- 模型：tsai 原生 `PatchTST`，骨干参数与 ST-PatchTST 中心分支一致：3 层、4 头、`d_model=16`、`d_ff=128`、patch length 4、stride 2、dropout 0.2。
- 随机种子：`20260809`、`20260810`、`20260811`。
- 训练预算：30 epoch、batch size 16、固定学习率 `1e-4`、梯度裁剪 1.0、最低 valid-loss checkpoint、早停 patience=15。
- 指标：valid MSE、RMSE、MAE、六种污染物 MSE、训练时间、参数量。
- 主比较：严格 PatchTST 与同协议 `uniform_alpha`、`per_pollutant_alpha`、`learnable_alpha` 的同 seed 配对差值；同时检查严格 PatchTST 与 `alpha_zero` 是否处于相同误差区间。
- 统计：3-seed 均值、样本标准差、95% t 区间及配对差值；`n=3` 只作探索性判断。
- 证据边界：本轮基线训练和模型选择不索引测试集；用于决定是否继续改进的主结论先基于验证集。
