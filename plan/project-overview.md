# 项目概览
## 基本信息

- 论文类型：中文硕士毕业论文
- 学科领域：新一代电子信息技术
- 暂定题目：《基于时空特征融合与 PatchTST 的多站点空气质量预测研究》
- 当前任务：整理逐污染物 alpha 搜索的独立实验记录，不撰写整篇论文
- 输出格式：Markdown、PNG、SVG

## 研究目的

针对单站点 PatchTST 难以利用邻近监测站空间关联的问题，引入空间差分、
跨站注意力和逐污染物邻站残差权重，研究邻站信息对中心站未来 24 小时
空气质量预测的影响。

## 当前技术路线

多站点相关性筛选 → 时间对齐与标准化 → 中心站 PatchTST 主干 → 邻站空间
差分与 Cross-Attention 残差分支 → 逐污染物 alpha 搜索与验证集闭式校准 →
基线、消融和随机种子复核。
