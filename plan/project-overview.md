# 项目概览

## 研究目标

在北京多站点 PM2.5 数据上改进 ST-PatchTST，并与由同一模型关闭空间残差后得到的退化 PatchTST 进行公平、可复现的对照实验。

## 本轮边界

- 按用户要求，本轮不处理站点相关性筛选使用完整序列所带来的前视信息问题。
- 首轮只预测中心站 PM2.5，其他变量不进入输入或目标。
- 退化基线与改进模型共享数据、PatchTST 主干、初始化顺序、训练器和超参数。
- 实验结论仅适用于当前数据、划分和任务，不能替代后续多城市或多预测尺度验证。

## 主要产物

- 可切换中心站单边门控与成对门控的 `ST_PatchTST`。
- 多随机种子实验运行器。
- 逐轮训练日志、逐样本预测、逐种子指标、汇总指标和空间诊断。
- 面向中文硕士论文写作的实验报告。
