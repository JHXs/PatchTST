# MC-CVLRA L1 项目概览

日期：2026-08-24。阶段：L1“实现与消融”，起点提交 `c3da238`。

本阶段只在北京 1013 的官方 train+validation 选择区间实现并验证冻结的 MC-CVLRA 协议。正式选择种子固定为 `2060,2061,2062`，但本次任务禁止启动正式三种子运行；只允许单种子、极少 epoch/样本、目录名带 `_smoke` 的流程冒烟。

不可变边界来自 `docs/第二创新点理论探索/03_最终推荐方案.md`、`04_阶段门决策记录.md`、`05_数据语义审计与代理签字.md` 和 L0 权威产物。正式 test 只允许读取时间戳以建立 70/10/20 边界，不得读取或构造 test 特征、目标值、窗口、预测、缓存或指标。原始 CSV 只读。

## 固定交付

- 无泄漏 L1 数据模块与 P=7 历史 token；
- 冻结基础模型后的 M、B1、B2、B-flat、B3；
- F00/F01/F10/F11 2×2 与完整 L1 对照运行器；
- 独立逐预测复算、M-shuffle 和硬门汇总器；
- checkpoint/hash/fit ledger、验证预测、门控与组质量诊断；
- F00→F10 PatchTST逐阶段参数/buffer审计、Git/源码hash追溯与正式clean-tree门；
- 单元测试、两个CPU `_smoke`、168→6真实GPU batch512资源`_gpu_smoke`和中文实现审计报告。

允许的结论仅是“具体工程验收项通过”或具体失败/阻断项；smoke 数值永不用于选型、论文性能或 L1 阶段门。当前P1与CPU链通过，但GPU资源验收因无设备BLOCKED，尚不允许正式启动。
