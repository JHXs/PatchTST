## 3. 关键实现

### 3.1 数据访问与无泄漏管线

- b1 中心站与 b0 邻站来源均为显式元组；正式中心站的授权集合严格等于“中心站＋b1 其余 7 站＋b0 全部 8 站”。
- 每个 `pd.read_csv` 紧前执行授权和禁用集合检查；读完后要求累计打开集合精确等于当次 16 站授权集合，并与 9022、9027、b2、b3 的并集无交集。
- 不扫描广州数据目录，不连续展开站号，不先读后滤。`--dry-run` 只落盘计划与空的实际打开集合，不读取 CSV。
- 各站先按时间升序、按时间戳去重，再取 16 站共同时间轴。
- 先按 `floor(0.7n)`、`floor(0.8n)` 划分 C-fit/C-val/C-confirm，再在每个子段内部单独调用只含 `ffill()` 的辅助函数。不存在反向填充路径；子段起点仍缺失的窗口被丢弃。
- Pearson 在 C-fit 前向填充后 16 站共同有限时间戳上计算；零方差或非有限候选无资格，按“系数降序、站号升序”取 Top-5，不足 5 个时在站点 STOP 目录记录原因且不训练。
- 中心站＋Top-5 一次生成两臂共享的索引、C-fit 缩放统计、目标时间戳和块标签。窗口历史与全部 H 个目标均在同一子段，历史严格早于目标。
- C-confirm 的全部时间戳等长切 5 块，余数从最早块起分配。每个预测标量按自己的目标时间戳入块，所以 H=6 的同一窗口可跨块。

### 3.2 固定模型与训练配置

两臂固定为 `degraded_patchtst` 与 `st_sparse_station_bias_delta_forecast`。ST 臂固定 `k=5`、预测端差值残差、站点身份偏置；同种子退化基线先训练，ST 随后从该运行的 best-valid checkpoint 初始化并冻结 `patch_tst` 主干。两臂均使用 AdamW、MSE、梯度裁剪 1.0、ReduceLROnPlateau，best checkpoint 只由 C-val loss 选择。

正式配置冻结如下：

| 参数 | 24→1 | 168→6 |
|---|---:|---:|
| batch size | 256 | 512 |
| epoch 上限 | 40 | 30 |
| early-stop patience | 8 | 6 |
| learning rate | 1e-3 | 1e-3 |
| weight decay | 1e-4 | 1e-4 |
| neighbor hidden dim | 32 | 32 |
| forecast alpha max/init | 0.5 / 0.1 | 0.5 / 0.1 |
| spatial pool bins | 4 | 4 |
| PatchTST layers/heads/d_model/d_ff | 3 / 4 / 16 / 128 | 3 / 4 / 16 / 128 |
| dropout | 0.2 | 0.2 |
| patch_len / stride | 4 / 2 | 4 / 2 |

正式种子只能是 7001–7005。`--formal` 不提供删站、改任务、改种子或改超参数的命令行入口，始终执行预注册完整矩阵。

### 3.3 产物与独立汇总

每臂/站点/任务/种子的 NPZ 保存物理尺度逐标量预测、真实值、目标时间戳、lead、块标签，以及五块 SSE 和元素数。运行元数据保存配置指纹、代码 commit、随机种子、实际打开集合、共享索引/缩放/块标签、Top-5 与 C-fit 相关系数；manifest 保存每臂实际训练轮数、初始化和冻结标志。

汇总器不读取运行器指标，而从逐标量预测重建 RMSE、MAE、SMAPE 和 SSE。保存 SSE、元素数、目标、时间戳、lead、块标签或两臂支持任一不一致均拒绝汇总。正式汇总还验证固定任务、站点、种子、超参数、访问集合、Top-5、同种子初始化及冻结标志。

输出包括 `gate_summary.json`、`run_metrics.csv`、`paired_effects.csv`、`station_metrics.csv`、`block_metrics.csv`、`lead_metrics.csv`、`peak_metrics.csv` 和 `quantile_smape_decomposition.csv`。配对 RMSE 由五块 SSE 与元素数合并后的全部标量计算，不平均块 RMSE；G1–G4 及双任务合取按协议固定规则判定。符号检验尾概率明确标记为描述性。

- 修复 R3 期间，实现代理曾改动稳定 `main` 上的 `run_st_patchtst_ablation.py`（把 `.ffill().bfill()` 改为 `.ffill().dropna()`），以通过"全仓库无反向填充"测试。该改动**违反工作单**（明令不得改动既有文件），且超出本轮授权，已由主代理回退，该文件与 `main` 完全一致。
