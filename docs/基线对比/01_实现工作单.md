## 3. 基线臂清单（臂 = 模型 × 通道 × 容量档）

**神经臂**（每个臂跑两档容量：`default` = 库默认；`matched` = ≈21,233 参数 ±20%）

| 臂 id | 层 | 信息集（通道） | 模型 |
|---|---|---|---|
| `center_mlp` / `center_gru` / `center_lstm` / `center_tcn` / `center_resnet` | B | 1（仅中心站） | tsai 对应模型 |
| `center_tst` | B | 1 | tsai TST（**风险臂**：需显式 `.to(device)`；无法稳定运行则记录并剔除，不得静默跳过） |
| `plain_mix_patchtst_all` | C1 | S（全部站点，与 ST 臂同集合） | **无门控跨站融合** `Conv1d(S→32, k=1) → GELU → Conv1d(32→1, k=1)` → 冻超参 `PatchTST(c_in=1, seq_len=L)`；**无门控/无差值/无站点偏置/无 Top-k**；必须过 T10 |
| `plain_mix_patchtst_top5` | C1b | 6（中心 + 训练段相关性最高 5 个邻站） | 同 C1，仅站点集合收窄 |
| `concat_patchtst_all` | C1-flat | S（拼成单通道 `[B,1,S*L]`） | 同 C1 的冻超参 PatchTST，但 `seq_len=S*L`；**部分覆盖臂**：batch=256 下实测 L≤48 可行、**L=72/168 显存溢出（实测）**，溢出配置登记为不可行，不得静默跳过 |
| `patchtst_ci_all` | C1-CI | 名义 S，**实际仅中心站** | v1.1 原设计（tsai PatchTST 通道独立）；**只作语义登记**，T10 反向断言变化 ==0；**不构成同信息集对手** |
| `patchtst_ci_top5` | C1-CI-top5 | 名义 6，**实际仅中心站** | v1.1 原 Top-5 设计改名后的语义登记臂；T10 反向断言变化 ==0；**不构成同信息集对手** |
| `multi_tst` | C2 | S | tsai TST（多通道） |
| `multi_gru` | C2 | S | tsai GRU（多通道） |

**传统臂**（A 层，确定性，无种子；全部只用训练段拟合）

| 臂 id | 定义 |
|---|---|
| `trad_persistence` | `y_hat[h] = x[center, L-1]`（全部预测步同值） |
| `trad_daily_naive` | `y_hat[h] = x[center, L-24+h-1]`（昨日同一小时；要求 `L≥24`，所有配置均满足） |
| `trad_climatology` | 训练段中心站**按小时（0–23）均值**，按目标时刻小时取值 |
| `trad_ar` | 中心站自身 PM2.5 滞后 `p=min(L,24)` 项 → 每预测步一个线性回归（训练段拟合） |
| `trad_ridge` | 中心站窗口展平（L 维）→ H 输出，`sklearn.linear_model.Ridge` 多输出，`alpha` 仅在验证集选（网格 `{0.1,1,10,100}`） |
| `trad_spatial_linear` | **全部 S 个站点窗口展平**（S×L 维）→ H 输出，同样的 Ridge 与 alpha 网格；线性空间上限参照 |

**预注册的广州臂集合**（成本控制，避免 8 站 × 20 配置膨胀）：`plain_mix_patchtst_all`、`plain_mix_patchtst_top5`、
`multi_gru`、`center_gru`、`trad_persistence`、`trad_daily_naive`、`trad_climatology`、`trad_spatial_linear`。

## 4. 训练规则（必须与 legacy 逐条一致）

### 4.1 复刻要求
`baseline_training.train_baseline(config, model, datasets, metadata, seed, device, variant)` 必须复刻
`run_st_patchtst_ablation.train_one_run` 的以下顺序与语义（**逐条对齐，不得"顺手改进"**）：

1. `legacy.set_seed(seed)` → 构造/搬运模型 `.to(device)`
2. `AdamW(lr=config.learning_rate, weight_decay=config.weight_decay)`
3. `ReduceLROnPlateau(mode="min", factor=0.5, patience=3)`
4. 损失 `nn.MSELoss()`；每步 `optimizer.zero_grad(set_to_none=True)` → forward → loss → 有限性检查
   （非有限即抛 `FloatingPointError`）→ `loss.backward()` → `clip_grad_norm_(model.parameters(), 1.0)` → `optimizer.step()`
5. 每轮后：在 **valid** 上评估（`legacy.predict(model, valid_loader, device, center_idx)`），
   `valid_loss = mean((pred - true)^2)`，`scheduler.step(valid_loss)`
6. 早停：`valid_loss < best_loss - 1e-7` 时保存 checkpoint（`torch.save(model.state_dict())`）并重置计数；
   否则计数 +1；计数 ≥ `config.patience` 时 break
7. 训练结束后 **加载 checkpoint**，在 `config.evaluation_split`（固定 `test`）上评估一次
8. 指标：`legacy.regression_metrics(...)`；同时记录 `best_epoch`、`best_valid_loss`、`training_seconds`、
   `parameter_count`、`trainable_parameter_count`
9. 落盘：`training_logs/<arm>_seed<seed>.csv`、`predictions/<arm>_seed<seed>.npz`
   （**键名与 legacy 一致**：`prediction_scaled`、`target_scaled`、`prediction_ugm3`、`target_ugm3`）
10. **不做**空间诊断与邻站干预（`collect_spatial_diagnostics` / `disable|zero|shuffle|center_copy`）——
    这些是 ST 专有量，基线模型没有该接口；此差异必须在 `02_实现与验收记录.md` 写明

### 4.2 C 层主干超参（必须与 ST 臂一致）
`tsai.models.PatchTST.PatchTST(c_in=<通道数>, c_out=1, seq_len=L, pred_dim=H, n_layers=3, n_heads=4,
d_model=16, d_ff=128, dropout=0.2, patch_len=4, stride=2, padding_patch=True)`
→ 与 `run_st_patchtst_ablation.build_model` 传给 `ST_PatchTST` 的值一致（`d_model=16`、`n_layers=3`、`patch_len=4`、`stride=2`）。

### 4.3 输出形状适配
- 我们的模型输出 `[B, 1, H]`；tsai 模型在 `c_out` 维度返回 `[B, c_out]`（部分模型 `[B, H]`）。
- 包装类必须统一返回 `[B, 1, H]`：`out.dim()==2 → out.unsqueeze(1)`，并对 `c_out=1, pred_dim=H` 的情形做
  `reshape`/`transpose` 的显式处理；**每种模型都要在测试中断言形状**（T2）。

### 4.4 容量档
- `default`：库默认超参，登记实际参数量。
- `matched`：调整隐藏维度使参数量落在 `21,233 ± 20%`；若某模型在最小可用配置下仍远超上限，
  记录该事实并把最接近的一档标注为 `matched_nearest`（不得伪造）。
- 每档都必须跑 **B 层与 C 层全部神经臂**，但 `matched` 档只在**头条 2 配置（24→1、168→6）× 5 种子**跑（协议 §5 成本约定）。

## 5. 传统基线的防泄漏约束

1. 任何拟合（AR/Ridge/线性空间回归/climatology 统计）**只允许使用训练段样本**；
2. 目标时刻的特征只能来自**输入窗口内**的观测（严禁 `bfill`、严禁未来标签、严禁全序列统计量）；
3. `Ridge` 的 `alpha` 只在 **valid** 上选；选完后不再回看 test；
4. 传统基线不做早停/训练，但必须在 `02_实现与验收记录.md` 写明其"调参预算"（网格大小）；
5. 气候均值必须用**训练段**的小时均值（不得用全序列）。

## 7. 测试清单（`test_baselines.py`）

| # | 测试 | 通过判据 |
|---|---|---|
| **T1** | **位级复现门**：同一 seed/config，用 `legacy.train_one_run('degraded_patchtst')` 与用新训练循环跑同一模型 | `test rmse_ugm3` 相对差 ≤ 1e-12（或逐位相等） |
| T2 | 全臂形状：随机 batch 前向 | 每个神经臂输出 `[B, 1, H]`；传统臂输出 `[N, 1, H]` |
| T3 | 防泄漏：climatology / Ridge / AR 只用训练段 | 构造训练段与测试段分布不同的小样本，断言拟合所用的行索引 ⊂ 训练段（或与手算值一致） |
| T4 | 信息集：C1 通道数 == `len(metadata["station_ids"])`；C1b == `min(6, S)` 且含中心通道；B 层 == 1 | 断言通过 |
| T5 | 容量登记：每臂参数量 > 0；`matched` 档落在 21,233 ± 20% | 断言通过（`matched_nearest` 例外须显式标注） |
| T6 | 确定性：同 seed 跑两次 | 预测逐位相等 |
| T7 | 评估划分守卫 | `evaluation_split == "test"`，否则抛错 |
| T8 | 传统基线正确性：合成斜坡上 `persistence`/`daily_naive` 与手算一致 | 数值相等 |
| T9 | 汇总器独立复算：由 `predictions/*.npz` 重算 RMSE 与运行器记录的差值 | 相对差 ≤ 1e-9 |
| **T10** | **信息流门（v1.2）**：随机 batch 上把邻站通道 `+5.0`，比较中心站预测 | 应看到邻站的臂（`plain_mix_patchtst_all`、`plain_mix_patchtst_top5`、`concat_patchtst_all`、`multi_gru`、`multi_tst`）变化 **>1e-8**；`patchtst_ci_all` / `patchtst_ci_top5` 变化 **==0**（反向断言） |

### 7.1 v1.2 实测事实（实现必须依据，已独立验证）

| 事实 | 数值 |
|---|---|
| `tsai.models.PatchTST.PatchTST(c_in=18)` 扰动邻站 → 中心预测变化 | **0.0**（通道独立，邻站进不来） |
| 同上但拼成单通道 `seq_len=S*L` | 4.55（有明显信息流） |
| `GRU/LSTM/TCN/ResNet/MLP/InceptionTime(c_in=18)` | 0.62 / 0.26 / 0.019 / 0.68 / 0.048 / 0.79（均 >0） |
| 本方已训练 ST 臂（24→1, seed 2047）扰动邻站 → 中心预测变化 | **0.247**，α=0.126（未训练时恒为 0 是零初始化设计） |
| 单通道拼接的显存上限（batch=256、8GB） | L=24 ≈945 ms/步；L=48 ≈785 ms/步 / 4.8 GB；**L=72、L=168 溢出** |
