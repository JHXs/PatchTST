# 第 10 轮主代理阶段决定

日期：2026-09-10。结论：**理论 NO-GO；不创建实验分支，不运行纯合成 L0。**

## 1. PCRS

独立挑战文档提出持久因果隐状态后验（PCRS），用两状态 HMM 的完整历史前向后验替换窗口最旧值。它确实扩展了有限窗口以外的因果信息集，H=1 不退化；但算法身份仍是“持久低/高污染隐状态 + HMM 状态记忆槽”，与本轮 `00` 明令不复活的污染事件/状态拼装路线同类。换成概率后验不改变该边界。主代理不放行 PCRS。

## 2. PLAC

建设文档提出预顺序逐预测步局部仿射校准（PLAC）。主代理和独立 reviewer 核验后确认：成熟目标的 score-before-update 在线信息集在真实滚动部署中可以合法，但当前方案不能作为第二创新放行。

具体阻断：

1. 当前 `tsai.models.PatchTST.PatchTST` 默认 `revin=True, affine=False, subtract_last=False`，而 `ST_PatchTST_model.py` 未覆盖这些参数；所以文档的 BASE 已是 RevIN-PatchTST，`Strongest existing=RevIN-PatchTST` 与 BASE 重复。
2. `A0=gamma I,q0=gamma[1,0]` 后又求解 `(A+gamma I)^{-1}q`，无数据时得到 `[0.5,0]` 而非声明的身份 `[1,0]`。成熟数不足时虽然由外层回退遮蔽，公式本身仍不闭合。
3. PLAC 的核心就是对 `[base_prediction,1]` 做逐 lead 指数遗忘递归最小二乘。最强同信息集对照必须包括 expanding affine、rolling affine 和同成熟顺序的标准 EW-RLS；其中最后一项与 PLAC 本体相同。Bias-only 只能证明增益项有用，不能证明存在区别于标准 RLS 的新机制。
4. 固定 `lambda=0.98` 且主 DGP 漂移状态 `rho=0.97`，即使产生主效应，也主要验证匹配遗忘时间常数的现成在线校准，而不是新的估计步骤。
5. 测试期消费成熟标签改变了当前批量静态评估协议。未来若把在线校准作为强基线，必须固定 chronological runner，并做空间 off/on × feedback off/on 完整 2×2；不能拿静态 BASE 单独对比后声称与第一创新可叠加。

已有近邻并非自动 NO-GO；本次 NO-GO 的原因是**候选与其最强同信息集现成算法完全同构，无法定义可归因的新机制增量**。PLAC 可作为未来在线部署基线，不作为论文第二创新。
