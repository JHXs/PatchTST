# Round 11 主代理签署：仅放行独立非正式 fixture

日期：2026-09-10。本文是对 `03_修订与L0冻结协议.md` 的执行边界补充；不改其单序列 DGP、CF-CV-CS 机制或 5% 双任务门。与 03 冲突时以本文为准。

## 1. 模型接口

合成 PatchTST 输入固定为单通道历史目标：

```text
X: [batch, 1, history]
y: [batch, 1, horizon]
```

不得把 `Y/sin/cos` 三通道送进 tsai channel-independent PatchTST 后只取一个输出，也不得为此外加通道融合层。03 中“三类通道”和 `input_channels: 3` 作废，替换为 `input_channels: 1`。条件向量 `C` 保持 03 第 4.1 节的历史统计与 lead 定义，不新增 target encoding；DGP 的日内均值变化只能由历史窗口间接学习，不能借此复活第 9 轮日历先验。

## 2. OOF 与真实训练预算

每个 `(seed, task)` 固定训练：

- raw-MSE full：1 次；
- log1p `m` 的 5 个 forward blocked OOF 模型：5 次；
- log1p full：1 次。

因此 fixture 为 `3 seeds × 2 tasks × 7 = 42` 次 PatchTST 拟合；正式 L0 若未来获准，为 `50 × 2 × 7 = 700` 次。03 的 12/200 次估计作废。raw base 不做 OOF，因为它不参与 smearing nuisance；所有 log 回变换臂共享同一组 log OOF/full 预测。

训练期先切一个只作初始拟合的 warm-up block，再切 5 个按时间前进的 OOF query blocks；每个 query 模型只使用满足 `target_timestamp <= query_min - purge` 的前缀。没有合法前缀的记录排除并计数，禁止用未来块补齐。实际 wall time、峰值显存/内存、训练 epoch 和排除比例须由 fixture 实测，未经实测不得授权正式 L0。

## 3. 选择边界

外层 project valid/test 不用于选择 `m`、`b`、`lambda`、`S`、checkpoint 或 smoother。raw/log 的每次 PatchTST 拟合均只在其合法训练前缀内部按相同时间比例划分 train-inner-fit/train-inner-valid，以 train-inner-valid 上各自训练尺度的 MSE 早停；两者共享 epoch 上限、patience、优化器和 seed 规则。log full checkpoint 不按某个重变换臂的 raw valid 指标选择。

conditional smoother/带宽也只在 train-inner blocked validation 上选择一次，并在外层 valid/test 前冻结。外层 valid 仅作为 fixture 文件契约中的保留区，不产生候选选择决定；fixture 性能不能用于改结构或门。

## 4. 时间戳权重

本协议逐 lead 估计。固定 lead `h` 时映射 `origin -> target_timestamp=origin+h` 一一对应，所以 `d_{s,h}=1`。03 的逆重复次数权重在实现中简化为每个有效记录权重 1，再在该 lead 内归一化；禁止跨 lead 合并样本或因同一时间戳出现在不同 lead 而重复加权。仍须保留跨 task/lead 的唯一标签逐点断言。

## 5. 控制变量归因恒等式

对每个 task、lead、OOF query block，必须使用完全相同的 `m,C,fold,purge,weight,H,raw boundary,evaluation rows` 构造 removal 与候选，并逐点断言：

\[
\widehat S_{cv}-\widehat S_{rem}
=-\widehat\lambda_h H(I-B)r.
\]

数值断言容差固定为 float64 的 `rtol=1e-10, atol=1e-12`。还必须保存 `H(I-B)r` 路径、`rho/kappa`、`Cov(u,v)`、伪结果方差和 paired raw RMSE。若恒等式失败、两臂除控制变量项外不相同，或 03 的近零诊断触发，则工程/归因 STOP；不能查看后再换 smoother。
