# CF-CV-CS 独立复审

## 结论：REVISE

**A 方差。** 已知 b(c)=E[r|C=c] 时，v=r−b(C) 条件均值为零；只有同权重 Cov(e^r,v)≠0 且 λ近最优才降方差。b由样本估计会再引入偏差/方差，无必然保证。若 b、S 共用 smoother H：

Ŝcv=H[e^r−λ(r−Hr)]=He^r−λ(H−H²)r。

H²=H 时严格抵消，H²≈H 时增量很小。交叉拟合令中心矩阵 B≠H，只能留下 H(I−B)r，说明可能不抵消而非保证增益；须 nested blocked OOF，并报告协方差、伪结果方差和 b 误差。仍共用 H，应降级为普通 smearing 变体。

**B 覆盖。** 这是已有的 regression-adjusted control variate[3]；最强对照是共享 OOF、C、权重、H 的 conditional smearing[1,2]。近邻不自动 NO-GO，但精确同构须降级；仅相对 removal arm 有非零可复现增量才可保留候选名。交叉拟合也不等于正交 score[4]。

**C DGP。** 代码按单序列切窗（run_st_patchtst_ablation.py:89–96）。现稿按 (t,h) 生成 Z_{t+h}，同一绝对时刻会有冲突标签。只生成 Z_s=μ_s+σ_sε_s、Y_s=exp(Z_s)−1，μ_s、σ_s只按 s 定义，再以同一 Y_{t+h} 构造 H=1/6；不得改成独立表格。

**D 截断。** 有界对称 ε 且 Z≥0 时，log1p 恒等式仍成立；但不是 lognormal，exp(σ²/2) 不成立。先截断 Y 时，须用 Z*=log1p(Y) 重算残差；同方差臂用经验 global smearing。

**E 归因。** 相对 raw-MSE 的5%混合了 log 训练、重变换、平滑和控制变量，可能主要来自 log 变换，不能据此归因。只有候选与 removal 共享 m、C、H、折、权重、边界、λ估计时，差异才归因控制变量。

**阻断修复：**重写 A；修正单序列 DGP、截断/对照命名；验证时间戳唯一；候选只有在相对 removal 的方差及 raw 增量均被独立配对证实后才放行，否则 STOP。
