# Round 11 算子维度更正

日期：2026-09-10。该更正由主代理在代码交接前发现；不改变 DGP、控制变量、对照或 5% 门。与 03/05 中的 `H²`、`kappa` 或方阵假设冲突时，以本文为准。

## 问题

合法的 blocked OOF smoother 将一个 fit 集的响应映射到另一个 query/evaluation 集，通常有

\[
H_E\in\mathbb R^{|E|\times n},
\]

其中 `n` 是统一的训练 OOF 记录数，`E` 可以是 OOF query、valid 或 test。它一般不是方阵，所以 `H_E²` 和 `H_E-H_E²` 没有定义。03 第 5 节把同样本方阵 smoother 的投影直觉直接用于 blocked fit/query，是维度错误；不得在实现中伪造方阵或把 query 行回填进 fit 集。

## 统一算子定义

对某一 task/lead，把全部合法训练 OOF residual 按时间排序成

\[
r\in\mathbb R^n,\qquad u=\exp(r)\in\mathbb R^n.
\]

定义因果 blocked 中心化算子 `B∈R^{n×n}`：第 `i` 行只可在满足该行 purge 的更早训练记录上有非零权重；没有合法前缀的行标记 excluded，不进入后续 fit。于是

\[
\widehat b=Br,\qquad v=(I-B)r.
\]

对任一评价集合 `E`，定义共享的 conditional-smearing 算子

\[
H_E\in\mathbb R^{|E|\times n},
\]

其每行只在该评价时允许的训练 fit 记录上有非零权重。外层 test 的 `H_test` 可使用全部冻结训练记录；训练 OOF query 的行只能使用满足 forward purge 的早期记录。removal 与候选分别为

\[
\widehat S_{rem,E}=H_Eu,
\]

\[
\widehat S_{cv,E}=H_E(u-\widehat\lambda v).
\]

因此唯一合法的逐点归因恒等式是

\[
\widehat S_{cv,E}-\widehat S_{rem,E}
=-\widehat\lambda H_E(I-B)r
=-\widehat\lambda H_Ev.
\]

该式维度为 `|E|`，对 OOF query/valid/test 均成立。实现可以用线性算子函数而不显式物化矩阵，但必须能对同一向量重复应用并通过 `rtol=1e-10, atol=1e-12` 的 float64 断言。

## 近零诊断

03/05 中所有 `kappa=||H-H²||/||H||` 要求删除，因为 blocked 矩形算子上无定义。保留并更正路径诊断：

\[
\rho_{E,h}
=\frac{\lVert H_Ev\rVert_2}
       {\lVert H_Eu\rVert_2+10^{-12}}.
\]

同时报告 `Var(v)`、`Cov(u,v)`、`Var(u-lambda v)/Var(u)`、`||S_cv-S_rem||` 和 paired raw RMSE。若任一任务多数 lead 的 `rho<=0.05`，则控制变量经过最终 smoother 后路径近零，归因 STOP；这里 H=1 的“多数”为该 1 个 lead，H=6 的“多数”固定为至少 4/6 lead。不得再尝试用 `H²≈H` 解释原因。即使 `rho>0.05`，仍必须通过候选相对 removal 的双任务 5% 门，不能仅凭非零路径放行。所有算子使用固定的训练记录列顺序；excluded 记录不进入 `r/u/v` 列空间，也不能被 query 行回填为 fit 样本。
