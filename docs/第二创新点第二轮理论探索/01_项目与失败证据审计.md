## 2. 当前第一创新点及可组合接口

### 2.1 当前结构

当前 ST-PatchTST 的外部输入为 `[B, S*F, L]`，内部重排为 `[B,S,F,L]`。中心站进入 PatchTST 主路径；邻站通过共享投影、中心—邻站差值、成对门控、Top-k 稀疏选择与站点身份偏置形成空间上下文。推荐结构在预测端加入有界残差：

```text
base_prediction = PatchTST(center_x)
spatial_correction = bounded_head(top5_neighbor_context, station_bias)
prediction = base_prediction + spatial_correction
```

预测端修正输出层零初始化；空间强度为零或 `forward_components(x, disable_spatial=True)` 时严格退化到中心站 PatchTST。`forward_components` 同时暴露基础预测、空间修正和门控诊断。[INT]

### 2.2 第一创新点已支持的结论

在北京 1013、PM2.5、24→1 和 168→6 上，固定的“Top-5 门控 + 站点身份偏置”结构从退化基线初始化并冻结 PatchTST 主干，在种子 2047–2051 上 RMSE 与 MAE 均为 5/5 改善；平均配对 RMSE 降幅分别为 3.1188% 和 0.8220%。2047–2051 仅是未参与此前优化的**新优化种子**；北京 1013 的同一 test 时间片此前已在多轮项目实验中被观察，因而这不是数据独立确认。24→1 的 SMAPE 上升，因此不能声称所有指标改善；没有城市更换或新中心站的数据独立证据，也不能声称跨城市泛化。[INT]

### 2.3 第二创新点的最小接口约束

第二创新点不得重做空间选站、邻站门控或站点先验。允许的最小接口只有：

```text
locked Top-5 ST input -> locked ST prediction [B, 1, H]
                              |
                              +-> second mechanism -> calibrated prediction [B, 1, H]
```

主候选只读取冻结模型在预测发生时保存的点预测，以及之后按真实时间顺序成熟的历史误差。它不读取新辅助变量、不改变邻站权重、不反向更新 PatchTST 或空间分支。[DEC]

## 3. 当前数据与运行器的泄漏审计

`run_st_patchtst_ablation.py` 的现状不能直接复制到新的无泄漏路线：

1. `load_station_data` 先对全时间序列执行 `ffill().bfill()`，再切训练/验证/测试；`bfill` 会用未来观测补过去缺失。[INT]
2. 它在完整对齐序列上计算中心站相关系数并筛站，验证和测试期信息进入了站点选择。[INT]
3. 当前 `station_end=1035`，而项目北京站点范围是 1001–1036；新协议若使用北京必须显式含 1036。[INT]
4. 缩放统计是在训练窗口触及的原始行上拟合，这一思想可以保留，但必须在先切时间后、仅训练目标时间范围内重写并断言。[INT][INF]
5. 当前正式 runner 只预测 PM2.5，`feat_size=1`。历史“污染物专属 alpha”多目标机制在当前正式任务上不存在可辨识的多污染物 alpha 维度。[INT]

第二轮协议必须先按目标时间切分，再做训练片筛站与统计拟合；只允许按时间顺序 `ffill`，训练起点前无法前向填充的缺失不得反向补齐，应删除受影响窗口或使用预注册的训练片常数并记录掩码。验证/测试的前向填充可以继承更早时刻最后一个已观测值，因为它属于预测时可用历史，但不得回看未来。[DEC]

## 4. MC-CVLRA：从理论放行到正式 STOP

### 4.1 第一轮理论假设

MC-CVLRA 试图用中心站七个共污染物/气象变量的离散滞后历史解释 PM2.5 预测残差，并在冻结 ST 输出后加有界残差。协议包含 self、recent、B-flat、普通 MLP、M-shuffle 和 2×2 组合价值对照；当时只获得“允许进入 L0”的条件放行，并未宣称模型有效。[INT]

### 4.2 L0 训练片/选择片证据

第一轮 L0 的直接目标 ridge 筛查通过：相对 self 平均改善 2.178407%，4/5 折同向；相对 recent 平均改善 2.027396%，5/5 折同向。它只说明冻结输入定义下存在低成本线性滞后信号，不证明神经适配器或组合创新有效。[INT]

### 4.3 L1 工程审计

L1 smoke 曾发现冻结主干仍处于训练态时 BatchNorm 状态可能变化，之后修正为冻结模块保持 eval。该阶段只证明实现可运行和退化路径可审计，不是性能证据。[INT]

### 4.4 L1 正式选择结果

168→6 正式选择的核心结果如下：

| 门 | 结果 | 判定 |
|---|---:|---|
| F11 相对 F10 三种子平均 RMSE 改善 | **0.477392%** | 未达到 0.5%，失败 |
| 三个种子 F11 相对 F10 | 0.680474%、0.459999%、0.291703% | 幅度不足且衰减 |
| 相对 B1 | 0.073843% | 特异性失败 |
| 相对 B2 | 0.022306% | 特异性失败 |
| 相对 B-flat | -0.161018%，0/3 同向 | 失败 |
| M-shuffle | 仅 seed 2061 达到 19.1907% 增益损失 | 远低于逐种子 50% 门 |

因此 MC-CVLRA 已正式 STOP；该路线没有进入其预注册的独立确认，也没有为 MC-CVLRA 新打开广州确认资源。这里不能把“MC-CVLRA 未新开 test”误写成北京 1013 test 未消费：该站同一 test 片在更早项目迭代中已经被多轮观察。[INT]

### 4.5 本轮不可更改的解释

- L0 线性信号不能抵消 L1 对结构特异性的否证。
- 0.477392% 不能四舍五入成通过 0.5%。
- 不得换名为“变量状态”“气象驱动”“污染物协同”“动态 lag”继续尝试。
- 不得改变 lag 集合、变量集合、宽度、损失或阈值后继续消费北京 1013 validation。
- 任何读取辅助变量后输出 PM2.5 残差的轻量 adapter，若没有新的、可由专门对照辨识的机制，均视为同路线挽救。[DEC]

## 5. 失败频域分支

频域分支先后验证了固定 rFFT 路线和严格单向的局部滤波器组：

| 变体 | 主要结果 | 关键特异性结论 |
|---|---:|---|
| 固定 rFFT 相对 locked ST | 0.3502% 改善 | 不足以构成稳定收益 |
| 等容量时域残差对照 | RMSE 49.9519，对比频域 50.1534 | 时域对照更好，频率结构不特异 |
| 因果局部滤波器组 | 平均改善 0.2666%，RMSE 50.1954 | 比时域对照差，6 个 horizon 全部更差 |

实现、参数公平、时间单向和完整性检查均通过，但频率结构本身没有过特异性门，因此路线级 STOP。[INT]

本轮继续排除 FFT、rFFT、STFT、VMD、wavelet、频率 token、谱门控、滤波器组、趋势/季节分解以及用“多尺度卷积”“多分辨率演化”重新包装的同类机制。[DEC]

## 6. pollutant-specific-alpha 历史

旧六污染物任务中，统一 alpha 的 validation MSE 为 `0.702654 ± 0.004348`，污染物专属 alpha 为 `0.702658 ± 0.003624`，差约 `0.000005`，Holm 校正后 `p=0.993`；可学习 alpha 为 `0.704894`。结果支持“空间残差有用”，不支持“按污染物设置 alpha”是增益来源。[INT]

该旧流程还在早期搜索中消费过 test，因此不能复用其 test 结果做新候选选择。当前正式任务为单目标 PM2.5，专属 alpha 更不具备结构辨识空间。[INT][INF]

## 8. 对第二轮设计的直接约束

由上述证据得到以下项目推断：

1. 第二创新点应处理第一创新点未处理的“预测发布后，真实值逐时到达时如何更新误差状态”问题，而不是再次编码输入或空间关系。[INF]
2. 因普通在线 adapter 已有丰富先例，只有跨预测步、同核验时刻的误差包和严格延迟到达算子可以作为待辨识结构；简单 EWMA 若同样有效，创新即失败。[INF][DEC]
3. 168→6 是主辨识任务；24→1 没有真正的跨 horizon 结构，只能作为退化/不恶化检查，不能为主机制提供正证据。[INF][DEC]
4. 新路线必须完全排除北京 1013 和广州 9022；其他站点也不能凭人工印象挑选，须按固定盐值与站点 ID 哈希进入互斥资源池。[DEC]
5. 新种子不能把已用于选择的站点或时间段重新变成独立确认资源。确认必须同时更换站点池并使用封存时间片，种子只作为优化稳定性的次级重复。[DEC]
6. TEFL 已覆盖“滚动预测历史残差、可观测完整多步误差向量、低秩误差模块”这一核心组合。把误差模块改成低维状态递推目前不能证明独立方法贡献，因此 HS-DFES 的当前阶段结论是 T0 NO-GO。[EXT][INF][DEC]
7. 即使未来重新通过 T0，北京和广州两城也不足以支持广泛的跨城市因果或泛化表述；只能按实际封存站点与时间块陈述预测关联和外推范围。[DEC]
