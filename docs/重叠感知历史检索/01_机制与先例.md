# 重叠感知历史残差检索：机制与先例

日期：2026-09-08。状态：待独立理论审查，不授权训练或数据访问。

## 研究问题

第一创新点处理空间邻站。新候选处理时间记忆：密集滑窗的Top-k检索可能集中在同一段历史，相似候选数不等于独立证据数。问题不是再加一个RAG模块，而是这种采样密度是否导致校正受单次历史过程支配，以及显式控制时间覆盖集中度是否优于简单去重。

该现象在本项目尚未测量；不能把推断写成已经发现的缺陷。不引入频域、辅助污染物、事件状态标签或在线参数更新。

## 一手先例（2026-09-08核验）

- [RAFT，ICML 2025](https://proceedings.mlr.press/v267/han25d.html)：检索训练期相似历史及其已知未来，辅助预测；[作者仓库](https://github.com/archon159/RAFT)。因此“检索历史未来”不是创新。
- [RATL，2026公开稿](https://arxiv.org/html/2609.03937)：冻结预测器，保存训练窗口的残差，按变量检索，路由到不同预测步块，并设零残差候选与校正强度选择。原文描述的记忆残差来自基模型训练样本，未找到前向留出残差生成协议；这属于拟合残差与部署残差的分布差异风险，不能笼统称测试泄漏。未找到候选间时间重叠约束。原文未定位官方代码链接，许可未知。
- [SARAF，KDD 2026](https://arxiv.org/html/2606.04135)：stride=1建立记忆，stationarity控制随机MMR及聚合；冗余代理是候选query相似度之间的接近程度，不是显式时间区间覆盖。[作者仓库](https://github.com/ShiqiaoZhou/SARAF)。因此“相似度与多样性折中”本身也不是创新。
- [空气质量analog/Kalman校正，2015](https://repository.library.noaa.gov/view/noaa/68213)：空气质量历史类比校正已有直接应用先例。

以上未找到的细节仅指所核验文本，非对全部相关工作的不存在证明。本轮不复制外部代码；代码许可证未逐项核实，不推断可复用。

## 候选 OARR（暂名，不作为原创性证据）

任务主设为168→6，中心PM2.5，保留空间结构。基预测器f只在时间A拟合并永久冻结。在后续B片段生成未参与f拟合的历史预测及残差，记忆条目为 `(origin, key, residual[H], target_interval)`。

起点t的输入为 `[t-L,t)`，目标为 `[t,t+H)`。候选i只在其全部目标已成熟且早于t时可用；额外隔开H个起点。记忆key只使用中心历史的训练尺度标准化值，不查询未来残差或目标。

从固定相似度的Top-K候选构造概率p。目标区间的归一化incidence向量为v_i，令O_ij=<v_i,v_j>，于是O半正定、对角为1。初稿权重：

```text
w* = argmin_{w>=0, sum(w)=1} ||w-p||² + lambda * wᵀ O w
prediction = frozen_prediction + gamma * sum_i w_i * residual_i
```

这是凸二次优化，不宣称优化器新颖。待检验差异在于：以可追溯的原始时间覆盖控制密集检索的重复占据，而非以query相似度或无依据的独立样本数表示多样性。

## 必须先解决的数学与接口风险

1. O是覆盖集中度核，不是已证实的残差协方差。不同候选的同预测步误差并不因目标集合交叠而必然共享同一个真值。
2. H=1时不同条目的O=I，退化为对p的均匀收缩；24→1只能作退化/非劣检查，不能为重叠机制提供正证据。
3. H=6目标区间重叠未必代表L=168历史的同过程依赖。需用简单时间间隔与硬块去重强对照，而不是只击败相似度。
4. 对角项wᵀw本身能产生均匀化。必须有O=I对照，分离收缩与真实时间排列的价值。
5. 非拟合记忆是公平数据协议，不是创新点；所有校正对照均共享同一记忆。
6. frozen参数+eval+buffers恒等；记忆生成后不得重训基模型而保留旧残差。
7. 不得使用确认期结果改变K、lambda、gamma、距离、去重宽度或核。

## 最低对照

无校正、等权检索、相似度检索、O=I收缩、最小时距筛选、硬时间块去重、SARAF式MMR、OARR、置乱O。全部使用同一个冻结基础预测器、非拟合记忆与评分目标。

L0只用于检验明确的小机制是否值得L1，不要求先开发神经路由器。若仅与朴素相似度比较有收益、但不胜过硬去重/各向同性收缩，就按机制否证止损。
