# 重叠感知历史残差检索（OARR）

日期：2026-09-08。当前：L0正式筛查STOP。独立理论及数值协议曾通过；实验分支按冻结协议完成L0，OARR虽优于检索对照，但相对无检索BASE的RMSE恶化14.616924%、四块0/4改善，故不进入L1。

## 一句话

用显式时间覆盖核抑制密集历史检索中相邻窗口的重复占据，检验其是否比普通相似度、均匀收缩和简单去重更有用。它是时间检索估计机制，第一创新点仍是空间邻站融合。

不是“首次残差检索”，不是残差协方差模型，不声称同过程识别或统计独立性。RATL、SARAF和空气质量analog先例均纳入强对照设计。
