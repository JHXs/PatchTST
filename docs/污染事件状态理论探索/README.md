## 结论

RES-Peak 的领域问题成立，但当前机制不构成足够独立的第二方法创新。有限事件相位加显式持续期属于 HSMM；把持续期展开为“相位×驻留年龄”后属于扩展状态 HMM；状态条件残差的软组合属于 mixture-of-experts，硬阈值版本则是确定性门控专家。[EXT][INF]

固定阈值、滞回宽度、最短持续期和事件合并间隔可以约束泄漏并提高事件定义的可复现性，却没有改变上述模型族。它们属于标签与分段协议，不是不可约预测机制。[INF]

一年逐小时序列在读取数据前已经构成高风险：事件而非小时才是独立统计单位；持续期、恢复期和合并间隔会进一步减少完整事件；单个开发目标还要承担阈值、五相位和状态条件校正的辨识。[INF]

## 独立审查吸收的五条理由

1. PM2.5 预测已有直接 HSMM 先例，领域对象与显式持续期的组合不新。
2. 通用 HSMM 和 neural semi-Markov 已覆盖可学习持续期、转移和状态条件输出。
3. 候选校正可重参数化为 HSMM/HMM 或门控专家混合，没有给出表示外机制。
4. 阈值、滞回、最短持续期与峰值加权主要改变监督标签或损失采样，属于工程协议。
5. 完整事件数存在先验不足风险，且“与空间创新不同”只证明正交，不证明自身原创。

五条中任一条都足以阻断 PROCEED；潜在精度收益不能推翻原创性门。[DEC]
