# 机制与不可约性

## 被审计的最小候选

冻结第一创新点产生基础预测 `y_hat_st(t, h)`。RES-Peak 只能读取预测时刻可见的目标站历史与已经成熟的事件状态，输出有界校正 `delta(t, h)`：

```text
y_hat(t, h) = y_hat_st(t, h) + alpha * tanh(delta(t, h))
```

候选状态固定为起始、上升、峰值、衰减、恢复；持续期、转移和校正不得反向更新 ST，也不得改变邻站门控或站点身份偏置。[INT][DEC]

## HSMM 重参数化

令 `s_t` 为五类事件相位，`d_t` 为当前相位持续期，`H_t` 为时刻 `t` 可见历史。任何状态条件校正都可写为：

```text
delta(t, h) = sum_{s,d} p(s_t=s, d_t=d | H_t) * g_{s,d,h}(H_t)
```

其中 `p` 是显式持续期状态后验，`g` 是状态条件输出。这正是 HSMM 的持续期、转移与 emission/expert 组合；把 `p` 和 `g` 换成神经网络只得到 neural HSMM。[EXT][INF]

若最大持续期有上界，把每个状态展开为 `(s, elapsed_age)`，半马尔可夫过程可表示为更大的 HMM。相位顺序约束只是在转移矩阵上置零，不形成 HMM/HSMM 表示之外的新机制。[EXT][INF]

## Mixture-of-experts 重参数化

上式同时是门控专家混合：`p(s,d|H_t)` 是 gate，`g_{s,d,h}` 是 expert。用固定阈值确定相位时，gate 退化为 one-hot；用软分类器时，它是普通 soft gate。[EXT][INF]

“冻结 ST 后加残差”只规定组合接口。把各专家输出解释为污染事件相位，不会改变函数类；没有额外守恒量、识别约束或可检验不变量时，解释标签不能提供不可约性。[INF]

## 工程规则不能承担原创性

固定阈值避免选择/确认泄漏，滞回减少边界抖动，最短持续期过滤短噪声，合并间隔避免一个事件被重复计数。这些规则有实验设计价值，但只决定标签和切段。[INF]

阈值按训练片分位数确定、按监管限值确定或由训练片学习，均未改变校正器的 HSMM/MoE 表示。规则数量越多，反而越容易形成可调事件定义和多重试验风险。[INF]

## 尝试过的不可约候选及裁决

| 候选差异 | 可否被既有族吸收 | 裁决 |
|---|---|---|
| 五相位只能按固定顺序转移 | HSMM 转移掩码 | 吸收 |
| 每个相位具有独立持续期 hazard | 显式持续期 HSMM | 吸收 |
| 转移与持续期由历史上下文调制 | neural/contextual HSMM | 吸收 |
| 每个相位产生不同预测残差 | switching regression / MoE | 吸收 |
| 软相位概率混合多个校正头 | gated MoE | 吸收 |
| 冻结 ST、零初始化、有界幅度 | 安全组合约束，不是新状态机制 | 不足 |
| 用阈值、导数和滞回生成相位标签 | 确定性 gate 与标签工程 | 不足 |

当前没有提出不能由 HSMM、扩展 HMM 或 MoE 重参数化的独立算子。若引入排放守恒、输送动力学或可观测外部干预，可能改变机制类别，但会越出当前冻结接口和可用资料边界，也可能重入已 STOP 的空间/滤波路线。[INF][DEC]

## 一年逐小时数据的先验事件数风险

风险在未读取数据前已经成立。全年只有 8,760 个小时，但统计单位是“目标站×完整事件”，不是小时或滑窗。若最短事件长度为 `m`、事件间最短恢复/合并间隔为 `g`，完整非重叠事件数上界不超过 `floor(8760 / (m + g))`；真实可用数还会因低于阈值、边界截断和缺失规则减少。[INT][INF]

一个事件内部的起始、上升、峰值、衰减和恢复高度相关，不能当作五个独立样本。季节聚集还会降低有效样本量，并使训练片内阈值、持续期分布与五个状态校正头同时估计变得不稳定。[INF]

B2 开发只允许一个预定目标，无法用“多站点小时数”掩盖单目标完整事件不足。未读数据时不能断言事件数必然不足，但足以把该路线判为高风险，且此风险不能用测试性能事后消除。[DEC]

## 与第一空间创新的区分

第一创新点回答预测发布前如何从邻站形成空间上下文；RES-Peak 回答目标自身处于何种事件相位并如何校正冻结预测。两者在建模轴上确实区分，也可以串联。[INT][INF]

这种区分只满足“非重复第一创新点”的必要条件。由于 RES-Peak 自身被 HSMM、regime switching 与 MoE 覆盖，它不满足“第二方法创新”的充分条件。[INF]

## T0 裁决

原创性门失败，结论为 NO-GO。不得通过运行 `B-flat`、观察性能或扩大事件定义搜索来补做原创性。[DEC]
