# 鲁棒性与迁移候选比较

> 访问日期：2026-09-05。本文仅是理论筛选，不构成实验授权，不分配 B0–B3，不消费任何选择或确认资源。后续专项审查已将当时待审候选判为 T0 NO-GO，以 `03_阶段门决策.md` 为准。

## 1. 评审口径与本轮结论

- 候选属于 Transformer、域适配或 conformal 等已有函数族，不再因此自动 NO-GO。审查对象是具体信息约束、估计方法、训练目标和可反驳优势，不要求“新函数族”或不可表示定理。
- 本轮没有读取数值或缺测掩码；因此“新站样本不足”“真实连续故障足够”都不是事实结论，只是待核风险。
- **当时唯一待审候选：中心站连续缺测下的缺口状态感知鲁棒预测。**专项审查加入 CRIB 和空间接口风险后，该方案已 STOP，不再是待审主候选。
- 少样本跨站迁移和缺测风险校准本轮不选：前者尚未提出超过强域适配近邻的可识别优势，后者已有高度贴近的 2023/2026 conformal 机制，且会改变论文主目标。

## 3. 候选 A：中心站连续缺测鲁棒预测（当时待审，现已 STOP）

### 具体假设与最小机制

在不改动第一创新已固定空间融合的前提下，只在中心路径加入因果可见的缺测掩码和“距最后观测时长”，对每个 patch 仅用已观测位置归一化/聚合。训练目标是清洁样本损失、同一样本因果块遮挡前后的预测一致性，以及按缺口时长/位置分组的最坏组预测损失。不对真实缺失值伪造插补标签，不重新发明空间门控。

**可反驳假设：**在完整输入性能变化不超过预先规定的非劣界时，上述机制对中心站连续历史缺口的“最坏缺口组”未来预测风险应低于强对照；优势应随缺口变长而不是只在平均缺测率上出现。

### 最近邻与可辨识差异

- 对 GinAR：GinAR 是“随机变量整窗缺失 → 插值表示 → 自适应图 → 全变量预测”；候选 A 是“单中心站可变长连续缺口 → 不显式恢复缺失值 → 固定既有空间路径 → 直接最坏组预测”。
- 对 MissTSM：MissTSM 的关键是通用 TFI token 和每时刻缺失特征屏蔽；候选 A 的候选贡献不能写成“mask-aware Transformer”，而应落在**中心故障缺口状态 + 因果块遮挡 + 缺口组鲁棒目标**的联合约束。
- 对 SAITS 的因果边界修正：预测起点 `t0` 前已观测且未被遮挡的历史属于可用信息集；只要插补不读取 `t>=t0` 值、预测目标或测试拟合统计，对历史窗内缺口使用前后双向上下文**不是未来泄漏**。SAITS 仍是插补目标的两阶段强对照，所有方法必须共享同一 `I_t0`。
- 这些是估计与约束差异，不是不可表示性声称。若“显式 mask+时长”基线已达到同样最坏组风险，或去掉组鲁棒/一致性目标后效果不变，则联合机制贡献被否证，应止损。

### 最小强对照与否证条件（非实验授权）

1. 同一固定 ST 预测器 + 因果前向保持 + mask + 距最后观测时长；这是不能省的强简单对照，禁止 bfill。
2. MissTSM–PatchTST 在完全相同的中心块掩码与训练预算下的无插补对照；SAITS 插补后接同一预测器作两阶段对照。
3. 候选 A 分别去掉缺口状态、一致性项和最坏组项，以验证差异确由声称机制产生。

若强简单对照或 MissTSM 在预先规定的最坏组主指标上非劣，若改善仅来自更多参数/更多训练，或完整输入退化超界，则不放行。

### 泄漏与真实缺测掩码风险

- 未来协议必须先按时间切分；归一化、掩码时长分布、分组边界和所有统计只能由训练期拟合。
- 块遮挡只能证明对人工干预的鲁棒性，不得冒充真实设备故障。尚未知真实掩码是否可得、数量是否足够、故障机制是 MCAR/MAR/MNAR 中的哪一类。
- 正在持续故障的中心站没有实时真值；真实案例只能在故障结束后的已观测目标上评估，或依赖经独立认证的参考仪器。不可用事后恢复值作为当时模型输入。
- 邻站和外生量也可缺测；若不显式声明其在预测时刻的可见性，会把未来信息泄漏误当成鲁棒性。

### 论文目标变化

仍是中心站点预测，但主张从“完整输入下的平均 RMSE”改为“因果连续缺口下的最坏组预测风险，同时保持清洁性能”。这是鲁棒点预测论文，不得写成真实故障泛化已被证明。

## 4. 候选 B：新中心站少样本迁移（本轮不选）

### 具体假设、近邻与可辨识差异

可研究的最小假设是：源站共享 patch 表示，新中心站只用明确数量的带标签时间窗拟合收缩的低秩站点 adapter，并在估计负迁移时回退到源模型。可反驳优势应是更低的“标签预算–风险曲线面积”和更少负迁移，而不是只在一个样本预算上赢。

DAF 已通过共享 query/key、域判别器和域私有 value 直接处理少样本预测，且使用源/目标联合训练。“换成 PatchTST adapter”或“在新站微调”不足以区分；必须证明收缩与负迁移回退规则在站点时序上有可重复的特有优势。本轮没有足够证据支撑这一点，故不选，但不是因为它属于已有函数族。

### 最小强对照、泄漏风险与目标变化

- 对照至少包含：目标站同预算从头训练、源模型直接推理（真零样本）、全参数微调、冻结编码器+线性头、DAF/域对齐强基线和带站点 ID 的池化训练。
- 新站必须在预训练、站点/邻站选择、归一化和调参中整体留出；使用过任何目标标签就只能称 few-shot，不能称 zero-shot。
- 当前未测定各候选新站可用窗数，不得以“样本确实不足”作为立项事实。
- 论文主目标会大幅变为跨站点样本效率与负迁移；“单站时间留出”无法支撑该主张。

## 5. 候选 C：缺测/分布变化下的风险校准（本轮不选）

### 具体假设、近邻与可辨识差异

一个可检验版本是：冻结点预测器，用中心站缺口时长和分布状态对非一致性分数做后训练校准，目标是不同缺口组的覆盖率达标且区间更窄。然而，CP-MDA 已用精确/嵌套遮挡解决缺测模式条件覆盖；2026 TMLR 先例的已核摘要又已包含后训练 NN、结构化缺测特征、新分数、时序依赖与组条件覆盖。

因此，仅将这些要素用到空气质不是可辨识贡献。只有在完成 2026 原文细节审计后，仍能提出其未覆盖的有限样本/时间序列保证，并且该保证对连续故障有实质价值，才值得重新评审。当前差异未闭合，故不选。

### 最小强对照、泄漏风险与目标变化

- 对照至少包含：全局 split conformal、常规 adaptive conformal、CP-MDA 精确/嵌套版和 2026 方法的官方可复现版；主指标是覆盖偏差/最差组覆盖与区间宽度，不是 RMSE。
- 校准集必须位于训练后、测试前，时序适应参数不得回看测试覆盖；真实缺测模式的存在与数量仍是未测风险。
- 该路线会把论文主目标改为预测区间可靠性；它可使用现有点预测器，但不能冒称点预测 RMSE 创新。
