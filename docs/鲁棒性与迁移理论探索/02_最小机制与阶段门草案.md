# 最小机制与阶段门草案

> 状态：T0 NO-GO 后的未授权保留件。公式用于说明原拼装方案的最小语义和公平对照，不是待实现算法，不冻结任何数值超参。

## 1. 固定人为遮挡任务

设预测起点为 `t0`，历史索引为 `[t0-L,t0)`，目标索引为 `[t0,t0+H)`；历史长度为 `L`，预测长度为 `H`，站数、特征数和中心站索引分别为 `S,F,c`：

\[
X\in\mathbb R^{B\times S\times F\times L},\quad
M\in\{0,1\}^{B\times S\times F\times L},\quad
Y\in\mathbb R^{B\times F_y\times H}.
\]

`M=1` 表示在 `t0` 可见。对中心站全部 `F` 个特征遮挡一个位于历史窗内的连续块：

\[
\mathcal B_{d,r}=\{t_0-r-d,\ldots,t_0-r-1\},\qquad d\ge1,\ r\ge0,\ d+r\le L,
\]

其中 `d` 是缺口长度，`r` 是缺口后仍在历史窗内的小时数；`r=0` 表示缺口截至 `t0-1`。只遮历史，`Y` 不动。`d,r` 网格和采样权重未冻结；因此这只定义任务族，不是可运行协议。

未知真实故障掩码不阻断这个可控模拟问题；它只限制结论为“对人为连续块遮挡的鲁棒性”，不得写成真实设备故障验证。

## 2. 同一信息集与 SAITS 因果边界

全部对照只可使用

\[
\mathcal I_{t_0}=\{M_{s,f,t}:t<t_0\}\cup\{X_{s,f,t}:t<t_0,\ M_{s,f,t}=1\}\cup\{\text{仅由训练期拟合的统计与参数}\}.
\]

对历史窗内一个内部缺口，SAITS 可使用缺口前后但均早于 `t0` 的观测；这种双向插补不是未来泄漏。读取 `t>=t0`、`Y`、测试拟合统计，或在线时不可得的事后修复值，会越过信息边界。人为遮掉的值不属于受损视图信息集；完整视图只能在获授权的训练中作为教师或对照，不能暗供受损视图推理。

## 3. 已止损机制的最小数学语义

先用训练期统计标准化得到 `Z`。用因果前向保持产生数值安全代理；窗左端之前没有已观测值时代理为标准化零并置左截断标记，禁止 bfill：

\[
Z^\dagger=M\odot Z+(1-M)\odot\operatorname{CausalCarry}(Z,M).
\]

将中心输入切为 `N` 个长度 `P` 的 patch，得到 `Z^c,M^c\in R^{B\times F\times N\times P}`。对 patch `(b,f,n)` 定义观测数 `k=\sum_p M^c_p`。原草案的“观测支持归一化值分量”仅能写成：

\[
v_{bfn}=\mathbf1[k>0]\frac{P}{k}W_v(M^c_{bfn}\odot Z^c_{bfn})\in\mathbb R^D.
\]

上述表达式按分段函数解释：`k=0` 时不求值 `P/k`，直接取 `v=0`；不用 batch 均值、局部伪均值或未来值。mask 运算之前须先将不可见位置替换为有限占位值，不能用 `0*NaN` 实现屏蔽。全缺 patch 只能向草案适配器暴露空观测 token、mask、左截断标记、截断后 age 和同信息集的空间上下文。

若 `e^0\in R^{B\times F\times N\times D}` 是基线 patch token，则原草案只能以下式表示其硬旁路意图：

\[
e=e^0+\mathbf1[k<P]A_\psi(e^0,v,M^c,age),
\qquad
\hat Y=\operatorname{where}(U,\hat Y_{robust},f_{\Theta,\Phi}(X)),
\]

其中 `U_b=1` 仅当该样本有人为遮挡。这里的 `where` 只是分段定义，并非同时执行两个分支；受损样本不得额外执行接收隐藏中心真值的原模型分支。`U=0` 必须直接调用原模型，不经过学习门，从而完整输入严格旁路。这些公式只说明必要边界；`P,D,W_v,A_\psi` 都未冻结，也未形成独立估计机制。

## 4. 空间分支接口风险

主代理代码检查已确认，`ST_PatchTST_model.py::_build_neighbor_context` 含有

```python
neighbor_values = neighbor_x - center_x.unsqueeze(1)
```

并且成对 gate 也读取 `center_summary`。因此，中心站遮挡同时改变中心 PatchTST 路径、邻站差值和成对 gate；冻结空间参数 `Phi` **不等于**空间输出不变。

任何未来模拟都不得向空间路径偷喂被遮掉的中心真值。若定义共享代理 `Z^dagger_c`，基线、SAITS、MissTSM、CRIB 和候选必须在差值与 gate 中使用同一信息集的中心代理。但重新定义该代理会改变第一创新分支的行为；此语义尚未闭合，本轮不实现解决。

如果未来重开新候选，空间接口至少需明示定义 `G_Phi(Z^dagger,M)->C`的实际输出形状，以及中心代理如何同时进入差值与 gate。当前不假定已有这个接口。

## 5. 冻结语义

原草案所谓“冻结主干与空间分支”必须同时满足：`Theta,Phi.requires_grad=False`；优化器不含这些参数；冻结模块保持 `eval()`；BatchNorm 等 running buffers 不更新；训练前后参数和 buffers 校验和不变。只冻结参数而保留 dropout 或 running-stat 更新不算冻结。

仅 `psi` 可训练的语义也不能解决上节问题：输入改变仍会使冻结空间函数输出改变。

## 6. 必要的拆分对照（仅保留，不授权）

对每个遮挡组 `g=(d,r)` 定义未来预测损失 `ell_g`。以下训练轴必须分开，不能把名称并列当成创新：

\[
L_{ERM}=\sum_g p_g\ell_g,\qquad
L_{uniform}=|G|^{-1}\sum_g\ell_g,
\]

\[
q_g^{j+1}\propto q_g^j\exp(eta\ell_g),\qquad
L_{DRO}=\sum_g q_g\ell_g,
\]

\[
L_{pred-cons}=d(\operatorname{sg}(\hat Y_{clean}),\hat Y_{masked}).
\]

固定 `p_g` ERM、均匀组训练、标准 GroupDRO、GroupDRO+输出一致性必须是四个独立格。GroupDRO 只针对预定义组，不自动保证未见故障机制；完整视图与受损视图的最优条件预测本可不同，强输出一致性也可能引入偏差。CRIB Eq. 11 的观测/额外遮挡视图**潜表示一致性**需单列；它与上式输出一致性不完全同构，但这一差别本身尚不构成独立估计机制。

最低强对照是：

1. 原 ST-PatchTST 与同信息集的因果代理；
2. GRU-D 类 mask/age 强简单对照；
3. MissTSM 无显式插补对照；
4. SAITS 历史窗插补后接同一预测器；
5. CRIB 在 point/block/column 设定中最接近的官方可复现版；
6. 与原草案训练参数量误差不超过预定容差的通用 MLP/adapter。

容量匹配需同时报告可训练参数、优化步数、输入信息、冻结 buffers 和计算量；不得用不参与 forward 的哑参数伪装容量相等。

## 7. T0 尚缺项与当前门状态

- 独立估计机制：缺失。mask/age、MissTSM 类缺测嵌入、CRIB 表示一致性和标准 GroupDRO 已覆盖主要构件。
- 空间接口语义：缺失。共享中心代理会同时改变邻站差值与成对 gate，不能用“冻结”掩盖。
- 数值协议：故意未冻结。`d,r,p_g,eta`、一致性权重、容量容差、主指标、清洁非劣界、种子和停止规则均不可执行。
- 资源协议：缺失。未分配数据、选择或确认资源，B0–B3 不自动重分配。
