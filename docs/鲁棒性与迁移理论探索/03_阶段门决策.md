# 阶段门决策：中心站连续缺测拼装方案

> 决策日期：2026-09-05。阶段：T0 理论门。结论：**NO-GO / STOP**。

## 1. 停止对象

停止的是 `01_候选比较.md` 中当时待审的“中心站连续缺测下的缺口状态感知鲁棒预测”当前拼装版，即 mask/age、观测支持归一化/adapter、缺口组 GroupDRO 与输出一致性的组合。`02_最小机制与阶段门草案.md` 仅保留其最小数学语义，不代表待实现候选。

## 2. 近邻证据与独立差异判定

- GRU-D 已覆盖 mask 和距最后观测时长这一状态原语。
- MissTSM 已覆盖缺测特征感知、无显式插补的通用表示路线。
- [CRIB](https://arxiv.org/html/2509.23494) 是新一手近邻：主代理已核对 Eq. 11 为观测/额外遮挡视图的潜表示一致性，并评估 point、block、column 与 AQI 自然缺测。因此本项目不能声称首次研究块缺测+一致性。
- CRIB 潜表示一致性与原草案输出一致性不完全同构；但原草案没有说明这一差别导出何种独立估计机制或可证优势。
- GroupDRO 是标准风险优化工具。把平均缺测损失换成缺口组最坏风险，可以定义评估目标，但不能单独构成算法创新。

结论不是“属于已有函数族所以 NO-GO”，而是主要构件已被直接近邻和标准目标覆盖，当前没有独立估计机制及其可反驳优势。

## 3. 空间路径未闭合

`_build_neighbor_context` 使用 `neighbor_x-center_x.unsqueeze(1)`，成对 gate 还读取 `center_summary`。遮挡中心站后，即使参数冻结，邻站差值、gate 和空间输出仍会改变。

任何比较都不得把被遮掉的中心真值仅提供给空间路径。双方必须共享同一信息集；但替换成缺测代理值又会改变第一创新的实际运行语义。当前方案未解决这一接口问题。

## 4. 缺失的资源与协议

- 没有读取站点数值、选择或 test；真实故障掩码可得性仍为未知。这不阻断人为块遮挡模拟，但禁止声称真实故障验证。
- `d,r` 网格、组权重、指标、清洁非劣界、容量容差、数据切分、种子、停止规则和确认资源均未冻结。
- B0–B3 不自动重分配；本决定不新建任何资源编号。

## 5. 为何不进入 ablation

T0 同时缺失独立估计机制、已闭合的空间接口和可执行的冻结协议。此时进入 ablation 只会检验已有构件的组合与未定义的空间代理，不能回答清晰研究问题。因此不创建 ablation 分支，不实现、不训练、不读数，不通过新检索或改名挽救当前方案。
