# 独立审查与证据补充

## 审查过程

两名 Codex（gpt-5.6-sol，high）分别完成候选调研与独立审查。第一轮均认为连续缺测方向值得进一步理论核查，但未授权实验。随后专项检索定位了更近的 CRIB；独立审查将当前具体拼装方案判为 T0 NO-GO。

这是先例审查后的阶段决定，不是训练结果。没有用真实站点数据、选择集或测试集诊断来选型。

## 决定性来源与边界

1. GRU-D：[论文](https://doi.org/10.1038/s41598-018-24271-9)已使用观测掩码、距上次观测时间与可学习衰减。不能单独把 mask/age 声称为新机制。
2. CRIB：[原文](https://arxiv.org/html/2509.23494)，*Revisiting Multivariate Time Series Forecasting with Missing Values*。主代理核对 §3.5 Eq.11：一致性作用于潜表示，不是预测输出；附录覆盖 point/block/column 缺测与 AQI。它不是当前候选的完全同构实现，但排除了“首次用块遮挡、一致性或空气质量场景”的泛化表述。
3. Group DRO：[原文入口](https://arxiv.org/abs/1911.08731)优化预定义组的最坏风险。它本身不保证任意未见故障机制的外推。

CRIB 的预测一致性替换与标准 GroupDRO 拼接尚未给出独立估计机制。缺少差异不能由先运行性能实验后解释来补足；同时，未找到充分差异也不是对整个缺测研究方向的否定。

## 主代理代码审计

`ST_PatchTST_model.py::_build_neighbor_context` 使用 `neighbor_x - center_x.unsqueeze(1)`，成对门控也读取中心站摘要。因此：

- 冻结空间参数不等于空间输出不变。
- 模拟遮挡中心后，中心路径和空间路径必须共享同一观测信息集。
- 不得只遮挡时间主干，却将完整中心真值交给邻站差值或门控。
- 代理值和缺测状态的空间接口尚未闭合；本轮不实现修复。

## 信息可用性修正

固定预测起点 t 的历史窗若全部早于 t，则使用窗内后续历史观测进行双向插补不构成预测泄漏。逐缺测时刻 s 的在线回放则不能使用 s 后观测。仓库仍禁止 bfill；允许同信息集的 SAITS 基线不等于允许全序列预填补或未来标签进入模型。

人工块遮挡只支持合成压力测试，不能冒充真实故障实验。真实缺失掩码、参考标签与事件数量未知，不应写成已测得的不足。
