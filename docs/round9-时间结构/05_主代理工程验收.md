# 第 9 轮 CCSPRF 主代理工程验收

日期：2026-09-10。结论：**工程实现 PASS，可提交固定实现并运行非正式同配置 pilot；尚未授权正式 30 种子性能运行。**

## 独立验收过程

初版实现虽通过 7 项测试与小 fixture，但主代理和独立 reviewer 发现发布阻断：global LOO 被再次按 tau 收缩、formal 完整性可漏 EMB、标签未独立闭环、动态与强对照门未实现、自定义主干不是项目实际 PatchTST、长跑不可恢复。主代理在任何正式结果产生前冻结 `03_L0执行补充协议.md`；reviewer 修订后 PASS。

按补充协议修复后，reviewer 又发现 EMB prior 无法独立复算、sidecar 元数据不完整、progress 崩溃窗口、raw/log 前缀及 tau 语义 5 个 P1。全部修复后，reviewer 静态终审 **PASS（仅工程代码可进入 pilot）**，未发现新 P0/P1。

## 主代理核验

主代理逐段检查并确认：

- DGP、时间切分、训练目标标准化和唯一物理时间戳 LOO 与补充协议一致；calendar LOO 的分组均值和 `mu0^{-t}` 都排除自身，global LOO 不使用 tau。
- 使用真实 `tsai.models.PatchTST.PatchTST`；四臂初始主干 hash 相同，构造后重置训练 RNG，EMB 增量严格为 124 参数。
- formal canonical/progress 固定 480 key；初跑 clean tree、不覆盖；resume 只允许输出目录变脏，验证完整 key，并处理仅 progress 落后一个 key 的合法崩溃窗口。
- 独立 summarizer 不导入 runner 的先验、指标或 artifact verifier，逐元素复算 DGP、split、scale、标签、calendar/global 先验、EMB bias、预测、指标、参数和全部六类 gate。
- 仅 CCSPRF 记录 `tau_applied=true,tau=50`；其他臂为 `false,null`。

## 阶段决定

1. 先提交并推送固定实现，使 pilot 的 `source_commit` 可追踪；
2. 用非正式种子 `991105`、正式数据长度/模型/epoch 配置运行 GPU pilot，测量 16 key 的真实耗时、显存和磁盘；
3. pilot 只决定工程资源可行性，不允许修改 DGP、tau、门或模型；
4. pilot 工程通过且成本可接受后，才在 clean source 上启动正式 480 key；正式结果只能由独立 summarizer 判定 PASS/STOP。
