## 3. 机制归因

1. `CCSPRF-global` 与 BASE 的差异约为零（24→1 为 `0.00076%`，168→6 为 `−0.00025%`），说明收益不是普通中心化或训练目标平移。
2. 24→1 的纯日历机制增量只有 `0.133%`，区间含 0，且普通 EMB 明显更优；该任务直接否证“收缩日历先验是主效应级第二创新”。
3. 168→6 的日历增量可重复、30/30 正向、胜过 EMB，且后段和 residual gate 通过；这说明机制在长历史多步条件下具有真实可识别作用，但冻结主效应只有 `2.704%`，未达到预注册 `5%`，不能用条件性正结果越过总放行门。
4. calendar-off 中两个任务均出现小幅但区间不含 0 的恶化，表明在日历效应不存在时，有限样本分组先验仍会注入可检测噪声；这违反预注册特异性门。
5. residual 和 168→6 后段均通过，因此失败不是残差头空壳或多步后段牺牲，而是短任务机制贡献不足、总体主效应不足和零效应适用边界不安全。
