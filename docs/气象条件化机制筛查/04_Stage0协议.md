## 1. 目的与非目的

**目的**：在完全不接触真实站点数据的条件下，判定"对风速响应的预注册形状约束（方向为负、有界、饱和）作为归纳偏置"是否具有可检验的作用：

- 在**有利情形**（真实响应确为递减且饱和；训练数据在低风速段、测试落在高风速段）应带来可观增益；
- 在**不利情形**（真实响应方向相反）不得表现为"免费增益"。

**非目的**：不评估真实数据性能，不产生任何关于北京/广州的结论，不构成第二创新成立证据。

## 2. DGP（合成，固定）

时间序列长度 \(T=20000\)，其中前 70% 训练、后 30% 测试按时间切分，禁止跨切分。

- 风速：\(w_t=\mathrm{clip}(0.8w_{t-1}+0.2\cdot 5+\varepsilon_t,\,0,\,14)\)，\(\varepsilon_t\sim\mathcal N(0,1.0^2)\)（平稳均值约 5、标准差约 1.7）；
- 状态：\(s_t=0.8s_{t-1}+0.2\cdot u_t\)，\(u_t\sim\mathcal N(0,1)\)；
- 上下文向量：\(x_t=[s_t,s_{t-1},w_{t-1}]\)——**只用输入窗口内可恢复的量**，避免不可识别的绝对时间项；
- 基准项：\(f(x)=\beta^\top x\)，\(\beta=(0.8,-0.5,0.3)\)；
- 幅度项：\(A(x)=\operatorname{softplus}(\gamma^\top x)\)，\(\gamma=(0.5,0.3,1.0)\)（正幅度且与状态交互）；
- 响应形状：\(g(w)=1-\exp(-\lambda w)\)，\(\lambda=0.15\)——训练段 \(w\le 4.5\) 落在上升区（\(g(4.5)\approx0.49\)），测试段 \(w>5.5\) 进入饱和区（\(g(12)\approx0.83\)），因此该偏移确实要求**形状外推**；
- 多步：\(y_h=c_h\cdot(f(x)-s\,A(x)g(w))\)，\(c=(1,0.9,0.8,0.7,0.6,0.5)\)，保证 H=6 各步非退化。

两个 DGP 只差符号：

- **DGP-M（单调递减，与物理预期一致）**：\(y_H=f(x)\cdot\mathbf 1_H-s\cdot A(x)\cdot g(w)\)，\(s=+1\)；即预测随风速递减且有界。
- **DGP-A（方向相反）**：同一式子但 \(s=-1\)，即随风速递增。

观测噪声：\(\mathcal N(0,\sigma^2)\)，\(\sigma=0.5\)；\(y_H\in\mathbb R^H\)，\(H\in\{1,6\}\)，六步共用同一 \(x,w\)，只改变输出维度（保证 H=1 与 H=6 都不是退化问题）。

## 3. 三种评估情形（均在同一 DGP 上）

| 情形 | 训练集 | 测试集 | 含义 |
|---|---|---|---|
| **S-shift** | 仅 \(w_t\le 4.5\) 的窗口 | \(w_t>5.5\) 的窗口 | 分布外偏移：饱和段在训练中缺失，必须外推形状 |
| **S-small** | 随机 25% 训练窗口 | 全测试集（同分布） | 有限样本 |
| **S-iid** | 全部训练窗口 | 全测试集 | 同分布充分样本（作为"约束不应造成明显损害"的对照） |

## 4. 骨架与三个臂（参数量报告，不做超参搜索）

共享骨架：输入为最近 \(L=24\) 步的 \([s,w]\) 两通道（48 维展平）→ 两层 MLP（hidden 64、GELU）→ 输出维度 \(H\)。三个臂只差最后一步如何引入 \(w_t\)：

1. **`uncon_add`（同信息集强基线 B0 形态）**：\(\hat y=f_\theta(x)+h_\theta([\text{feat},w_t])\)，其中 \(f,h\) 均为 hidden 64 的两层 MLP；
2. **`wcs_neg`（候选）**：\(\hat y=f_\theta(x)-\operatorname{softplus}(g_\theta(x))\odot\left(1-\exp(-\operatorname{softplus}(\kappa)\,w_t)\right)\)，其中 \(f,g\) 与 `uncon_add` 的 \(f,h\) 同宽同初始化方式，\(\kappa\) 为标量参数；
3. **`wcs_pos`（错误符号对照）**：同 `wcs_neg` 但符号为 \(+\)。

要求与实现约束：

- `wcs_neg`/`wcs_pos` 的输出对 \(w_t\) 必须**严格单调且饱和**（由构造保证，单测覆盖）；
- 三臂使用相同优化器（Adam，lr 1e-3）、相同批大小（256）、相同 epoch 数（60）、相同早停规则（按训练集内 10% 验证切分的 RMSE，patience 8）；
- 三臂初始化使用同一随机种子序列，仅模型构造顺序不同；
- 每个臂的真实参数量必须由代码统计后写入结果表；若 `uncon_add` 参数量少于 `wcs_neg`，本协议判为对照不公平并停止。

## 5. 重复与判据（预注册，运行后不得修改）

- 重复：**20 个独立种子**（数据生成与初始化均随种子变化），逐种子配对；
- 主指标：测试集物理尺度 RMSE；统计量为逐种子**配对相对改善** \(\Delta=100\cdot(\mathrm{RMSE}_{\text{ctrl}}-\mathrm{RMSE}_{\text{wcs\_neg}})/\mathrm{RMSE}_{\text{ctrl}}\)；主对照为 `uncon_add`。

**放行判据（全部满足才进入 Stage 1）**

| 编号 | 判据 |
|---|---|
| P1 | DGP-M / S-shift / H=1：平均 \(\Delta\ge 5\%\)，且 ≥16/20 种子为正 |
| P2 | DGP-M / S-shift / H=6：平均 \(\Delta\ge 5\%\)，且 ≥16/20 种子为正 |
| P3 | DGP-M / S-small / 两个 H：平均 \(\Delta\ge 5\%\)，且 ≥16/20 种子为正 |
| P4 | DGP-M / S-iid / 两个 H：平均 \(\Delta\ge -1\%\)（约束不得在充分同分布数据上显著损害） |
| N1 | DGP-A / S-shift / 两个 H：`wcs_neg` 相对 `uncon_add` 的平均 \(\Delta\le 1\%\)，且 ≤12/20 种子为正 |
| N2 | DGP-M / S-shift：`wcs_pos` 相对 `uncon_add` 的平均 \(\Delta\le 0\)，且 ≥14/20 种子为负（证明符号必须正确） |
| N3 | 单调性与饱和性单测通过：对固定 \(x\)、在 \(w\in[0,12]\) 网格上，`wcs_neg` 输出严格递减且相邻差分之比随 \(w\) 增大而减小 |

**任一判据不满足 → Stage 0 不通过 → 整轮 STOP**，不进入 Stage 1，不做真实数据改造，不消耗任何站点资源（北京/广州数据与种子均未使用；本协议只用合成数据）。
