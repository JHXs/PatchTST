# Round 16 主代理合并决定

日期：2026-09-15。结论：**W4 直接 NO-GO；W2/W3 降级为基线；W1 有条件 GO，但只放行"先合成、后真实"的分阶段路径**。

## 1. 两份材料与分歧

- `01_候选机制.md`（设计代理）：W1 形状约束"条件性保留"，W2 交互弹性"不可识别"，W3 风场传播核"实质新增第二套空间门 → NO-GO"。
- `02_先例与等价性审查.md`（独立代理）：W1（无条件门控）＝标量 FiLM/gating，**降级为 B-cap**；W2＝特征工程 + 普通头；W3＝自由残差/有界输出，FiLM 已覆盖；W4＝weather-conditioned MoE，且属边界禁止的多尺度换名。

两份文档实际在收敛：审查方给出的唯一出路是——**预注册的物理形状约束，且必须把主张限定为"归纳偏置"而非"函数类不可表示"**（02 §9.3），而设计方的 W1 正是这个。

## 2. 主代理字段核验（新增证据，决定可行性）

只读 `tsai/data/stations_data/df_station_1013.csv` 的表头与列统计（北京 1013 已消费资源，不引入新资源）：

| 字段 | 缺失率 | 范围（中位数） | 判定 |
|---|---|---|---|
| `PM25_Concentration` | 0.0% | 3–461（61） | 目标，正常 |
| `wind_speed` | 0.0% | 0–34.56（5.0） | **物理合理，可作为预注册单调变量** |

## 3. 裁决

### 3.1 W4：NO-GO

weather-conditioned 多尺度/专家加权（02 §8）落入边界明令禁止的"多尺度换名 + 条件 MoE"，且与 W2/W3 的覆盖结论一致。

### 3.2 W2/W3：降级为基线，不进入实验

- W2（把 `U×PBLH`、湿度等构造量送入模型）＝确定性特征工程 + 普通头，MLP 可从原变量逼近，违反硬约束 4；且数据中**没有 PBLH**，任何代理量都有换名风险。
- W3（风场条件化的邻站传播核）会让核权重随气象改变邻站的有效贡献 → 实质是气象驱动的**第二套动态空间权重**，违反硬约束 3；且 `wind_direction` 不是角度、邻站方位不在当前信息集内。

### 3.3 W1：条件 GO（分阶段，先合成后真实）

放行对象被收窄为：

> **WCS**：在冻结主干的既有结构上，对预测输出相对 `wind_speed` 的响应施加**预注册、可观测、可证伪的形状约束**（方向为负、幅度有界、随风速饱和），并把它作为**归纳偏置**而非表示能力来源。

必须满足的三条框架性要求（来自 02 §9）：

1. 承认 \(\mathcal F_{\text{str}}\subseteq\mathcal F_{\text{cap}}\)，主张限定为归纳偏置；
2. B-cap 与候选输入、参数原语、训练预算完全相同，**只解除该约束**（或把符号反置）；
3. 正/负 DGP 双向见证，证明该判据有区分力。

## 4. 分阶段执行与止损门

**Stage 0（纯合成，不读任何站点数据）**

- 在固定的小型序列骨干上构造两类 DGP：
  - **DGP-M（单调）**：真实条件均值对风速严格递减且饱和；在**受限样本/分布外偏移**设定下评估；
  - **DGP-A（反单调）**：真实响应方向与预注册符号相反。
- 判据：DGP-M 上受约束臂在受限样本/偏移设定下平均配对 RMSE 优于无约束臂 **≥5%**；DGP-A 上受约束臂**不得优于**无约束臂（允许变差）。
- 若 Stage 0 不通过 → 整轮 STOP，不进入 Stage 1（不消耗任何真实数据与工程改造）。

**Stage 1（真实数据，仅训练段/验证段）**

- 先重建新信息集下的对照链：含 `wind_speed` 的退化 PatchTST（新 BASE）→ B0（含气象的普通残差头）→ B-cap（等容量、解除约束）→ 候选 WCS；2×2（空间 off/on × 约束 on/off）。
- 3 种子筛查；门：两任务上候选相对 **B0 与 B-cap** 的平均配对 RMSE 均下降 ≥1%，3/3 方向一致，MAE 恶化不超过 0.5%。
- 机制诊断：固定输入的干预检验——提高 `wind_speed` 输入，候选的响应必须落在预注册方向与幅度带内，B-cap 不作要求。
- 未过门 → STOP；不得改用更小阈值、换变量（如改用湿度）或只报单一任务。

**Stage 2（确认，需另行授权）**

- 每任务 ≥5 个未消费新种子、预注册门、独立复算；测试段此时才首次启用。

## 5. 边界与记账

- **不影响现有结论**：北京 3.1188%/0.8220% 与广州 2.2072%/1.8224% 仍只对**旧信息集**成立；Stage 1 建立的是新信息集基线，两者不得混比。
- 数据纪律：气象只做**因果填充**（禁 `bfill`），缩放/阈值/筛站只用训练段；`wind_direction` 语义未核验前不得参与任何机制。
- 资源：本轮（理论）未消耗任何数据/种子/算力。Stage 0 为纯合成、不涉及数据。Stage 1 若启动，须在实验分支协议中显式登记新信息集、新基线与新种子。
- 若 Stage 0 或 Stage 1 失败，本方向按 STOP 归档，禁止以"气象条件化 + 更小阈值/换变量"复活。
