> 状态（2026-08-23）：F1/F2通过，固定rFFT的F3和唯一因果局部滤波器组FA1均失败；当前频域/多尺度路线已止损。

## 与第一创新点的边界

- 上游锁定结构：Top-5 稀疏门控＋站点身份偏置＋同种子退化基线初始化＋冻结 PatchTST 主干。
- 频域探索不再调整空间 Top-k、站点门控、空邻站或空间训练策略。
- 无泄漏新协议锁定的是 ST 架构，不是旧协议下的站点集合、权重或检查点。
- 旧 ST 正式结果仍保存在 `experiments/results/st_patchtst_ablation/`，不会被频域运行器覆盖。
- 频域结果只能写入 `experiments/results/causal_frequency_ablation/`。

## 当前实验结论

可以表述为：“在无泄漏北京1013站PM2.5的168→6验证设置中，固定rFFT与12/48小时因果局部三尺度分解均未提供超过等容量时域残差适配器的增量证据。”这是否定当前两个预注册实现的局部结论，不代表所有频域方法普遍无效。

不得表述为“频域分支已有效”“可学习频带已有效”“动态门控已具有气象意义”或“污染峰值已得到保持”。当前也没有允许进入的后续Gate；重启研究前必须重新定义第二创新点。
