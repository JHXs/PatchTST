- 上游锁定结构：Top-5 稀疏门控＋站点身份偏置＋同种子退化基线初始化＋冻结 PatchTST 主干。
- 频域探索不再调整空间 Top-k、站点门控、空邻站或空间训练策略。
- 无泄漏新协议锁定的是 ST 架构，不是旧协议下的站点集合、权重或检查点。
- 旧 ST 正式结果仍保存在 `experiments/results/st_patchtst_ablation/`，不会被频域运行器覆盖。
- 频域结果只能写入 `experiments/results/causal_frequency_ablation/`。
