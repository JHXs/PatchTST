# 单站点同可训练参数预算对照协议

> 协议版本：v1.0  
> 锁定日期：2026-09-25  
> 实验分支：`experiment/backbone-upgrade-ablation`

## 1. 问题与声明边界

已有主干升级实验将中心站主干冻结，只训练空间分支。`cap32_b4_a10` 的可训练参数为 4,588–5,418，`cap128_b8_a20` 为 55,596–61,386；已有单站点 GRU/LSTM 基线的总参数约为 21k，且全部参与训练。两者没有在同可训练自由度下比较。

本轮只补齐这一方法学维度，不新增模型机制，不调整既有空间分支或主干，不使用本轮测试结果回调隐层宽度。种子 2047–2051 已被既有研究消费，所以本轮是同协议补充对照，不得称为新独立确认。

## 2. 数据、任务与输入边界

数据由 `run_beijing_leakfree_coverage.prepare_datasets_leakfree` 构造。站点筛选只使用训练窗口覆盖的时间段，缺失值只做因果前向填充，并按时间使用 70%/10%/20% 的 train/valid/test 划分。训练数据集仍保留筛出的 18 站张量，但单站点适配器在模型边界只截取中心站 1013 的 PM2.5 通道。任何邻站扰动都不得改变基线输出。

覆盖 20 个北京任务：`L∈{24,48,72,168}` 与 `H∈{1,3,6,12,24}` 的笛卡尔积。24→1 和 168→6 使用种子 2047–2051，其余任务使用 2047–2049，共 64 个任务—种子组。

## 3. 预注册实验臂

基线为 tsai `GRU` 与 `LSTM`，均设置 `c_in=1`，预测维度等于当前 horizon，端到端训练所有参数。隐层宽度在运行前固定为 `{8,16,32,40,48,64}`，形成 12 个实验臂：`center_gru_h*` 与 `center_lstm_h*`。不依据测试集选择隐层宽度。

每个运行登记 `input_channels=1`、`total_parameter_count`、`trainable_parameter_count`、`best_valid_loss` 和 `rmse_ugm3`。本轮模型全部可训练，因此总参数应与可训练参数完全相等。

## 4. 训练与评估语义

训练语义与 `run_st_patchtst_ablation` 保持一致：AdamW（`lr=1e-3`、`weight_decay=1e-4`），`ReduceLROnPlateau(mode="min", factor=0.5, patience=3)`，MSELoss，全局梯度范数裁剪 1.0，以验证集 MSE 早停并保存最优检查点。`L≤48` 使用 40 epochs / patience 8 / batch 256，`L>48` 使用 30 / 6 / 512。只在训练结束后对 test 评估一次。

若损失出现 NaN/Inf，同一运行仅允许将学习率降为原值的 1/10 重试一次；仍发散则记为 `nonfinite`。GPU OOM 记为 `infeasible_oom`。异常运行也必须落盘，不中断其余矩阵。

## 5. 三项对照与聚合规则

同预算主对照将 `cap32_b4_a10` 与 GRU/LSTM `h=40` 按 `(history,horizon,seed)` 配对。差值定义为 `our_rmse - baseline_rmse`，相对变化定义为 `100×(our/baseline-1)`，负值表示空间模型更优。结果报告总体、按 horizon 与按 history 的平均相对变化、更优组数及有效配对数。异常终态不得当作数值配对，但必须进入完整性统计。

容量曲线对每个 `(history,horizon,family,hidden_size)` 报告可训练参数和各种子 test RMSE 的均值与样本标准差，并与 `cap32_b4_a10` 和 `cap128_b8_a20` 的完成运行并列。`cap128_b8_a20` 的 55k–61k 超出本轮预注册 GRU/LSTM 网格上限；因此只能与注册网格中参数最多的 `h=64` 作“低于预算上限的参考”，不得标成同预算。

参考对照沿用容量搜索的 C1（候选空间分支 vs 自身冻结主干）和 C2（候选空间分支 vs 现有验证集选出的最强单站点基线）。C2 的选择决定不得使用本轮结果重做。

## 6. 预注册判据

“成功”要求 GRU h=40 和 LSTM h=40 两类配对的平均差值均小于 0，且两类合并后至少 60% 的有效组中 `cap32_b4_a10` 更优。若总体不满足，但仅某一模型族、某一 history 或某一 horizon 同时满足平均差值小于 0 且至少 60% 组更优，判为“部分成功”。若上述条件都不满足，判为“失败”，并按“当前实验范围内，跨站信息在该可训练预算下没有展示价值”的边界记录。

## 7. 完整性与复算门

正式矩阵预期 768 个身份。汇总器必须检查身份集合完全相等、所有状态属于预定终态、输入通道恒为 1、参数量可由模型独立重建、完成行的预测文件可独立复算 RMSE、训练配方与锁定语义一致，以及表图数据均来自真实实验文件。任一强制检查失败时，结果文档必须标记为不可放行。
