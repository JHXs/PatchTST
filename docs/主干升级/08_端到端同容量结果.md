## 对照设计

| | 基线臂 B | 我们的臂 O |
|---|---|---|
| 主干 | GRU/LSTM(h) 单站点，**全部参数训练** | **同一主干，不冻结** |
| 输入 | 仅中心站（通道=1） | 中心站 + 邻站（通道=18） |
| 配方 | 与 `trainable_matched` 完全一致（同数据、同划分、同种子、同 epochs/patience/batch/lr/早停） | 同 B，仅多一个空间头 |
| 可训练参数 | h（273–14,424） | h + 空间头（4,588–8,406） |

B 臂数据直接取自 `experiments/results/trainable_matched/raw_metrics.csv`（同一配方，独立跑过一次）。

按预测步（平均）：

`lstm_h16` +27.2%、`gru_h16` +28.1%（主干越小、劣化越重）。

## 不是离群、不是早停

- 幅度分布：|Δ|≤1% 有 138 组、1–10% 有 86 组、>10% 有 **155 组**（其中 >50% 有 76 组）。
  剔除 |Δ|>200% 的 2 条后均值仍为 +22.3%。
- **O 臂验证损失本身就更差**：中位 `best_valid_loss`，L=72 为 1.237（B 0.526）、
  L=168 为 1.454（B 0.521）→ 约 B 的 2.4–2.8 倍。
- 两组都训到 epoch 上限（L=168 时中位 epoch 均为 30），**早停未截断**。
- 结论：长输入配置下联合训练**真的拟合不上**，不是评估偶然。

## 与冻结版对照的结论差异

| 训练方式 | 相对同一主干的变化 |
|---|---|
| 冻结主干 + 只训空间头（`04_容量搜索结果.md`，111 组） | **−1.43%（更好）** |
| 端到端联合训练（本文件，384 组） | **+23.47%（更差）** |
| 差异 | **−24.90 个百分点** |

**判定：空间残差分支的增益依赖于“主干冻结”这一前提。**
一旦主干同步训练，空间头在长输入配置（L=72/168）下会把验证损失抬高 2–3 倍，
并使测试 RMSE 系统性劣化（最高 +53%）。

## 对论文口径的影响（必须写入）

1. 可以主张：在**冻结主干**的受控设置下，空间残差分支带来 +1.43% 的稳定机制增益。
2. **不可主张**：端到端联合训练更优；也不可把"冻结"当作实现细节隐去——它是结论成立的条件。
3. 必须并列的负面事实：
   - 同信息集多站点 GRU（21k 全可训练）：我们平均差 2.8%；
   - 同可训练预算单站点 GRU：验证集口径差 1.38%、测试集口径差 3.44%；
   - 端到端同主干：平均差 23.47%（长输入最重）。
4. 未探索项（后续若要做必须重新预注册）：空间头单独使用更低学习率、
   head-only warmup 后再解冻、或对长输入配置单独调 α 上限。
   本轮统一使用 lr=1e-3、无 warmup，因此负结果的边界是"**按本配置**"。
