# 主代理机制与先例核验

所有访问日期：2026-09-09。区分原文结论、本项目推论及尚未核实的线索。

## A. 训练期特权未来监督

机制设想：教师在训练时看中间未来状态或未来辅助变量，学生部署时仅看历史。这在按时间切分、所有教师训练与特权值均不越训练边界的前提下可以合法，不自动是泄漏。

最强近邻是Karlsson等的LuPTS（AISTATS2022）：

- https://proceedings.mlr.press/v151/k-a-karlsson22a.html
- 全文：https://arxiv.org/html/2110.14993
- 官方代码：https://github.com/RickardKarl/LearningUsingPrivilegedTimeSeries
- GitHub license API核实MIT；LICENSE blob=e879851e594c13c782a7faf5ea33584aff3658b7。

原文算法不是泛泛教师学生：分别估计中间状态转移矩阵，再复合为只依赖起始状态的终点预测器。Gaussian-linear、Markov等条件下用Rao–Blackwell论证估计方差降低；§3.1的明确证明还采用各步各向同性噪声条件。不能直接把证明外推相关滑窗、非线性PatchTST或未知污染生成过程。

原文§4.3已经做PM2.5空气质量预测，比较Distill-Seq与Distill-Concat；6h示例改善、24h示例退化，指出误设偏差可能随递推累积。因而“把未来中间态用于PM2.5训练”本身不构成本项目新机制。

TimeKD（arXiv:2505.02138，2025年5月）：

- 全文：https://arxiv.org/html/2505.02138
- 使用包含真实未来的prompt训练校准语言模型教师，再蒸馏相关性和特征到历史输入的学生。
- 此次未核实官方仓库许可证，不导入代码、不下载教师模型。
- 论文的“first systematic”措辞不能替代与2022 LuPTS的具体范围比较；本项目不照搬这个优先权声称。

### 一个必须先排除的代数退化

令X是学生的线性设计矩阵，Z是教师设计矩阵，且col(X)包含于col(Z)。若同一批样本上教师用无正则OLS得到拟合值T=P_Z Y，则

`Xᵀ(T−Y)=0`。

学生优化`λ||Y−Xβ||²+(1−λ)||T−Xβ||²`，其正规方程与直接拟合Y相同。因此可识别的学生拟合值不会因这类蒸馏改变。

这只是同样本、嵌套线性设计、OLS、平方损失的条件命题；不否定交叉拟合、正则化、非线性表示或LuPTS的非嵌套状态复合。它说明普通“加一个看更多输入的老师”需要核验真正的估计改变，不能把老师训练误差更低当成学生必然增益。

## B. 训练期跨站共享监督

子代理CWSTS候选：在中心任务之外，对训练期其他站的历史→未来任务使用同一个时间编码器，推理不新增邻站模块。

合法且可能有收益，但最直接近邻不是只有DeepAR，更包括PatchTST本身：

- PatchTST，ICLR2023：https://arxiv.org/abs/2211.14730
- https://github.com/yuqinie98/PatchTST ，Apache-2.0（此前已核实官方LICENSE）。
- 其channel-independence明确共享embedding与Transformer；将各站单变量序列作为同任务训练样本，是global/shared forecasting的直接实例。
- DeepAR：https://arxiv.org/abs/1704.04110 ，同样从related series共享估计。本轮未复核实现许可证；不能把自回归改为direct head当唯一创新差异。

故当前CWSTS应首先视为强训练基线，而不是已经放行的第二创新。它可能有经验价值，不能因归入现有函数族就否定；但当前给定的目标函数就是现成共享监督，尚无新的样本选择、估计约束或可归因机制。

若试图增加相关聚类/梯度权重来补差异，还须对照MTLinear（AISTATS2025）：

https://proceedings.mlr.press/v258/nochumsohn25a.html

本轮核对出版方摘要：已将变量分组视为任务、按相关性聚类、分析梯度角度并按预测误差缩放梯度。未核对完整源码/许可证，不冒称全面覆盖所有梯度方法，但不能再把普通相关分组和损失平衡当空白。

## C. 条件Student-t及相关误差

子代理CTRE是固定ν的Student-t位置/尺度头，以NLL训练、部署取位置参数。它是有价值的概率回归对照，但当前还没有区别于现成分布头的估计机制。

关键风险：一般分布下Student-t位置参数不是自动等于条件均值；减少大残差权重可能改善稳健性，却不保证RMSE或高污染峰值表现。只有在正确指定且ν>1等条件下，位置才对应分布均值。NLL/覆盖改善不能冒称点精度改善。

后续若加跨站/跨步协方差，也不能忽略已有工作：

- High-Dimensional Multivariate Forecasting with Low-Rank Gaussian Copula Processes，NeurIPS2019：https://arxiv.org/abs/1910.03002
- Multivariate Probabilistic Time Series Forecasting with Correlated Errors，2024预印本：https://arxiv.org/abs/2402.01000

前者本轮作为检索线索，后者核对摘要，未深审源码或许可证，不据此宣布覆盖一切新协方差估计。这里只排除“加低秩协方差就天然新颖”的快捷推论。
