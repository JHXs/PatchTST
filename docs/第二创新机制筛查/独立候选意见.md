# 第二创新机制筛查：独立候选意见

筛查日期：2026-09-09。本文只作理论筛查，不声称完成独立性能验证；未训练、未读取原始站点 CSV、checkpoint 或封存结果。第一创新固定为 Top-5 与站点偏置的空间输出残差。频域、VMD、滤波、分解、多尺度换名，以及 MC-CVLRA、HS-DFES、RES-Peak、OARR、patch 偏移均排除。

## 结论

最值得进入下一轮理论放行的是“因果窗口跨站共享监督”（CWSTS）。它把多站 PM2.5 的标签当作训练期额外监督，而不是再造一个邻站门：对训练区每个站点、每个内部预测起点，用同一中心时间编码器预测该站未来 1/6 小时；与中心站主任务联合优化，推理时删除辅助头，只保留原有锁定 ST 输出。形式上可固定为

`L = L_center + 0.1 * mean_s,t MSE(g(X_s[t-L:t-1]), Y_s[t:t+H-1])`。

辅助起点先按时间切分，只取训练段，标签是已观测的真实 PM2.5；不生成未来状态，不用未来辅助变量，不建教师，也不做预训练拼装。收益假设是：8760 小时的多站点共享时间参数可降低中心站在突变与长历史任务上的估计方差；若只是“多做了几步优化”，则不算机制。

最强近邻是 LuPTS：Karlsson 等在 AISTATS 2022 直接用预测区间内的连续状态转移，再复合得到终点预测，并在空气质量任务验证 Gaussian-linear 条件下的 Rao–Blackwell 方差收益（[原文](https://arxiv.org/html/2110.14993)，访问于 2026-09-09）。TimeKD 又以真实未来 prompt 训练教师，再作相关性/特征蒸馏（[原文](https://arxiv.org/abs/2505.02138)，访问于 2026-09-09）。因此“预测未来中间态”“未来辅助变量蒸馏”不能包装成新点。CWSTS 的差异在于只用训练区已经存在的同任务未来标签作联合窗口监督，推理没有额外信息，目标是共享时间估计而非连续状态转移或教师逼近。最强方法近邻是 DeepAR 的 related-series global sharing，但其为自回归概率模型；CWSTS 保持当前直接多步点预测接口（[原文](https://arxiv.org/abs/1704.04110)，访问于 2026-09-09）。

最低强对照为：退化 PatchTST、锁定第一创新、锁定第一创新加中心站重复窗口（匹配样本数但不增加站点多样性）、以及加全部站点共享监督。保持同一 split、种子、更新步数、初始化和早停，主看 168→6 RMSE，24→1 作支持性任务并报告各 horizon。只有全部站点共享胜中心重复，才支持“跨站共享监督”；若两任务任一主指标无稳定改善，或中心重复已同等收益，即止损，不加身份头、teacher、蒸馏或新空间结构。辅助窗口越过验证/测试边界也立即失败。

## 备用候选：条件 Student-t 估计器（CTRE）

若 CWSTS 的增益不能归因于跨站共享，可只筛查一种不同估计机制：保持中心时间输入和第一创新结构不变，输出每个预测步的 `μ_h` 与 `σ_h=softplus(a_h)+ε`，固定自由度 `ν=4`，以 Student-t 条件负对数似然训练；推理仍返回 `μ_h`，不增加空间门。PM2.5 污染事件可能存在重尾和条件异方差，似然估计或许能减少极端样本对点估计的过度牵引，同时提供不确定性；但这只是可证伪的统计估计假设，不等于已知分布事实。DeepAR 证明由网络直接估计条件分布参数、并在 related series 上共享学习是可行的，但其点/概率目标与本项目不同；Ti-MAE 的随机遮挡重建也说明时间序列辅助任务可改善表示，但完整方案偏预训练，因此只作为 CWSTS 的方法邻近参照，不能直接照搬（[Ti-MAE 原文](https://arxiv.org/abs/2301.08871)，访问于 2026-09-09）。

CTRE 的最低对照是同参数量 Gaussian NLL、原 MSE 头和固定 Huber；固定 `ν`，不扫描分布族。报告 RMSE、MAE、NLL 与区间覆盖，点预测只取 `μ`。若 NLL/覆盖改善而 RMSE 不优于 MSE 头，CTRE 只能作不确定性附加结果；若需调 ν、改损失或借未来真实值挽救，立即止损。

综合排序：CWSTS 为唯一建议先做理论协议的候选，CTRE 仅作低成本备用；两者都不是独立性能结论。进入实验分支前仍须重新冻结无泄漏时间划分、训练期站点使用范围、参数/更新预算、主指标和新确认资源。

## 本轮能力使用审计

已使用：研究探索工作流、学术检索规范、当前模型接口与理论分支 Markdown；联网核验 4 篇一手论文。未使用：原始 CSV、模型 checkpoint、封存结果和任何性能指标。产物仅为本文件；验证命令为 `git diff --check` 与 Markdown 字数/结构检查。剩余风险是 CWSTS 的增益可能只是共享参数或额外梯度带来的正则化，CTRE 可能只改善校准而不改善点误差；二者均待独立消融否证。

## 对主代理复核的回应

CWSTS 应降级为强基线。PatchTST 已在多条单变量序列间共享 embedding/Transformer；再把多站窗口放进同一目标，至多是 global training 的样本组织变化，direct head 也不足以形成算法差异。若作对照，必须分开记录“第一创新结构固定”和“第一创新权重冻结”：前者允许主干更新但不改空间模块，后者才要求参数与缓冲状态不变，不能混称锁定主干。CWSTS 没有超出 global sharing 的可归因估计约束，故不放行。

CTRE 同样降级为现成概率回归基线。固定自由度的 Student-t NLL 只是常见 likelihood head，不能因仓库未实现而称创新；最多检验重尾假设、点误差与校准的权衡。除非另有明确、独立且可否证的估计约束，本轮不保留第二创新候选，也不再凑名字。
