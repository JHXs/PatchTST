# 学位论文章节重构方案（六章版）

## 一、组织原则与论文定位

本方案面向现稿《基于时空特征融合的 Transformer 架构空气质量预测模型研究》，采用六章结构，不设置尚未实现的预测系统章节。

**主线：问题与理论 → 空间融合模型 → 频域残差扩展 → 统一预测评价 → 总结。**

采用“方法与实验分章”，但不机械禁止方法章出现数据：

- 第三、四章负责方法构造、数学表示、训练流程，以及必要的构造示例和模块性质验证。
- 第五章统一报告预测性能、组件消融、基线比较、任务覆盖与跨城市目标域有效性。
- 分解图、重构误差和频率分辨率分析不等于预测有效性证据；不在方法章预先宣称性能改善。
- 第一项核心贡献是受控的稀疏邻站预测端修正机制；频域是第二项研究工作/扩展研究，不是已经成立的第二创新。
- 跨城市验证是固定结构的外部有效性证据，不是新增机制，也不自动等于零样本迁移。
- 章节数与创新点数不一一对应。第四章允许篇幅少于第三章，不为凑页数重复理论或虚构实验。

### 参考论文及借鉴边界

参考：`GUET_Thesis_LaTeX/Chapters/template/蔡 - 基于变分模态分解和图神经网络的空气质量预测模型研究.pdf`。

其第三章（正文第29–38页）包含 VMD 分解器构建、分解尺度与惩罚因子选择、其他站点的分解效果验证；第五章集中报告预测结果、消融、模型对比和泛化。可以借鉴“模块构造与分析先行、预测效果统一评价”的逻辑。

本文使用固定频带 rFFT，不使用 VMD，因此不照搬其模态数搜索、包络熵选择或惩罚因子实验，也不将分解平稳性或图形清晰度当作预测收益证明。
