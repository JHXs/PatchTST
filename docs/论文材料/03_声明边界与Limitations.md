## C. 必须说（披露义务）

1. **信息集差异**：基线 = 中心站单站点；我们的模型 = 中心站 + 邻站（18 站）。所有比较表必须标注。
2. **双口径**：验证集口径与测试集口径（上界）两组数字同时给出（A8）。
3. **选择规则**：说明 top-5 由验证集选择（2024–2026 段），最终确认使用 5 个新种子。
4. **失败记录**：`02_失败方向一览.md` 的内容必须至少以"我们尝试并否证了 N 条替代机制"的形式出现。
5. **冻结前提**：方法部分必须明确说明主干冻结是设计的一部分（§3.2 的 Scope statement）。
6. **不可复活清单**：若引用任何被 STOP 的机制（如频域、注入位置），必须同时说明其对照实验结论。
