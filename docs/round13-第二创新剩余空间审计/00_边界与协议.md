## 3. 约束清单（审计必须逐条检查）

**信息与估计量**

1. 第二创新必须是中心站自身的时间建模或不同估计机制；不得新增第二套空间门。
2. 测试期信息集与 BASE 相同（只含中心站与已固定 Top-5 邻站的历史 PM2.5），除非显式声明并重做整条对照链。
3. 评价 estimand 是观测 PM2.5 的物理尺度条件均值；改变 estimand 的机制不可用。
4. 任何先验、阈值、协方差、teacher、辅助标签只能拟合训练时间；多步标签不得跨界；禁止 `bfill`。
5. 无法从观测识别的结构假设（测量误差、共享偏差、潜在状态）按不可识别处理，除非提供 replicate/reference/instrument。

**架构与训练**

6. 第一创新结构固定；`--freeze-backbone` 冻结 `patch_tst` 全部参数，可训练容量只剩预测端加性残差槽位（`ST_PatchTST_model.py:400`）。
7. 若新机制进入该槽位，必须与空间分支构成完整 2×2 并预注册交互项检验；否则空间收益会被误记。
8. “结构固定”不等于参数/buffer 冻结：允许重训主干，但必须同时重训 BASE 并保持数据、种子、主干、优化器、epoch/patience、best-valid 选择规则完全一致。
9. 参数量、监督信号数、输出非负性等混淆项必须有匹配对照臂。

**统计门**

10. H=1 与 H=6 都必须非退化；不得依赖跨 lead 结构或以 H=6 覆盖 H=1。
11. 主指标物理尺度 RMSE；需 5 新种子、方向一致、单侧精确符号检验、预注册平均配对降幅门，并留出未参与选择的确认资源。
12. 已有近邻不自动否决，但与最强同信息集现成算法完全同构时只能降级为基线。
