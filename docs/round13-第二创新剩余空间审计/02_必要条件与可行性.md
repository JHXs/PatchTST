# Round 13 第二创新：必要条件与可行性

## 1. 推导边界与记号

本文只使用 `00_边界与协议.md` 给出的信息和约束，不使用机制清单、数据文件、checkpoint 或旧结果。因此，下文给出的是候选存活的必要条件，不是对任何具体候选有效性的充分证明。

记预测时点为 \(t\)，预测步为 \(h\)，\(Y_{t+h}\) 为物理尺度观测 PM2.5。\(\mathcal I_t\) 是 BASE 在测试时可用的信息所生成的 \(\sigma\)-代数，即中心站和已固定 Top-5 邻站截至 \(t\) 的历史 PM2.5。目标函数为

\[
m_h(\mathcal I_t)=\mathbb E[Y_{t+h}\mid\mathcal I_t].
\]

记 \(S\in\{0,1\}\) 为固定第一创新空间分支的关/开，\(M\in\{0,1\}\) 为第二创新的关/开，\(R_{sm}^{(h)}\) 为对应实验臂的总体 RMSE 风险。训练集、验证/选择集和确认资源分别记为 \(T,V,C\)。

## 2. 必要条件

### NC1：观测分布下的识别性

精确陈述：候选所依赖的关键量必须是协议观测分布 \(P(Y,\mathcal I)\) 的泛函。若存在两个潜在过程 \(P_1,P_2\)，它们对所有可观测量诱导出相同分布，却要求不同的校正方向、潜状态或误差分解，则该量不可识别。测量误差、共享偏差和潜状态只能在引入 replicate、reference 或 instrument 后重新审查。

可否证判据：为候选写出其预测决策依赖的全部结构量；只要能构造上述 \(P_1,P_2\) 观测等价反例，且协议中没有额外识别资源，候选即被否证。

失败示例：将单次观测分解为“真实污染+传感器偏差”，并根据无法独立识别的偏差进行预测校正。

### NC2：测试信息集同一且无时间泄漏

精确陈述：候选预测 \(\hat y_{t+h}\) 必须对 \(\mathcal I_t\) 可测。所有先验、阈值、协方差、teacher、辅助标签和数据驱动结构选择只能由 \(T\) 拟合；任何窗口和多步标签都不得跨越划分边界，不得使用 `bfill`。

可否证判据：对每个输入、buffer 和拟合统计标注“数据来源和最晚时间戳”。任一量不能证明属于 \(T\) 或 \(\mathcal I_t\)，或候选比 BASE 多使用一个测试时变量，即失败。

失败示例：用全序列选阈值，用 \(t+1\) 之后的值回填 \(t\) 时刻缺失，或在候选中加入 BASE 不可见的气象/日历/额外站点信息。

### NC3：estimand 与输出约束一致

精确陈述：候选优化和输出的对象必须仍是 \(m_h(\mathcal I_t)\)，不得换成分位数、分布尺度、潜在真值或另一个转换尺度上的条件均值。若候选新增非负截断、链接函数或重转换，对照臂必须使用相同操作。

可否证判据：将候选损失的人口最优解写成函数形式。若该最优解不是 \(m_h\)，或候选独占一个会改变 RMSE 的输出投影，则失败。

失败示例：直接对 \(\log Y\) 做平方损失再指数反变换，却将结果当作原尺度条件均值；或只对候选输出做非负截断。

### NC4：创新作用域合规且不与现成基线同构

精确陈述：第二创新必须作用于中心站自身的时间建模，或构成一个真正不同的估计机制；它不得实质上成为第二套邻站选择、加权或空间门。若其估计方程与最强同信息集现成算法在变量重命名或重参数化后完全相同，它只能作为基线。

可否证判据：展开候选与最近现成基线的估计方程、状态更新和预测映射。若候选的唯一新自由度是邻站权重，或存在一一参数映射使两者对任意样本给出相同预测，即失败。

失败示例：在已固定 Top-5 上另学一组动态站点门；或将标准递归最小二乘换一组符号后声称为新估计器。

### NC5：H=1 与 H=6 都必须结构性非退化

精确陈述：候选在 \(H=1\) 和 \(H=6\) 上都必须有可识别、可训练且可独立开关的作用路径。对 \(H=1\)，不得使用跨 lead 关系作为唯一新约束；在一个步长上删除其他 lead 后，候选假设类仍必须可以在正测度的输入集上与 BASE 不同。

可否证判据：对候选做 \(H=1\) 符号化简。若新项恒等于零、恒等变换、只剩一个无约束标量缩放，或无法从 \(H=1\) 标签估计，则失败。\(H=6\) 同样必须有非零、可估计作用，不能只把 \(H=1\) 效果复制六次作为多步机制证据。

失败示例：只学习 lead-to-lead 协方差或轨迹平滑惩罚；当 \(H=1\) 时该矩阵降为 \(1\times1\)，新结构消失。

### NC6：加性槽位中的可归因性与完整 2×2

精确陈述：当预测写成 \(\hat y=b+r_S+r_M\) 时，单看联合输出无法识别两个残差的语义，因为 \((r_S+c,r_M-c)\) 给出相同预测。候选必须允许 \(S\) 和 \(M\) 独立开关，并以同一协议运行 \((0,0),(1,0),(0,1),(1,1)\) 四臂。对每个任务预注册

\[
B_{M\mid S}^{(h)}=R_{10}^{(h)}-R_{11}^{(h)},\quad
B_{M\mid \neg S}^{(h)}=R_{00}^{(h)}-R_{01}^{(h)},
\]

以及交互项

\[
I_{SM}^{(h)}=B_{M\mid S}^{(h)}-B_{M\mid \neg S}^{(h)}.
\]

第二创新的主张必须由 \(B_{M\mid S}^{(h)}\) 支撑，不得用 \(R_{00}-R_{11}\) 把空间收益重复记入。\(I_{SM}\) 用于限定“独立叠加”还是“依赖第一创新的交互收益”，不要求交互必然为零。

可否证判据：若任一分支不能在不改变其他部分的情况下关闭，四臂无法在匹配协议下构造，或主张没有事先指定 \(B_{M\mid S}\) 和 \(I_{SM}\) 的判定方式，即失败。

失败示例：在现有预测端残差上再接一个校正头，只比较“BASE”与“空间+校正”两臂。

### NC7：除待测机制外的训练链同一

精确陈述：四臂及容量对照必须使用相同数据划分、种子、主干、优化器、epoch/patience 和 best-valid 选择规则。若重训主干，BASE 也必须重训；若冻结主干，必须核对所有 parameter 与 buffer 的状态，而不能以“结构未改”代替冻结证明。

可否证判据：对每臂生成训练协议指纹和可训练 parameter/buffer 清单。除预注册的机制差异外，指纹或状态更新集不同即失败。

失败示例：候选重训 PatchTST，却将已有冻结权重的 BASE 作为对照；或候选独占更长 patience。

### NC8：参数量、有效监督数与输出处理匹配

精确陈述：比较必须分离“机制归纳偏置”和“更多容量/更多标签/更有利输出处理”。记 \(p_{\mathrm{eff}}\) 为可训练的有效自由度，\(n_{\mathrm{eff}}\) 为考虑时间相关和重叠窗口后的有效监督数。候选与主对照应匹配 \(p_{\mathrm{eff}}\)、每个训练时点可见的标签数、损失项数以及非负投影/链接函数。无法精确等参数时，必须增加同量无结构容量对照，且候选必须同时胜过它。

可否证判据：报告每臂的 \(p_{\mathrm{eff}},n_{\mathrm{eff}}\)、目标张量数和输出操作。任一不匹配且无对应安慰剂对照，或增益也被同容量对照复现，机制主张即失败。

失败示例：为候选增加一个大型 MLP 和六个 lead 辅助损失，却用小型单头 BASE 作对照；或只对候选输出做 `clamp(min=0)`。

### NC9：训练拟合窗口内可估性

精确陈述：每个会影响预测的参数、阈值、状态和协方差都必须仅凭 \(T\) 可估。对局部参数化，训练窗内的设计/Jacobian 必须满列秩；对非线性或事件型参数，必须事先定义有效样本数、最小事件数、条件数/最小特征值与分块稳定性阈值。重叠滑窗数不得冒充独立监督数。

可否证判据：在不查看 \(C\) 的前提下，用 \(T\) 计算预注册的秩、条件性、事件计数和时间分块稳定性。任一阈值不达标，或阈值未在检查前锁定，则候选不得进入正式实验。

失败示例：为极少数污染峰值学习一组事件状态转移，其自由参数数量接近或超过训练窗内的独立事件数。

### NC10：确认资源与所有选择行为独立

精确陈述：候选结构、超参数、阈值、停止规则、主张和平均配对降幅门必须在打开 \(C\) 前冻结。\(C\) 不得与理论筛选、L0、消融、超参数选择或任何早期查看共享种子/时段。每个任务使用 5 个新种子，主指标为物理尺度 RMSE；无 tie 时 5/5 方向一致的单侧精确符号检验 \(p=2^{-5}=0.03125\)，并且还须达到预注册的平均配对 RMSE 降幅门。tie 的处理必须事先规定。

可否证判据：对确认资源建立使用账本和冻结的 commit/协议指纹。任一确认结果被用于修改模型或门限，该批 \(C\) 立即失去确认资格；任一任务未达 5/5 或平均收益门，严格放行即失败。

失败示例：查看五个确认种子后调整正则强度，再在同五个种子上报告 5/5。

### NC11：可证伪的 L0 正 DGP

精确陈述：每个候选必须给出一个完全可生成的正对照 DGP \(D^+\)，其信息集、estimand、样本规模和噪声量级与协议兼容，且只激活该候选声称的结构。运行 fixture 前必须预注册 \(H=1,H=6\) 各自的最小正收益 \(\gamma_h>0\)、重复次数、随机种子、统计量和接受域 \(A_h^+\)。在匹配 2×2 与容量对照下，必须有

\[
\mathbb E_{D^+}[R_{10}^{(h)}-R_{11}^{(h)}]\ge \gamma_h,
\]

且同容量安慰剂不得复现该收益。

可否证判据：未给出可执行 DGP、\(\gamma_h\) 或接受域，视为不可证伪而失败；任一 horizon 的预注册统计量不落入 \(A_h^+\)，或收益同样出现在容量对照中，L0 正对照失败。

失败示例：声称某门能识别中心站的时变统计，却无法构造一个该统计已知存在、H=1 也会改变条件均值的 DGP，或在该 DGP 上不能胜过等参数 MLP。

### NC12：可证伪的 L0 负 DGP

精确陈述：每个 \(D^+\) 必须配对一个负对照 DGP \(D^-\)，它保留信息集、边缘分布、样本规模和噪声难度，但删除候选声称的唯一结构信号。运行前必须预注册可容忍虚假收益 \(\varepsilon_h\)、机制输出幅度上限 \(\eta_h\) 和接受域 \(A_h^-\)。候选在 \(D^-\) 上不得显示超过 \(\varepsilon_h\) 的稳定收益，其新分支应收缩到预注册的 \(\eta_h\) 内。

可否证判据：若 \(D^-\) 同时改变了噪声难度或其他预测信号，它不是有效负对照；若候选在有效 \(D^-\) 上仍稳定超过 \(\varepsilon_h\)，或分支不收缩，则“特定机制”解释失败。

失败示例：将正 DGP 中的时变信号打乱后，候选仍在各种子上稳定胜出，而它的残差幅度不下降；这更支持“增加容量”而非所声称的机制。

## 3. 被必要条件整体排除的候选族

下列“整体排除”针对候选族的定义性特征，而非某个可经实质重构后已属于另一家族的版本。

| 当前形态下被整体排除的家族 | 直接触发的必要条件 |
|---|---|
| 新增邻站门、站点重选、动态邻站加权或第二空间残差 | NC4；其创新定义已越过“非第二套空间门”边界 |
| 依赖新站点、气象、日历、未来值或全序列统计的家族 | NC2；测试信息集不同或存在泄漏 |
| 将目标改为分位数、概率分布、潜在真值或未校正转换均值的家族 | NC3；改变 estimand |
| 无 replicate/reference/instrument 的测量误差分解、共享偏差或潜状态家族 | NC1；关键量不可由观测分布识别 |
| 只依赖跨 lead 协方差、低秩或轨迹一致性的家族 | NC5；在 H=1 恒等退化 |
| 与空间残差共用加性槽位、却不能独立开关或完成 2×2 的校准/残差家族 | NC6；收益不可归因 |
| 本质增加参数、辅助标签或输出截断，又拒绝匹配对照的家族 | NC8；机制效应与混淆项不可分离 |
| 需要的独立事件数、状态覆盖或矩阵秩超出训练拟合窗口能力的家族 | NC9；参数无法在允许时段内估计 |
| 需要查看确认种子/时段才能定结构或阈值的家族 | NC10；确认资源已参与选择 |
| 与最强同信息集现成估计器完全同构的家族 | NC4；只能作为基线，不能作为创新 |
| 无法给出成对正/负 DGP 及事前数值接受域的纯经验扩容家族 | NC11–NC12；机制故事不可证伪 |

## 4. 当前协议内是否存在解

定义协议内的可行域

\[
\mathcal F=\bigcap_{i=1}^{12}\{M:M\text{ 满足 NC}i\}.
\]

仅从逻辑约束看，\(\mathcal F\) 未被证明为空：“只使用同一信息集、作用于中心站时间表示或不同估计原理、H=1/H=6 均非退化、可在训练窗估计、可独立开关”的抽象候选并不自相矛盾。这只证明协议有形式上的剩余空间，不证明存在能通过 L0 和真实数据门的具体候选。

“当前协议内存在解”的初步判据应为：至少能构造一个具体 \(M\in\mathcal F\)，对它完成估计方程的非同构证明、H=1/H=6 符号非退化检查、训练窗可估性设计、匹配 2×2 和容量对照设计，并预注册能同时通过的 \(D^+,D^-\) 接受域。任一项只能在查看确认资源后完成，均不算存在解。

## 5. GO / PIVOT / STOP 准入条件

### GO：进入消融，不等于已确认

GO 只在以下条件同时成立时准入：已固定不超过 1–2 个具体候选；每个候选逐条通过 NC1–NC10；估计方程已证明不与最强现成基线同构；H=1 和 H=6 均通过符号非退化；成对 \(D^+,D^-\) 及数值接受域已预注册并通过；2×2、交互项、容量/监督对照和尚未使用的确认资源已锁定。GO 的含义是“有资格进入真实数据消融”，不是“第二创新成立”。

### PIVOT：有明确的最小放宽可恢复可行性

PIVOT 只在当前 \(\mathcal F\) 无具体存活候选，但能指定一条最小放宽时准入。放宽必须能使某个已写明的候选通过其余所有 NC，并同时报告代价：放宽信息集需在新城市/新站点/新目标变量上重做整条 BASE—消融—确认链；引入 replicate/reference/instrument 需要新数据与新识别假设；改变 estimand 会改变论文问题和全部指标；解冻或重训主干则必须同步重训 BASE，并重建公平性证据。不得以“多试几个种子”或“降低收益门”作为 pivot。

### STOP：当前协议内停止搜索

STOP 在下列任一情形成立时准入：对当前允许机制空间完成互斥且穷尽的分类后，每类都违反至少一条 NC；所有通过 NC1–NC10 的具体候选均未通过预注册 L0 正/负 DGP；或唯一剩余方向需要不可识别假设、测试额外信息、改变 estimand 或污染确认资源，而项目又不接受相应 pivot 代价。STOP 只否定“当前协议下继续寻找第二创新”，不否定更换城市、中心站、目标变量或识别资源后的新问题。

## 6. 本轮初步判定

根据必要条件本身，当前结论是“形式可行域未证空，但尚无足够信息准入 GO”。这一判定不能直接升格为 PIVOT 或 STOP：PIVOT 需要一个只被特定边界阻断的具体候选，STOP 需要对允许机制空间的穷尽性排除或对全部存活候选的 L0 否证。后续合并审计只有在提供具体候选并逐条通过 NC1–NC12 后才能给出 GO；否则应依上述准入条件选择 PIVOT 或 STOP。
