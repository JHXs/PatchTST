# 低门槛投稿档：可报告结果清单

日期：2026-09-15。依据：工作流 §2.4「两种验收档位」。本清单回答一个问题——**按低门槛投稿档，之前被严格档否掉的方向里，哪些现在可以写进论文**。

原则：本清单只做"分类与表述建议"，不改动任何已记录的数字与结论；所有数字均可在对应分支的文档与产物中复核。

## 1. 两类可分的东西

| 类型 | 判据 | 论文里怎么写 |
|---|---|---|
| **可报告的增益** | 平均配对改善 > 0 且 ≥2/3 种子同向（低门槛档） | "我们额外测试了 X，它在 A 任务上带来 Y% 的 RMSE 改善"，并**并列**给出等容量/强对照的结果 |
| **只能作负结果** | 相对同信息集基线平均为负，或机制未通过同构审查 | 放进"负结果与消融"一节，或只作内部记录 |

**推荐写法**（对低门槛期刊/会议）：

> 在固定的空间结构之上，我们额外评估了若干增强模块：因果多尺度频域残差在 24→1 上带来 +0.35% 的 RMSE 改善（但未超过等容量时域控制）、日历收缩先验在 168→6 上带来 +2.70% 改善（去掉日历项后相对基线恶化为 −0.31%）、跨变量滞后适配在 24→1 上带来 +0.84% 改善。这些模块的增益幅度有限且部分可归因于容量，故本文不把它们作为独立的方法创新。

这样写的两个好处：**数字真实**（可直接复核）、**归因诚实**（同时给出对照），因此低门槛刊物能收，也不会因为夸大被审稿人反打。

## 4. 按低门槛档的论文结构建议

1. **贡献一（主）**：固定空间结构（Top-5 门控＋站点身份偏置＋退化初始化＋冻结主干），北京 1013，24→1 **+3.1188%**、168→6 **+0.8220%**（5 种子、预注册门、位级可复现）。
2. **贡献二（泛化）**：跨城市泛化确认，广州 8 个未消费中心站，24→1 **+2.2072%**、168→6 **+1.8224%**（40/40 与 37/40 配对、8/8 站、5/5 块）。
3. **贡献三（增强模块与消融，低门槛档新增）**：上述可报告增益 + 匹配组件消融（含"注入位置随训练制度翻转"的发现）+ 邻站干预消融（打乱邻站使 24→1 RMSE 上升 9.41%）。
4. **附录/负结果**：16 条方向的止损理由与数字（体现研究过程的严谨性，也是低门槛刊物少见的加分项）。

## 5. 使用注意

- 本清单放行的是**报告口径**，不是**创新归因**：第 2 节任何一条都不得在论文中称为"新机制/新方法"。
- 若某条要升级为"方法创新"（例如频域增强），仍然需要过严格档：胜过等容量特异性门（NC13）。当前它没过。
- 若论文投低门槛期刊/会议，建议在 Limitation 中说明：北京协议使用完整序列筛站与 `bfill`（存在前视），广州协议为无泄漏版本；探索性结果为 3 种子、未做显著性检验。
