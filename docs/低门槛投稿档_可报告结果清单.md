# 低门槛投稿档：可报告结果清单

日期：2026-09-15。依据：工作流 §2.4「两种验收档位」。本清单回答一个问题——**按低门槛投稿档，之前被严格档否掉的方向里，哪些现在可以写进论文**。

原则：本清单只做"分类与表述建议"，不改动任何已记录的数字与结论；所有数字均可在对应分支的文档与产物中复核。

## 1. 两类可分的东西

| 类型 | 判据 | 论文里怎么写 |
|---|---|---|
| **可报告的增益** | 平均配对改善 > 0 且 ≥2/3 种子同向（低门槛档） | "我们额外测试了 X，它在 A 任务上带来 Y% 的 RMSE 改善"，并**并列**给出等容量/强对照的结果 |
| **只能作负结果** | 相对同信息集基线平均为负，或机制未通过同构审查 | 放进"负结果与消融"一节，或只作内部记录 |

## 2. 逐条核对"基线是什么、能不能算在冻结 ST 之上"

**关键区分**：论文里说"X 在 ST 基础上提升 Y%"，必须满足两条——(i) 同一信息集；(ii) 对照基线与当前冻结 ST 结构一致且划分/种子可比。逐条核对如下。

| 方向 | 基线 | 是否叠加在冻结 ST 上 | 信息集 | 划分与种子 | 实测 | 结论 |
|---|---|---|---|---|---|---|
| 频域：固定 rFFT | `locked_st_prediction + frequency_residual`（叠加在同一冻结 ST 检查点上） | **是**（但基线是**干净管线**上重训的 `locked_st_clean`，与 2047–2051 确认非同一条线） | 相同 | **验证划分**，**3 种子（2052–2054）** | 相对锁定 ST **+0.3502%**（3/3）；**等容量时域适配器为 +0.7498%** | 可作附带实验，须说明：(i) 基线来自无泄漏 P0 管线；(ii) 容量匹配的时域适配器收益更大；(iii) 划分/种子与主确认不同 |
| 频域：因果局部滤波器组 | 同上 | **是**（同上管线说明） | 相同 | 同上 | 相对锁定 ST **+0.2666%**（3/3）；平均 RMSE 50.1954 劣于控制 49.9519 | 更弱，建议只作附录 |
| 频域：容量匹配的时域适配器 | 同一冻结 ST 检查点 | 是 | 相同 | 同上 | 相对锁定 ST **+0.7498%** | 该臂**不是创新**，而是用来证明频域增益来自容量的对照；论文中必须与频域臂并列 |
| 日历收缩先验 CCSPRF | 合成 DGP 的 BASE | **否** | 合成 | 合成（30 种子 `20260939–20260968`） | 合成 168→6 +2.7037%（30/30） | **不得写成真实数据提升**；只能作合成机制研究放附录 |
| 跨变量滞后 MC-CVLRA | 锁定 ST（F10） | 是 | **不同**（引入其他污染物） | train+validation，3 种子（2060–2062） | 24→1 对 F10 +0.8411%；168→6 对 F10 +0.4774% | 增益来自**新增变量**；对同输入普通适配器 B-flat **0/3、−0.1610%**（更差）→ 不能算结构增益 |
| 匹配组件消融的注入位置发现 | 同 run 退化基线 | — | 相同 | test 划分，3 种子（2024–2026） | 冻结协议 168→6：输入端 +2.25% vs 预测端 +0.46% | **描述性消融发现**，可写进消融节 |

**因此：按低门槛档真正能写进论文的，只有"频域增强"这一条附带实验**（+0.35%，验证划分、3 种子），且必须同时报告等容量控制更好这一事实。其余两条要么是合成结果、要么是新增变量带来的收益。

补充说明（频域实验与主确认的四点条件差异）：数据管线（无泄漏 P0 桥 vs 旧协议的全序列筛站与 `bfill`）、种子（2052–2054 vs 2047–2051）、评估划分（验证 vs 测试）、主门设计（168→6 为主 vs 两任务并重）。因此频域结果**不得**写成"在确认结果之上再加 0.35%"。

推荐写法：

> 在固定空间结构之上，我们额外评估了因果多尺度频域残差：在 168→6 验证划分上相对同管线的锁定 ST 带来 +0.35% 的 RMSE 改善（3 个种子方向一致）；作为对照，容量匹配的时域适配器带来 +0.75% 的改善，说明该增益主要来源于额外容量而非频率结构。类似地，引入同站其他污染物序列可带来 +0.84% 的改善，但这属于信息集扩展，且未超过同等输入的普通适配器。以上结果均在独立于主确认的无泄漏管线上取得，划分与种子不同，故不与主确认数字合并。

## 4. 按低门槛档的论文结构建议

1. **贡献一（主）**：固定空间结构（Top-5 门控＋站点身份偏置＋退化初始化＋冻结主干），北京 1013，24→1 **+3.1188%**、168→6 **+0.8220%**（5 种子、预注册门、位级可复现）。
2. **贡献二（泛化）**：跨城市泛化确认，广州 8 个未消费中心站，24→1 **+2.2072%**、168→6 **+1.8224%**（40/40 与 37/40 配对、8/8 站、5/5 块）。
3. **贡献三（消融与附带实验，低门槛档新增）**：匹配组件消融（含"注入位置随训练制度翻转"的发现）+ 邻站干预消融（打乱邻站使 24→1 RMSE 上升 9.41%）+ 频域增强的附带实验（+0.35%，并如实报告等容量控制更优）。
4. **附录/负结果**：16 条方向的止损理由与数字（体现研究过程的严谨性，也是低门槛刊物少见的加分项）。

## 5. 使用注意

- 本清单放行的是**报告口径**，不是**创新归因**：第 2 节任何一条都不得在论文中称为"新机制/新方法"。
- **不得把合成结果写成真实数据结果**（CCSPRF），也不得把"新增输入变量"的收益写成"机制结构"的收益（MC-CVLRA）。
- 若某条要升级为"方法创新"（例如频域增强），仍然需要过严格档：胜过等容量特异性门（NC13）。当前它没过。
- 若论文投低门槛期刊/会议，建议在 Limitation 中说明：北京协议使用完整序列筛站与 `bfill`（存在前视），广州协议为无泄漏版本；探索性结果为 3 种子、未做显著性检验。
