# 最终推荐方案：MC-CVLRA

调研与修订日期：**2026-08-23**。本文件是可证伪的未来实验协议，不是模型实现、性能结论，也不表示第二创新点已经成立。

## 1. 研究问题与表述边界

**机制约束的中心站跨变量滞后残差适配器**（MC-CVLRA，Mechanism-Constrained Cross-Variable Lag Residual Adapter）研究：在锁定的 ST-PatchTST 已利用 PM2.5 自历史与邻站信息之后，中心站历史共污染物和气象状态是否仍含有变量/离散滞后特异的预测信息。

原创性只定位为：

> 面向冻结 ST-PatchTST、严格可退化、带离散滞后特异性对照与空间×适配器因子对照的空气质量残差适配方案。

它不是通用变量选择新机制。softmax 门、嵌入、MLP 和有界残差均为已有技术；其中有界残差和零初始化只是安全机制。L0、L1 和独立确认全部通过前，不得把 MC-CVLRA 写成“已成立的论文第二创新点”。

## 2. 可证伪假设

- **H1 增量信息**：完整适配器 M 应稳定优于同一锁定 ST 和 self-history 适配器 B1。
- **H2 离散滞后特异性**：M 应优于 recent-only B2；L0 的结构化滞后 ridge 也应优于自历史和 recent-only ridge。
- **H3 结构特异性**：M 应优于读取同一真实 `7×6×2` 输入、参数量匹配但没有变量/滞后结构的普通 residual MLP。
- **H4 分组可诊断性**：污染物与气象组消融可区分组级预测关联；权重不解释为因果效应。
- **H5 互补性待检验**：空间轴和中心站跨变量轴在建模对象与工程接口上区分，但可能利用重叠信息。只有预注册 2×2 因子比较才能判断组合增益和增益衰减，接口隔离本身不能证明“信息正交”。

## 3. 输入、时间与接口

### 3.1 MVP 输入

- 目标历史：中心站 `PM25_Concentration`。
- 污染物辅助变量：NO2、CO、O3、SO2。
- 气象辅助变量：temperature、按固定规则统一为 hPa 的 pressure、按固定规则清洗的 humidity。
- 中心站辅助张量 `U ∈ R^{B×7×L}`，固定变量顺序见[数据语义代理签字](05_数据语义审计与代理签字.md)。
- PM10 因北京 1341 h 的 `1000` 长平台全局排除；wind_speed 因仓库无单位字典且跨城量化模式不一致全局排除；`weather` 和 `wind_direction` 因无码表继续排除。

预测起点为 `t`，最近可用观测是 `t−1`。固定 `K={0,1,2,3,6,12}` 小时；lag 0 指 `t−1`，lag k 指 `t−1−k`。禁止使用 `t` 至 `t+H−1` 的真实污染物或气象值，也不得根据验证结果扩充 lag 集合。

### 3.2 ST 外部接口与逻辑形状

仓库运行器的实际外部输入是站点优先展平张量：

```text
X_st_external: [B, S*F, L]
```

ST 内部才重排为逻辑形状：

```text
X_st_logical: [B, S, F, L]
```

本项目 PM2.5 单目标实验中 `F=1`，但文档不得把逻辑形状写成外部 API。锁定模型输出 `y_st=f_ST(X_st_external)∈R^{B×1×H}`。适配器另读中心站 `U`，不改变 Top-5、站点身份偏置、空间门或 PatchTST 主干。

## 4. 数学与张量框架

### 4.1 变量—滞后 token

所有标准化统计量仅由当前折/正式训练片拟合。对变量 p、滞后 k：

```text
V[b,p,k,:] = [z_p(t-1-k), z_p(t-1-k)-z_p(t-2-k)]
V: [B, 7, 6, 2]
E[b,p,k,:] = phi_shared(V[b,p,k,:]) + e_var[p] + e_lag[k]
E: [B, 7, 6, d], d=16
```

PM2.5 历史只生成过去上下文 `c∈R^{B×4}`：最后值、均值、标准差和首尾斜率。

M 的网络结构在理论阶段固定如下。`phi_shared` 是 `Linear(2,16,bias=True) → GELU → Linear(16,16,bias=True)`；不使用 dropout。变量嵌入为 `Embedding(7,16)`，滞后嵌入为 `Embedding(6,16)`。所有 token 共享同一个 `phi_shared`，不得为不同变量另设投影。

### 4.2 唯一冻结的分组门版本

每个预测步先在全部 `7×6` token 上做一次全局 softmax：

```text
s[b,p,k,h] = q_h(c[b])^T E[b,p,k] + bias[p,k,h]
a[b,:,:,h] = softmax over all (p,k)
```

每个 horizon 有独立 `q_h`，结构固定为 `Linear(4,16,bias=True) → GELU → Linear(16,16,bias=True)`，`dropout=0`；另有可训练分数偏置 `bias[p,k,h]∈R^{7×6×H}`。不共享不同 horizon 的 `q_h` 参数。

然后按组求和，不再做组内 softmax：

```text
z_poll[b,h] = sum_{p in pollutants,k} a[b,p,k,h] E[b,p,k]
z_met[b,h]  = sum_{p in meteorology,k} a[b,p,k,h] E[b,p,k]
m_poll[b,h] = sum_{p in pollutants,k} a[b,p,k,h]
m_met[b,h]  = sum_{p in meteorology,k} a[b,p,k,h]
m_poll + m_met = 1
```

因此污染物组和气象组竞争同一权重质量。未来不得在同一验证资源上改成“两组各自 softmax”。

### 4.3 有界旁路

```text
beta = beta_max * sigmoid(theta)
r[b,1,h] = beta * tanh(head_h([z_poll, z_met, c]))
y_hat = y_st + r
```

每个 `head_h` 独立，固定为 `Linear(36,16,bias=True) → GELU → Linear(16,1,bias=True)`，`dropout=0`；36维输入来自两个16维组向量和4维上下文。末层 `Linear(16,1)` 的权重和偏置均零初始化，其余线性层与嵌入采用框架固定默认初始化并记录随机种子。固定 `beta_max=0.2`、`beta_init=0.02`。这样初始化时 `r=0` 且输出严格等于 `y_st`。必须精确记录梯度行为：第一次反向传播只有零初始化输出层获得非零梯度；门、投影、变量/滞后嵌入和 `theta` 的梯度为零。第一次优化器更新使输出层非零后，后续反向传播才把梯度传到上游参数。显式 `disable_auxiliary=True` 或 `beta_max=0` 必须逐元素返回 `y_st`。该设计是训练安全与可退化机制，不作为创新点。

按上述结构，M 的可训练参数数固定为 `P_M(H)=529+1003H`：24→1 为1532，168→6为6547。常数项为 `phi_shared 320 + 变量嵌入 112 + 滞后嵌入 96 + theta 1=529`；每个 horizon 为 `q_h 352 + 分数偏置 42 + 输出头 609=1003`。参数计数不含冻结基础模型。

训练适配器时，整个 ST（含空间分支）必须 `eval`、无梯度，参数和缓冲区哈希前后一致；同一种子所有对照复用同一基础 checkpoint。

## 5. 2×2 空间×适配器因子比较

建模轴区分不等于信息互补。L1 必须在相同数据、种子、训练预算和配对 checkpoint 下运行：

| 空间 S | 适配器 A | 变体 | 含义 |
|---:|---:|---|---|
| 0 | 0 | F00 degraded PatchTST | 无空间、无适配器 |
| 0 | 1 | F01 degraded + adapter | 中心站多变量适配器增益 |
| 1 | 0 | F10 locked ST | 已锁定第一创新点 |
| 1 | 1 | F11 locked ST + adapter | 组合模型，即 M |

对误差指标 `E(F)` 定义正值为改善：

```text
G_A|S=0 = E(F00)-E(F01)          # 无空间时适配器增益
G_A|S=1 = E(F10)-E(F11)          # 组合增益
G_S|A=0 = E(F00)-E(F10)          # 无适配器时空间增益
G_comb  = E(F00)-E(F11)          # 总组合增益
I = G_A|S=0-G_A|S=1              # 增益衰减/差分中的差分
R_attn = 1-G_A|S=1/G_A|S=0       # 仅 G_A|S=0>0 时报告，否则 NA
```

`I>0` 表示加入空间后适配器增益衰减，`I<0` 表示可能协同；二者都只是预测交互，不是因果交互。只有 `G_A|S=1` 通过 L1/确认方向门，才能说适配器与锁定 ST 有实证组合价值。

## 6. L1 模型对照与消融

| 编号 | 变体 | 控制问题 | 公平性说明 |
|---|---|---|---|
| B0/F10 | locked ST | 第一创新点基线 | 同一 checkpoint |
| B1 | ST + self-history | 是否只是新增残差容量 | `7×6×2` 槽全部由 PM2.5 自历史构造 |
| B2 | ST + recent-only | 是否只需最新多变量状态 | 六个 lag 槽复制各变量 lag 0 |
| B-flat | ST + ordinary residual MLP | 变量/滞后结构是否必要 | 读取同一真实 `[B,7,6,2]` 后展平；无变量/lag身份、无结构门、无组门；固定三层普通MLP和同一有界旁路；宽度只按参数数规则确定 |
| B3 | ST + uniform gate | 条件门是否必要 | 真实 token 固定均匀聚合；仅称“条件门消融”，不是严格等容量对照 |
| M/F11 | ST + MC-CVLRA | 完整方案 | — |

M 通过核心门后才做 M−Poll、M−Met、M−VarID、M−LagID。不得同时加入峰值损失、频率分解、VMD、新空间图、RevIN 变体或主干微调。

### B-flat 的固定架构与参数匹配

B-flat 将真实 `V∈R^{B×7×6×2}` 按冻结变量—滞后—原值/差分顺序展平为84维，网络固定为：

```text
Linear(84,w,bias=True)
→ GELU
→ Linear(w,w,bias=True)
→ GELU
→ Linear(w,H,bias=True)
```

全部 `dropout=0`，末层权重和偏置零初始化。其输出经与 M 相同的标量 `beta=beta_max·sigmoid(theta)` 和逐元素 `tanh` 后，加到同一冻结基础预测上；`disable_auxiliary=True`、`beta_max`、`beta_init`、首步梯度和 checkpoint 冻结规则与 M 相同。B-flat 没有其他旁路、skip connection、归一化、变量/滞后嵌入或条件门。

参数匹配不接触数据或性能。在整数候选集 `w∈{1,…,256}` 中，先计算

```text
P_flat(w,H) = w^2 + (86+H)w + H + 1
w* = argmin_w |P_flat(w,H)-P_M(H)|
```

平局取较小的 w。必须在训练前把候选集、全部参数数和 `w*` 写入配置；禁止按训练/验证性能选宽度。按冻结结构，24→1 固定 `w*=15`，`P_flat=1532`，与 M 完全相等；168→6 固定 `w*=47`，`P_flat=6540`，相对差约0.107%。可接受上限固定为3.0%；未来实现前必须按实际可训练参数重新计数。若全体候选的最小相对差仍超过3.0%，则协议验收失败并停止，不得扩大候选范围、增加无效参数或查看性能后改结构。

### 固定 M-shuffle

M-shuffle 只做冻结权重诊断，不重训。对 L1 的三个训练种子 `2060,2061,2062` 分别执行，禁止跨训练种子合并预测：

1. 将每个训练种子的按时间排序验证样本切成不重叠块，每块恰含24个预测起点。不足24个预测起点的尾块排除该诊断，不影响主指标。该种子的固定诊断子集记为 `D_s`。
2. 用固定种子 `3101,3102,3103,3104,3105` 分别置换完整块。
3. 对每个接收块，在相同块内位置替换**完整的七变量辅助历史窗口**；七变量共享同一置换，以保留变量间同期结构。PM2.5 自历史、ST 输入、目标和模型权重均不变。
4. 对训练种子 s，`G_orig,s=RMSE_Ds(B0_s)-RMSE_Ds(M_s)` 必须在排除尾块后的 `D_s` 上重算；每个 `G_shuffle,s,j=RMSE_Ds(B0_s)-RMSE_Ds(M_shuffle,s,j)` 也在完全相同的 `D_s` 上计算。不得把全验证集 `G_orig` 与删尾后的 shuffle 指标混用。
5. 若任一 `G_orig,s≤0`，该训练种子的门失败。否则定义 `L_s=1-mean_j(G_shuffle,s,j)/G_orig,s`，要求三个训练种子分别满足 `L_s≥50%`。并列报告三种子 `L_s` 的算术平均、每个 `L_s` 和全部15个置换结果；不得先拼接三个训练种子的预测再计算一个总值。

## 7. 数据审计与无泄漏验收

### 7.1 已完成的数据语义审计与输入冻结

对仓库原始 CSV 的只读直接审计得到：

| 中心站 | 行×列 | 时间范围 | 时间戳 | 冻结的七个 MVP 辅助变量 |
|---|---|---|---|---|
| 北京 1013 | 8760×14 | 2014-05-01 00:00 至 2015-04-30 23:00 | 解析失败0、重复0、逐小时断点0 | 解析级缺失/非数值0，非有限值0 |
| 广州 9022 | 8760×14 | 同上 | 解析失败0、重复0、逐小时断点0 | 解析级缺失/非数值0，非有限值0 |

解析完整不等于语义可用。2026-08-23 的只读审计发现北京 PM10 极端长平台、pressure 双量级、两城 humidity 零值和 wind_speed 跨城编码不一致。研究负责人代理签字已将输入冻结为七变量，并固定 pressure 换算、零值缺失和最多 6 h 因果 ffill；证据、规则与未决假设见[数据语义审计记录](05_数据语义审计与代理签字.md)。这仍不能证明真实报送延迟或在线可用性，因此论文仅限历史回放预测。

### 7.2 自动验收条件

未来实验数据管线必须自动失败于任一条件：

- train/validation/test 的**目标时间戳集合**不两两互斥；窗口归属以全部目标时间戳决定。所有相邻边界按 horizon 应用 `H−1` 个预测起点 embargo，并断言边界两侧目标时间集合交集为空。
- 筛站函数接收训练时间片以外的数据；站点相关系数、完整性只允许训练片。
- 出现 `bfill`、反向填补或用未来值修复过去；只允许最多 6 小时因果前向填补，残余缺失窗口删除。
- 任一拟合对象没有记录 `fit_start`、`fit_end`、行数和配置哈希。对象至少包括站点筛选、标准化器、缺失判据、q90/快速升降阈值、ridge 内外层拟合和早停选择。
- 冻结候选池不一致：北京固定为 1001–1036（明确含 1036），广州固定为 9017–9047 加 9058；中心站从邻站候选中排除。
- 七变量任一按冻结规则因果处理后的训练片缺失率超过 10%。不得查看验证后再删变量或恢复已排除变量。
- 预测起点 `t` 使用了 CSV 时间戳晚于 `t−1` 的记录，或把 CSV 时间戳误称为真实入库/在线可用时刻。

训练/验证阶段禁止计算、缓存或查看测试预测。标准化、场景阈值和所有选择只用相应训练片；验证只早停/选型；确认结构冻结后测试一次打开。

## 8. L0：无需 ST 残差的 forward-chaining ridge 筛查

L0 不实现/调用 MC-CVLRA，也不需要 ST 的 in-sample 残差。它只筛查数据中是否存在跨变量离散滞后信号，不能证明神经适配器有效。

### 8.1 五折边界

只使用官方 train+validation 可选择区间的目标起点。先按预测起点建立八个连续、近等量的名义块 `Q1…Q8`；名义起点块不等于目标时间互斥块。对每个相邻名义边界 `b_i`（右块第一个预测起点），从左块删除预测起点区间 `[b_i-(H-1), b_i-1]` 的 `H−1` 个样本。168→6 的每个边界删除5个左侧预测起点，24→1删除0个。保留下来的每个样本必须满足其全部目标时间戳只属于边界一侧。

完成 block-level embargo 后，五个外层折固定为：

| 折 | 外层训练目标块 | 外层验证目标块 |
|---:|---|---|
| 1 | Q1–Q3 | Q4 |
| 2 | Q1–Q4 | Q5 |
| 3 | Q1–Q5 | Q6 |
| 4 | Q1–Q6 | Q7 |
| 5 | Q1–Q7 | Q8 |

每个外层折都构造训练样本全部目标时间戳的集合 `T_outer_train` 和验证集合 `T_outer_val`，并自动断言 `T_outer_train ∩ T_outer_val = ∅`。八块各相邻边界也执行同一断言；名义起点分块本身不构成验收证据。输入只回看预测起点之前，官方 test 完全不进入 L0。

### 8.2 三个 ridge 与正则选择

每个模型都含共同 PM2.5 自历史控制特征 `C_t`：固定六个 lag 的原值和一阶变化。比较：

- `R_self(C_t)`；
- `R_recent(C_t + 7变量lag0原值/变化)`；
- `R_lag(C_t + 7×6×2结构化滞后)`。

直接预测真实目标，不拟合 ST 残差。24→1 单独拟合一个 ridge；168→6 对每个 horizon `h=1…6` 分别拟合一个 ridge，并用所有样本×horizon 拼接的 `RMSE_all` 作主汇总，同时报告逐 horizon RMSE。若未来改用 ST 残差，必须先在每个外层训练段内用严格 nested forward-chaining 产生全 OOF 基础预测；禁止 in-sample 残差。MVP 不采用该备选。

固定正则网格 `{1e-4,1e-3,1e-2,1e-1,1,10,100}`。设 embargo 后的外层训练样本数为 `N_outer`，按预测起点排序，前 `floor(0.85·N_outer)` 个作为名义 inner-fit，其余作为 inner-validation；在该 inner 边界再次从 inner-fit 左侧删除 `H−1` 个预测起点，即168→6删5个、24→1删0个。随后构造 `T_inner_fit` 与 `T_inner_val`，自动断言 `T_inner_fit ∩ T_inner_val = ∅`。缩放器仅拟合 embargo 后的 inner-fit。每个特征族/任务选一个跨 horizon 共享 alpha，以 inner-validation 的 `RMSE_all` 最小为准，平局取更大的 alpha；随后在已完成 outer embargo 的完整外层训练段重拟合缩放器和 ridge，再一次评估外层验证。选择层级固定为“特征族/任务→共享 alpha→逐 horizon 系数”，不得用外层验证反调 alpha。

### 8.3 L0 门

168→6 为主筛查，必须同时满足：`R_lag` 相对 `R_self` 五折平均 RMSE 改善≥0.5%，相对 `R_recent` 平均改善≥0.2%，且两项均至少 4/5 折同向。24→1 仅报告支持性结果，不参与是否实现的主门。失败即止损，不实现神经模块。

## 9. L1：神经选择门

数据语义已由研究负责人代理签字，且协议已按 `P=7` 重新冻结；因此允许进入独立实验分支执行 L0。只有 L0 通过才允许实现神经适配器。北京 1013 主任务 168→6、次任务 24→1；选择种子暂登记 `2060,2061,2062`，进入实验前核对未被消费后冻结。纯 MSE、相同数据/优化器/batch/早停预算，同一种子复用配对 checkpoint。

168→6 的 M 必须同时满足：

1. 对 B0/F10：3/3 种子 RMSE 改善，平均改善≥0.5%。
2. 对 B1：3/3 种子 RMSE 改善，平均改善≥0.2%。这是 self-history 硬门。
3. 对 B2：至少 2/3 同向且平均改善≥0.2%。
4. 对 B-flat：至少 2/3 同向且平均改善≥0.2%；否则不能声称变量/滞后结构有效。
5. 六个 horizon 至少 4/6 的平均 RMSE 优于 B0。
6. 训练期 q90 定义的高污染 RMSE 相对 B0 恶化不得超过 **1.0%**。
7. 24→1 总体 RMSE 相对 B0 平均恶化不得超过 0.2%。
8. 固定 M-shuffle 对三个训练种子分别满足 `L_s≥50%`，再报告三种子均值；不得合并预测。
9. 2×2 中 `G_A|S=1` 满足第1项；四格误差、`I` 和可定义时的 `R_attn` 均逐种子报告。

B3 只诊断条件门，不承担等容量证明。任一硬门失败即止损，不扫描 lag、变量子集、beta、频率模块或新损失挽救。

## 10. 指标与关键场景

- 主指标 RMSE；次指标 MAE、SMAPE。
- 168→6 报告总体及逐 horizon RMSE/MAE、配对绝对/相对差、均值、标准差、逐种子方向。
- 训练期固定阈值定义高污染、快速上升、回落和普通状态；报告样本数、RMSE、MAE与偏差。
- 高污染安全门统一为“相对基线 RMSE 恶化不超过 1.0%”，不使用“显著恶化”这种未定义表述。
- 场景指标不替代总体门，不对小样本子组作显著性声称。

## 11. 独立确认

### 11.1 北京内部确认

验证选型后固定 commit、结构、所有阈值算法和 epoch 规则，再用五个未参与选择的新种子（暂登记 `2063–2067`，实施前核对）。只比较固定 F11 与配对 F10。168→6 要求 5/5 RMSE 改善且平均≥0.5%（单侧精确符号检验 `p=0.03125`）；24→1 同门。MAE/SMAPE、逐 horizon 和场景指标完整报告，但不是替换主门。北京测试已被第一创新点研究查看，只称内部确认。

### 11.2 广州预指定跨城市迁移确认

广州 9022 曾用于项目历史单站流程，因此只能称**预指定跨城市迁移确认**，不是项目级未见盲测。

- 中心站固定 9022；任务固定 24→1 与 168→6。
- 候选池固定 9017–9047 加 9058，排除 9022；相关性和完整性只用广州训练片。
- `Pearson>0.85` 后若少于 5 个合格邻站，不降低阈值、不补看验证、不换中心站；该任务标记为“无法评价精确 Top-5 结构迁移”并停止对应空间组合确认。若不少于 5，仍固定 Top-5。
- 五个新种子暂登记 `2068–2072`，进入 confirmation 前核对未被任何选择/确认消费后冻结。
- 每个任务 F11 对配对 F10 要求 5/5 RMSE 同向、平均改善≥0.5%，高污染 RMSE 恶化≤1.0%；主指标 RMSE，次指标 MAE/SMAPE、逐 horizon 与场景指标。
- 每个种子 F10 与 F11 使用同一 ST checkpoint 文件与哈希；F11 全程冻结该 checkpoint。数据切分、初始化来源、batch、早停和评估 checkpoint 配对记录。
- 预算上限为 30 次模型拟合：2任务×5种子×（degraded 基础1 + locked ST 空间分支1 + adapter1）。F10 直接评估共享的 locked ST，不重复拟合；不增加广州超参数/消融搜索。
- 广州验证仅按冻结规则早停；测试一次打开。任一任务失败只报告失败，不改站、种子、阈值或结构。

只有北京与广州相应任务均通过，才可表述跨城市一致证据；这仍不是所有城市泛化。

## 12. 止损与论文边界

以下任一情况止损：L0 不过；L1 未过 B1/B2/B-flat；组合增益无逐种子稳定性；M-shuffle 不敏感；高污染恶化超过 1.0%；需要解冻/换 checkpoint/扩预算；冻结七变量按因果处理后的训练片缺失率超过10%；需要扫描 lag、频率/VMD/滤波、变量子集或损失。

若全部确认通过，可有限表述“在冻结 ST-PatchTST 上，固定历史辅助变量与离散滞后结构提供了稳定的残差适配增益，且因子与特异性对照支持组合价值”。不得声称因果机理、通用变量选择创新、所有指标提升或广泛城市泛化。
