# Experiment protocol handoff

本文件只为未来实验分支交接，不授权在当前理论分支实现或训练。唯一权威细节见 [最终推荐方案](../03_最终推荐方案.md)。

## 阶段顺序

1. 采用已代理签字的`P=7`历史回放数据语义；实现前复核确定性清洗、变量顺序和参数计数。
2. L0：直接目标、八个名义起点块、五折nested ridge；outer/inner每界应用`H−1`起点embargo并断言目标时间集合无交集；失败即止损。
3. L1：F00–F11 2×2，加B1/B2/B-flat/B3和固定M-shuffle。
4. 固定commit后北京五新种子内部确认。
5. 固定广州9022两任务五新种子迁移确认，预算上限30次拟合。

## 最低产物

- split及L0每个outer/inner边界的目标时间戳集合、embargo删除起点清单与空交集断言；
- 每个拟合对象的时间范围ledger；
- 候选池和训练期筛站日志；
- checkpoint路径/hash和配对表；
- M和B-flat的逐层结构、精确参数数、宽度候选参数差表与3.0%验收状态；
- 七变量清洗ledger：pressure换算、零值缺失、逐split最多6 h因果ffill、残余缺失窗口及训练片10%门；
- L0逐折/逐horizon、L1逐种子、2×2交互、每个训练种子的五个shuffle结果和场景结果；
- 所有止损门的布尔状态。

任何测试结果不得用于修改上述协议。
