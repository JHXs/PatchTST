# Method–experiment traceability

本表只规划未来实验，不代表执行结果。

| 假设/风险 | 设计组件 | 最小对照或验收 | 指标 | 硬门 |
|---|---|---|---|---|
| H1 增量信息 | 中心站冻结七变量残差适配 | B0 locked ST；B1 self-history | 168→6 RMSE | 对B0 3/3且均值≥0.5%；对B1 3/3且均值≥0.2% |
| H2 离散滞后特异性 | `{0,1,2,3,6,12}`原值+差分 | L0 self/recent/lag；L1 B2 recent-only | 五折与逐种子RMSE | L0对self≥0.5%、对recent≥0.2%、各4/5；L1对B2均值≥0.2%、至少2/3 |
| H3 结构特异性 | M固定两层投影/查询/输出头 | B-flat读取同一真实`7×6×2`；固定三层GELU MLP；`w=1…256`仅按参数差选择 | 配对RMSE、精确参数数 | 参数最小相对差≤3.0%（预计算w=15/47）；M对B-flat均值≥0.2%、至少2/3 |
| H4 条件门价值 | 全局softmax后组求和 | B3固定均匀门 | RMSE | 仅条件门消融，不称严格等容量 |
| H5 与空间组合 | 空间S×适配器A | F00/F01/F10/F11 2×2 | `G_A|S=1`、`I`、`R_attn` | 组合增益满足B0门；交互只报告不作因果解释 |
| 时间对齐 | 真实辅助历史 | 每个L1训练种子固定24预测起点块；置换种子3101–3105；原始/置换使用同一删尾子集 | 逐训练种子原始与5个置换增益 | 三个训练种子各自增益损失≥50%，再报三种子均值；禁止合并预测 |
| 严格退化/冻结 | 全ST eval无梯度；零输出层 | `disable_auxiliary=True`；状态哈希 | 逐元素输出、梯度与哈希 | 初始/旁路输出相同；首个backward仅输出层有梯度；ST不变 |
| 无场景伤害 | 训练q90高污染场景 | B0/F10 | 高污染RMSE | 恶化≤1.0% |
| 无泄漏 | 名义起点块每界`H−1`起点embargo、train-only拟合、禁止bfill | outer/inner逐折目标时间集合交集断言与fit range ledger | 集合交、时间范围 | 168→6每界删5个、24→1删0个；任一集合交集非空即停止 |
| 数据语义 | 固定七变量与历史回放规则 | PM10/wind排除；pressure换算；零值缺失；最多6 h因果ffill | 训练片缺失率、处理ledger | 任一变量>10%或使用`timestamp>t−1`即停止；不得验证后回调 |
| 广州迁移 | 9022、两任务、五新种子 | 配对F10/F11；固定候选池含9058 | RMSE主，MAE/SMAPE辅 | 每任务5/5且均值≥0.5%；不足5邻站则不可评价精确Top-5迁移 |

确认阶段只确认固定组合包效果；组件归因来自预注册L1与2×2，确认结果不得回调结构。
