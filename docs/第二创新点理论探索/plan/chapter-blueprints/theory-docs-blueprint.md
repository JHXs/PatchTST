# Theory deliverables blueprint

## 段落目标

1. 先固定现有能力和失败边界，防止重复研究。
2. 用一手来源说明候选为何成立，同时呈现相反证据。
3. 统一评分，避免先选结论后补理由。
4. 把主候选写成张量、接口和对照，而非模块名。
5. 用训练/验证门定义可被推翻的结果。
6. 以论文表述边界结束，隔离理论可行性和性能结论。

## 关键证据分配

- 项目审计：当前代码、稳定性 CSV/JSON、频域 P1/P1A、alpha 消融。
- 候选比较：TFT、Lag-FLSTM、TimeXer/iTransformer/TiDE、空气质量多变量/峰值、Dish-TS/RevIN、EnbPI。
- 最终方案：外部 `[B,S*F,L]` 与内部 `[B,S,F,L]`、冻结 ST 接口、2×2、无ST残差L0和等输入普通MLP对照；所有外部实现只作概念参考。
- 阶段门：工作流规则、数据语义代理签字、L0/L1 阈值和北京/广州独立确认边界。

## 反方证据

必须保留 2026 iScience 对污染物组合的负面结果、频域等容量对照失败、alpha 无差异，以及当前 RevIN 已存在的事实。它们用于收紧方案，不应被省略。
