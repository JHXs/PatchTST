# Task packet

## 范围

只做理论调研与方案确认；不得改模型、加运行器、训练、正式实验、提交或推送。

## 证据优先级

1. 当前代码/测试；
2. CSV/JSON；
3. 当前报告；
4. 旧文档；
5. 外部论文原文与作者官方仓库。

## 必答问题

- 现有模型真正缺什么？
- 频域和 alpha 分支具体否定了什么？
- 至少四个建模轴/接口可区分的候选如何统一比较，且不把接口隔离误写为信息正交？
- 主候选如何与锁定 ST 对接并严格退化？
- 如何用训练/验证证伪而不消费测试集？
- 什么结果必须止损，最终能说到哪里？

## 验收

- 所有外部引文可点击且事实/推断分开；
- 标题、年份、URL、代码、许可证和访问日期齐全；
- 明确一个主候选和一个备选；
- 条件放行或止损状态唯一明确；
- 2×2、无泄漏L0、B-flat、M-shuffle与广州迁移确认均可自动/人工验收；
- `git diff --check`、内部链接和关键词一致性通过；
- 仅文档变更。
