## 4. 冻结的后续协议

- 北京任务：1013，168→6 主筛查/主选择，24→1 次任务。
- 广州迁移：9022，24→1 与168→6；候选池9017–9047加9058。9022历史上已用于单站流程，不称项目级未见盲测。
- 北京候选池1001–1036，明确含1036；所有筛站只接收训练片。
- 七变量、`K={0,1,2,3,6,12}`、原值+一阶变化、`d=16`、全局softmax后两组求和；M的投影、`q_h`和输出头均为固定两层GELU MLP、带偏置且`dropout=0`。
- beta有界残差、零初始化和显式旁路只作为安全机制。
- L0：八个名义起点块组成五个扩展窗口外层折；168→6在每个block、outer和inner边界从左侧删除5个起点，24→1删除0个；每折outer/inner目标时间集合交集必须为空。直接目标 ridge，固定 alpha 网格；主门只看168→6。
- L1：B0、B1、B2、B-flat、B3、M及完整2×2；B3仅为条件门消融。B-flat固定三层GELU MLP，宽度在1–256中仅按参数差确定，最小差须≤3.0%，否则协议失败。
- 高污染实际效应门统一为相对基线 RMSE 恶化≤1.0%。
- 固定 M-shuffle：每块恰含24个预测起点；每个L1训练种子在相同删尾诊断子集上重算原始与五个置换增益，三个训练种子分别须达到50%增益损失，禁止合并预测。
- 测试只在固定 commit 后一次打开，结果不得回流改结构。

## 6. 明确止损条件

- 冻结七变量按因果处理后的训练片缺失率超过10%，或出现违反 `timestamp<=t−1` 的历史回放可用性；
- L0 未达到相对 self 0.5%、recent 0.2% 且各4/5折同向；
- L1 未过 B0、B1、B2 或 B-flat 硬门；
- 2×2 的 `G_A|S=1` 不稳定，不能支持与锁定 ST 的组合价值；
- 任一L1训练种子的 M-shuffle 增益损失低于50%，或高污染 RMSE 恶化超过1.0%；
- outer/inner任一目标时间集合交集非空，或B-flat最小参数差超过3.0%；
- 需要解冻主干、改 checkpoint、扩大 lag/变量/损失/频率搜索或查看测试来挽救。

RES-Peak 不能在主候选失败后直接消费同一确认资源；需单独重做理论协议和资源登记。
