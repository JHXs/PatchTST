# MC-CVLRA L1 正式选择止损报告

执行与决策日期：**2026-08-24**。分支：`experiment/cross-variable-lag-adapter-ablation`。

> 本报告只使用北京 1013 的 train+validation 选择区间。正式 test 特征、目标、样本、预测、缓存和指标构造数均为 0。以下结论不是测试集性能结论，也不能解释为变量因果作用。

## 1. 执行范围

严格按冻结协议运行两个任务、三个预登记种子 `2060–2062` 和八个变体：

- 24→1：40 epochs、patience 8、batch 256；
- 168→6：30 epochs、patience 6、batch 512；
- 变体：F00、F01、F10、F11、B1、B2、B-flat、B3；
- 主指标：物理尺度 RMSE；
- 主选择任务：168→6；24→1只承担非劣门。

F10每轮训练后强制PatchTST保持eval；F00来源、F10初始化、逐epoch、最佳checkpoint和最终加载的全部PatchTST参数与buffers逐元素一致。所有适配器共享配对基础checkpoint，基础模型在适配器训练期间保持eval/no-grad且状态哈希不变。

24→1运行绑定源码提交`5d2e3a1`，168→6运行绑定提交`372ff8a`；两者关键L1源码SHA256一致，中间提交只归档前一任务结果。独立汇总器从逐validation预测重建全部指标、2×2、场景、M-shuffle和阶段门；完整性状态为PASS。

## 2. 主结果

168→6中，完整模型F11相对锁定ST基线F10的RMSE在三个种子均改善：

| 种子 | F11相对F10的RMSE改善 |
|---:|---:|
| 2060 | 0.680474% |
| 2061 | 0.459999% |
| 2062 | 0.291703% |
| **平均** | **0.477392%** |

方向为3/3，但平均改善低于预注册的0.5%实际收益门，因此主增量门失败。

更关键的特异性对照也失败：

| 硬门 | 预注册要求 | 实际结果 | 状态 |
|---|---|---|---|
| F11 vs F10 | 3/3且平均≥0.5% | 3/3，平均0.477392% | FAIL |
| F11 vs B1 self-history | 3/3且平均≥0.2% | 3/3，平均0.073843% | FAIL |
| F11 vs B2 recent-only | 至少2/3且平均≥0.2% | 2/3，平均0.022306% | FAIL |
| F11 vs B-flat | 至少2/3且平均≥0.2% | 0/3，平均−0.161018% | FAIL |
| M-shuffle | 每个种子增益损失≥50% | 2061仅19.1907% | FAIL |

B-flat在三个种子上全部优于F11，说明当前收益不能归因于预设的变量身份、离散滞后身份和条件门结构。L0证明的线性滞后信号没有转化为MC-CVLRA相对等输入普通适配器的结构特异性优势。

## 3. 通过但不能挽救主门的项目

- 168→6六个预测步的平均RMSE均优于F10，逐horizon方向门通过；
- 高污染RMSE相对F10平均改善约0.8635%，安全门通过；
- 24→1中F11相对F10为3/3改善，平均0.841108%，非劣门通过；
- F11相对F10在168→6也是3/3同向。

这些结果不能替代结构特异性和实际收益硬门，也不能用于将STOP改写为PASS。

## 4. 唯一阶段结论

**L1状态：STOP。**

触发了预注册止损条件：未通过F10、B1、B2、B-flat和M-shuffle硬门。因此：

1. 不创建`experiment/cross-variable-lag-adapter-confirmation`分支；
2. 不使用北京正式test，不运行2063–2067确认种子；
3. 不进入广州9022迁移确认；
4. 不扫描lag、变量、beta、网络宽度、损失或频域模块挽救；
5. MC-CVLRA只能作为完整保留的负结果，不能写成已成立的第二创新点。

备选RES-Peak不得在本分支直接启用，也不得继续消费同一选择资源。若以后研究备选方向，必须重新建立独立理论分支、实验协议和未消费资源登记。
