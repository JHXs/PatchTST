# 候选比较与来源清单

调研日期：**2026-08-23**。本文件区分“来源事实”和“本项目推断”；后者不是论文作者的结论。候选比较没有使用本项目测试预测或指标；后续全 CSV 语义审计只用于验证前全局冻结输入，另见[代理签字记录](05_数据语义审计与代理签字.md)。

## 1. 检索方法

检索覆盖了近年时间序列预测、外生/辅助变量、跨变量依赖、空气质量、多变量滞后、污染峰值、非平稳性、分布漂移和不确定性。先广泛浏览约 30 个题名/摘要/仓库，再对与候选直接相关的论文原文页、正式 proceedings、作者仓库和许可证文件作深核验。

来源优先级为正式 proceedings/期刊/DOI/PMC、作者官方仓库、arXiv；搜索摘要只用于发现，不作为关键结论的唯一依据。引用数没有进入评分，表中记为“未采集”，避免用不稳定的第三方快照影响路线选择。

## 3. 四个实质不同的候选

### C1 机制约束的中心站跨变量滞后残差适配器（MC-CVLRA）

对象是中心站共污染物/气象历史与 PM2.5 残差之间的变量—滞后关系。它不改空间图，不做频率分解，不重新训练 PatchTST 主干。关键特异性问题是：完整模型能否同时击败冻结 ST、等容量 PM2.5 自历史适配器和等容量“只有最新时刻、没有真实滞后”的多变量适配器。

### C2 污染演化状态感知的峰值校正（RES-Peak）

用训练期阈值定义稳定/快速上升/高污染/回落状态，从历史窗口预测软状态，再由状态条件残差校正冻结 ST，并可附加峰值分类辅助任务。优点是空气质量叙事强、场景指标清楚；风险是峰值样本少、阈值自由度大，容易退化为损失加权技巧。

### C3 lookback→horizon 状态迁移校准器

从最近窗口预测未来位置/尺度变化，对冻结 ST 输出做可逆校准。它与空间机制在接口上区分，也能处理季节/污染状态漂移；但当前主干已有 RevIN，增量能力需要非常严格地与 RevIN 和简单线性校准区分，空气质量机制叙事偏弱。

### C4 条件不确定性与时间序列校准

在冻结 ST 上增加分位数/异方差头，再用按时间排序的 conformal 校准给出总体与高污染条件区间。它对风险沟通有价值、开源参考成熟；但主要指标从点误差转为覆盖率/区间宽度，与当前论文主线的 RMSE 改善不完全一致，且单年数据再切校准段会减少有效样本。

## 4. 统一量表与评分（仅决策辅助）

评分不是文献证据或性能证据，只用于在当前约束下组织判断。正向项越高越好；复杂度、风险、否证成本越低越好。通用锚点为：1=明显不满足/高风险，3=部分满足且关键问题待验证，5=已有直接项目证据支持；由于当前尚无第二创新点实验，任何候选的“轴/接口区分度”均不得因接口设计直接给5分。

各维度的1/3/5锚点为：机制匹配=牵强/可解释/有直接空气质量证据；原创叙事=现成模块/特定组合/已证明独特机制；数据支持=需新数据/需审计/现有列且语义确认；泄漏安全=依赖未来/可通过协议控制/已有自动验收；复杂度=大主干/中型适配/线性诊断；消融=难归因/可部分拆分/有等输入与因子对照；开源=无可核验/概念参考/官方成熟许可；风险与否证成本则按低、中、高反向解释。

C1 胜出不是因为评分或外部论文证明它有效，而是因为它把当前未覆盖问题转化为低成本可否证协议，且不需要新数据或替换主干。其建模轴与空间创新不同、工程接口可隔离，但信息互补仍须2×2实测。S10、S11与S17同时压低了原创性上限：多变量滞后和变量选择都不是新概念，能够主张的只是一套面向冻结 ST-PatchTST 的严格退化、离散滞后特异性和因子对照方案。

## 5. 明确排除的方向

| 排除方向 | 原因 | 与频域失败的关系 |
|---|---|---|
| rFFT、STFT、wavelet、VMD、趋势/季节/残差、多尺度滤波 | 已有固定 rFFT 与唯一因果局部滤波特异性门失败；继续扫描属于验证集试错 | 直接重复或换名重复 |
| Koopa/Fourier Filter、周期 token、频谱门控 | 核心信息分解仍在频域 | 换名重复 |
| 再加 RevIN | 当前 tsai PatchTST 默认已经启用 | 非频域，但重复现有能力 |
| 污染物专属 alpha | 既有分支三种子消融未优于统一 alpha；当前正式任务又是单目标 | 非频域，但已失败/不适用 |
| 固定邻站传播滞后或新空间图 | 现有诊断支持 lag 0，且与 Top-5 空间创新重合 | 非频域，但正交性不足 |
| 直接替换为 iTransformer/Crossformer/TimeXer/AirFormer | 小数据、算力与公平性成本高；会破坏锁定主干和第一创新点接口 | 不是频域重复，但属于“换整套主干”而非第二机制 |
| 只做峰值加权损失 | 缺少状态机制和等容量对照，容易成为指标工程 | 备选只有在固定状态假设下才保留 |
| 依赖未来数值天气、排放清单、地形或化学传输模型 | 现有数据不含可靠未来协变量，新增数据难复现 | 数据约束不满足 |
| 声称学习到结构因果关系 | 只有观测时序，无干预或可信因果识别条件 | 概念越界 |

主候选只对原始历史变量的离散时滞建模，不执行频率变换、不分解频带、不使用移动平均/卷积尺度库，因此不是频域路线的换名版本。
