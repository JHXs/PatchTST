# 北京 1013 跨变量滞后 L0 选择区间筛查报告

执行日期：**2026-08-23**。分支：`experiment/cross-variable-lag-adapter-ablation`。

> 本报告只讨论 train+validation 选择区间的 forward-chaining ridge。它不是正式 test 结果，不是 MC-CVLRA、ST-PatchTST 或其他神经模型性能，也不能把变量权重解释为因果机制。

## 1. 执行范围与冻结项

本轮只执行最终推荐方案的 L0。北京中心站固定为1013，辅助变量固定为`[NO2, CO, O3, SO2, temperature, pressure_hPa_fixed, humidity_clean]`，lag固定为`{0,1,2,3,6,12}`。PM10、wind_speed、weather和wind_direction没有加载到特征管线；没有实现或调用MC-CVLRA神经模块。

清洗严格执行签字规则：pressure在`<900`时乘`1.33322`，换算后域外`[900,1100]`标缺失；辅助污染物`<=0`、humidity为0或`>100`、temperature域外`[-50,60]`标缺失；train和validation分片独立做最多6小时因果ffill，不bfill，PM2.5不修补。北京训练片只有humidity出现125个无效值，均由不超过6小时的过去值填补；七变量训练片残余缺失率均为0。

三个直接目标ridge保持共同样本：`R_self`使用PM2.5六个lag的原值/变化，`R_recent`再加七变量lag 0，`R_lag`再加七变量全部六个lag。对应特征数为12、26和96。alpha严格从`{1e-4,1e-3,1e-2,1e-1,1,10,100}`用inner 85/15的`RMSE_all`选择，平局取更大值；各horizon系数独立，scaler和ridge只拟合对应训练片。

## 2. 时间边界与无泄漏验收

运行器先只读取8760个原始时间戳，再以整数比例建立精确70/10/20行边界：train 6132行、validation 876行、test 1752行。允许特征与目标只读取前7008行，test从`2015-02-17 00:00:00`开始。test特征行、样本、预测、缓存和指标构造数均为0。

Q1–Q8在残余缺失删除前按名义预测起点近等量建立。168→6在每个相邻Q边界删除左侧5个起点，24→1删除0个；五个outer边界和五个inner边界执行同一`H-1`规则。两任务共34个block/outer/inner边界的目标时间集合交集均为空。168→6保留6800个共同样本，block embargo删除35个名义起点；24→1保留6984个共同样本；两任务残余缺失窗口删除数均为0。

|---|---|---:|---:|
| 168→6 | R_self | 42.092536 | 8.951116 |
| 168→6 | R_recent | 42.027657 | 9.008640 |
| 168→6 | R_lag | 41.175590 | 8.674604 |

168→6中，`R_lag`相对`R_self`的五折平均RMSE改善为**2.178407%**，4/5折同向；相对`R_recent`改善为**2.027396%**，5/5折同向。唯一反向项是第2折相对self恶化2.762784%，但不改变预注册的4/5方向门结论。

24→1只作支持性报告。`R_lag`相对self/recent的五折平均RMSE改善为2.075136%/0.335655%，方向为5/5与3/5；其中相对recent没有达到4/5方向一致，但该任务不参与L0硬门，也不能用于挽救或否决168→6。

逐折、逐horizon、alpha和样本数见[fold_horizon_metrics.csv](../../experiments/results/cross_variable_lag_adapter/l0/fold_horizon_metrics.csv)、[fold_metrics_all.csv](../../experiments/results/cross_variable_lag_adapter/l0/fold_metrics_all.csv)、[inner_alpha_scores.csv](../../experiments/results/cross_variable_lag_adapter/l0/inner_alpha_scores.csv)和[paired_differences.csv](../../experiments/results/cross_variable_lag_adapter/l0/paired_differences.csv)。

## 4. 唯一阶段门

168→6的四项预注册硬门全部通过：

- 相对self平均改善至少0.5%：实际2.178407%；
- 相对recent平均改善至少0.2%：实际2.027396%；
- 相对self至少4/5折同向：实际4/5；
- 相对recent至少4/5折同向：实际5/5。

因此唯一结论为：**PASS**。这只允许下一阶段按已冻结协议进入L1神经实现；L0本身不证明MC-CVLRA有效，也不授权修改变量、lag、alpha、结构、门槛或使用test选型。当前用户任务在L0结束，不包含L1实现。

## 5. 工程异常与结果复算

首次工程运行使用浮点`int(N*(0.7+0.1))`，把选择区间止点错误截为7007。该运行在查看边界元数据后立即判无效，保留[无效说明](../../experiments/results/cross_variable_lag_adapter/l0_invalid_float_boundary_7007/INVALID_RUN.md)，不得引用其指标。修复只把同一冻结70/10/20规则改为精确整数比例，并新增8760行边界回归测试；变量、lag、alpha、Q/折和门槛没有变化。权威结果均来自修复后从头运行的`l0/`目录。

独立复算器从[outer_predictions.csv](../../experiments/results/cross_variable_lag_adapter/l0/outer_predictions.csv)重建逐折/逐horizon指标、配对差和硬门，并复核alpha、ledger、P=7顺序、缺失率及全部目标时间集合。34个边界与30个alpha选择组通过，最大绝对数值误差为`2.14e-14`；完整结果见[integrity_verification.json](../../experiments/results/cross_variable_lag_adapter/l0/integrity_verification.json)和[gate_status.json](../../experiments/results/cross_variable_lag_adapter/l0/gate_status.json)。

## 6. 风险与允许表述

L0只说明固定七变量和固定离散lag在北京1013历史回放选择区间中提供了低成本线性增量信号。它不能证明神经适配器、与空间分支的信息互补、真实在线无延迟、变量因果作用或跨中心站/城市泛化。数据精确血缘、原始缺失掩码和真实报送时刻仍不可证；pressure单位解释与零值缺失是验证前冻结的工程假设。
