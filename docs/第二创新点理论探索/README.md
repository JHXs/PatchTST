# 第二创新点理论探索

调研日期：**2026-08-23**

本目录记录 PatchTST 项目第二创新点的理论调研、候选比较与阶段门决定。独立 reviewer 的“需大修”意见已在 2026-08-23 纳入并替代上一版结论。本分支未修改模型代码、未运行训练或正式实验，也未读取测试预测/指标来选型；本轮按用户授权读取全 CSV 仅作一次性语义审计，并在 L0 前全局冻结规则。

## 结论摘要

- 主候选：**机制约束的中心站跨变量滞后残差适配器**（MC-CVLRA，Mechanism-Constrained Cross-Variable Lag Residual Adapter）。它利用中心站已经存在但当前正式运行器未使用的共污染物与气象历史，解释冻结后的 Top-5 ST-PatchTST 仍然留下的预测残差。
- 备选：**污染演化状态感知的峰值校正**（RES-Peak）。它针对上升、峰值和回落状态，但阈值自由度、稀有事件样本量和“只做损失工程”的风险高于主候选。
- 阶段门：**数据语义已由研究负责人代理签字，条件放行进入低成本 L0**。MVP 已冻结为七个辅助变量；该结论不是性能放行，L0 也不能证明神经适配器有效。
- 与第一创新点的关系：两者的建模轴、输入角色和工程接口可区分，主候选不会回写锁定 ST；但信息互补尚未证明，未来必须用 degraded PatchTST / degraded+adapter / locked ST / locked ST+adapter 的 2×2 因子比较检验组合增益和增益衰减。有界 beta 残差只是安全机制，不是创新。
- 论文状态：MC-CVLRA 只是主候选。L0、L1、2×2 和独立确认完成前，不得称为“已成立的第二创新点”。

## 阅读边界

文中“因果”只用于“预测时仅使用预测起点之前的信息”这一**时间因果/防泄漏含义**。没有干预数据或可靠因果图，因此不得把学习到的变量权重解释为污染物之间的结构因果效应。所有外部来源事实和本项目推断均明确分开。
