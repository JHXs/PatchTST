# 第二创新点理论探索

调研日期：**2026-08-23**

本目录记录 PatchTST 项目第二创新点的理论调研、候选比较与阶段门决定。独立 reviewer 的“需大修”意见已在 2026-08-23 纳入并替代上一版结论。理论阶段没有修改模型代码、运行训练或读取测试预测/指标；数据语义签字在 L0 前冻结。随后在独立 `experiment/cross-variable-lag-adapter-ablation` 分支依次完成train+validation范围的L0与L1，最终按预注册规则在L1止损；正式test始终未构造或查看。

## 结论摘要

- 主候选：**机制约束的中心站跨变量滞后残差适配器**（MC-CVLRA，Mechanism-Constrained Cross-Variable Lag Residual Adapter）。它利用中心站已经存在但当前正式运行器未使用的共污染物与气象历史，解释冻结后的 Top-5 ST-PatchTST 仍然留下的预测残差。
- 备选：**污染演化状态感知的峰值校正**（RES-Peak）。它针对上升、峰值和回落状态，但阈值自由度、稀有事件样本量和“只做损失工程”的风险高于主候选。
- 阶段门：L0曾以168→6相对self/recent改善2.1784%/2.0274%通过；但冻结L1正式选择最终为 **STOP**。F11相对F10虽3/3改善，平均仅0.477392%，低于0.5%门；对B1、B2、B-flat和M-shuffle的结构特异性门也全部失败。
- 与第一创新点的关系：F11在168→6和24→1中相对锁定ST均为3/3改善，但未达到预注册实际收益/特异性要求，不能据此声称跨变量离散滞后结构与空间分支形成了可靠互补。
- 论文状态：MC-CVLRA已按预注册规则止损，只能作为负结果保留，**不是已成立的第二创新点**。不创建确认分支，不打开正式test，也不扫描配置挽救。
