## 硬规则（协议摘要）

1. 基线**仅中心站单站点**（输入通道 = 1；1013 的通道索引 = 9，须按站点 ID 解析而非硬编码）
2. 容量对齐按**可训练参数量**，且必须含**精确匹配点**（Informer `d=12,e=2` = 5,125，落在我们 4,588–5,418 区间内）
3. **禁止用测试集挑对手**；结论必须同时报「验证集口径」与「测试集口径（上界）」
4. 必须报每个家族**验证损失–测试 RMSE 秩相关**（方向 20 实测 −0.20）
5. 配对统计只用**共同子集**；负面结果原样入表
6. 所有臂复用**同一锁定训练循环**（`run_trainable_matched_baselines.train_one_baseline` 语义），**只替换模型类**
7. **逐 lead（步内）分析必做**（H∈{6,12,24}，零额外训练，模板复用 `F2_per_lead`/`FF6_per_lead`/`T3_per_lead`）
8. 无新资源：北京 1013 与种子 2047–2051 为已消费资源，仅作配对对照臂；广州 b2/b3 未打开
