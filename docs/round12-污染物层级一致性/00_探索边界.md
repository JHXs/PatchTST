# Round 12 污染物层级一致性探索边界

日期：2026-09-11。

## 本轮问题

只审查中心站颗粒物的物理层级：在同一时刻，理想语义为

```text
PM10_total = PM2.5_fine + coarse_fraction,  coarse_fraction >= 0
```

问题是：在只评价 PM2.5 点预测的前提下，训练期同时利用 PM10 标签与上述层级，能否形成区别于普通多任务学习、差值辅助任务和现成层级预测 reconciliation 的可归因有限样本估计机制？

本轮从稳定 `main@1a26492` 独立建立，只读代码和一手文献；不得读取任何站点 CSV、checkpoint、旧性能 JSON/CSV 或运行训练。

## 硬边界

1. 第一创新保持 Top-5 空间门＋站点身份偏置＋退化基线初始化＋冻结 PatchTST，不增加第二套空间门。
2. 第二创新必须属于中心站自身的目标估计/训练机制；空间 off/on 与该机制 off/on 将来必须能组成完整 2×2。
3. PM10 只可作为训练期中心站辅助标签，除非另行显式声明部署时 PM10 历史输入；不得偷用验证/测试目标，也不得使用未来 PM10。
4. 普通 shared-backbone MTL、直接预测 `PM10-PM2.5`、硬令 `PM10_hat=PM2.5_hat+coarse_hat`、非负输出、MinT/OLS/WLS reconciliation 均须作为近邻或强基线，不得换名声称新范式。
5. 若候选只是在可逆线性重参数化下等同于双输出 MTL，或完全同构于现成 forecast reconciliation，理论 STOP。
6. 真实测量可能出现 `PM10<PM2.5`；不得删样本、clip 后伪称物理真值，也不得用全序列估计违反率、噪声协方差或阈值。
7. `log1p` smearing、Student-t/概率头、事件状态、频域/VMD、多尺度换名、跨站共享监督和前轮已止损机制继续封存。
8. 即使理论 GO，也只能从最新稳定 `main` 新建带 round12 的实验分支并先运行纯合成 L0；北京1013、广州9022/9027和 confirmation 资源继续封存。

## 必答审计题

- 辅助 PM10 标签相对只看 PM2.5 的信息增益来自哪里？
- 在无限容量共享骨干下，候选是否退化为独立 heads，PM10 对 PM2.5 无净约束？
- 层级约束的收益如何与“多一个监督信号”“输出非负”“参数量变化”分离？
- 与 Hyndman 等 forecast reconciliation、MinT、hierarchical neural forecasting 和普通 auxiliary-task learning 的公式差异是什么？
- 测量误差导致层级违反时，候选是否仍识别目标条件均值，而不是强行投影到错误锥？
- H=1 必须非退化；不能只靠跨 lead 协方差或多步 reconciliation。

## 阶段门

理论阶段只能 GO 到一个满足下列条件的最小机制：

1. 给出明确 estimand、信息集和训练/推理公式；
2. 给出至少一个与 ordinary MTL/MinT 可分离的机制臂；
3. 给出乘性或测量噪声下的主 DGP，以及“辅助无信息”“层级偶发违反”负对照；
4. H=1 与 H=6 均定义且不靠新增空间信息；
5. 先例审计承认归属，若与最强同信息集方法完全同构则 STOP；
6. 明确未来 L0 只用 synthetic seeds，所有训练/阈值/协方差仅 fit 时间拟合，并设置不少于 5% 的双任务主效应门和机制归因门。
