## 2. 主代理独立复核

### 2.1 代码事实（`main@1a26492`，不训练即可判定）

- `run_st_patchtst_ablation.py:161` 只读 `usecols=["time", "PM25_Concentration"]`：PM10 从不进入任何信息集 `I_t^S`。
- `run_st_patchtst_ablation.py:464-466` 对 `model.patch_tst.parameters()` 全体设 `requires_grad=False`：冻结主干成立。
- `ST_PatchTST_model.py:375,400`：`base_prediction = patch_tst(center_x)`，`prediction = base_prediction + forecast_residual`。

由后两条可得 **P4**：冻结主干下 PM2.5 读出来自不可训练的骨干，任何辅助机制对 PM2.5 的净影响只能经（i）可训练参数共享，（ii）预测间联合约束，或（iii）测量模型去偏三条通道。若辅助头与 PM2.5 修正头不共享可训练参数且无联合约束，则 PM10 监督对 PM2.5 预测的净影响恒为零。该命题与训练结果无关。

### 2.2 代数复核（数值验证）

- **同设计 SUR-GLS 恒等于逐方程 OLS。** 设 `X = I_q ⊗ X`、`Ω = Σ ⊗ I_n`，则
  `(X'Ω⁻¹X)⁻¹X'Ω⁻¹ = [Σ ⊗ (X'X)⁻¹][Σ⁻¹ ⊗ X'] = I_q ⊗ (X'X)⁻¹X'`。
  以随机满秩设计、非对角 `Σ` 与 FGLS 两种形式数值验证：最大偏差 `9.4e-16`（OLS）、`1.5e-15`（FGLS）。
  ⇒ 交叉方程误差相关本身不产生 PM2.5 系数效率收益；只有设计差异、缺失格局差异或跨方程约束才会打破填平，而后两者已不是“协方差带来 SUR 收益”。
- **观测等价反例。** 取 `C = c > 0`，`W, U25, U10` 独立零均值：
  - DGP-A：`F = m + W`，`e = (U25, U10)`；
  - DGP-B：`F = m`，`e = (W + U25, W + U10)`。

  二者给出同一 `(Y25, Y10)`（数值最大差 `1.8e-15`，仅浮点结合序差异），且 `C ≥ 0` 在两侧都成立。共享系统偏差 `(d, d)` 同样可等价并入潜在均值而观测分布不变。
  ⇒ 单次配对标签无法把“潜在 coarse 创新”与“测量误差/共享偏差”分离；识别只能来自 replicate、reference/instrument 或第三指标等排除限制，本轮三者皆无。
- **推理期不可见性。** 若 `Y25 = m25(X) + B + U`、`Y10 = m10(X) + B + V` 且推理时看不到未来 `Y10`，则 `E[Y25 | X] = m25(X)`，零均值共享随机偏差对个体预测无更新价值；只有同时观测到 `Y10` 时才有非零 oracle 更新项。
- **潜成分重参数化。** `(F, C) → (PM2.5, PM10)` 的行列式为 1，仍是可逆坐标变换；加 `C ≥ 0` 后精确等价于对双输出施加顺序锥约束，不产生第三个独立观测。

### 2.3 与最强同信息集方法的关系

即使放弃“可识别性”主张，候选剩下的全部内容分别是：普通相关目标 MTL（共享表征/额外监督信号）、已有的硬或软层级一致性正则、以及 `MinT`/非负 reconciliation 一类投影。前者是 `02` 的 A/C2 通道，后者已有直接先例（含一篇对 `PM2.5 ≤ PM10` 施加不等式调和的跨污染物论文，其卷期与同行评审状态未能独立确认，故只作警示、不作决定依据）。按边界第 4、5 条，这些只能作为强基线，不能包装成第二创新。

## 3. 阶段决定

**Round 12 理论 STOP。** 依据：

1. `01` 与 `03` 分别独立给出等价性与不识别结论，主代理复核成立；
2. E 臂的 GO 依赖“共享测量偏差存在且可在 fit 窗口识别”这一在观测上不可检验的前提，且一手证据（分粒径特异偏差、RH 驱动伪影）对其不利；
3. synthetic C1-positive 只能验证“假定前提成立时算法可运行”，无法验证真实数据中前提成立，因此不构成进入实验阶段的理由；
4. 去掉不可识别部分后，候选与普通 MTL 或已有层级一致性方法同信息集，触发边界第 5 条 STOP。

不授权：实验分支、模型实现、synthetic L0、真实站点数据、`confirmation` 资源、以及 4001–4003 之外的任何新种子登记。

禁止挽救路径：更换 DGP 直到出现增益、把“共享偏差”直接写进合成真值后宣称可迁移、用参数量或监督数不匹配的对照制造增益、把普通 MTL 收益改名为“层级一致性”、或只报告聚合层级指标。

## 4. 对外表述边界

- 可表述：在中心站只预测 PM2.5、推理期不含 PM10 的设定下，把 `PM10` 作为辅助标签并施加 `PM2.5 ≤ PM10` 一致性，无法识别测量误差结构；其净机制或与普通多任务学习同构，或与已有层级一致性/非负 reconciliation 方法同信息集，故不构成本项目的第二创新。
- 不可表述：不得声称“层级一致性方法无效”；不得声称已用真实数据验证；不得把本轮的不可识别性推广为对 measurement-error 领域的否定。
- 工程可留用的事实：`PM10` 辅助标签可作为**普通 MTL 强基线**保留在后续对照清单中，但不得据此宣称新机制。
