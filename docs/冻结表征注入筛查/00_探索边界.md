# Round 15 第二创新筛查：冻结主干的邻站信息注入机制

日期：2026-09-15。模式：**批量筛查**（工作流 §2.1，单分支按轮次追加提交）。依据：`docs/研究探索与实验验证工作流.md`、`docs/研究路线总表.md`、`docs/提交记录中文对照表.md`。

## 1. 为什么要开这一轮

- Round 13 的元审计结论是：在**同信息集、冻结主干、同一 estimand**下，当时已知的机制族全部违反至少一条必要条件（NC1–NC12），因此 STOP。
- 但该审计发生在**匹配组件消融之前**。2026-09-15 完成的匹配组件消融给出了一个新的实证线索：

| 变体（相对同 run 退化基线） | 端到端 24→1 | 冻结 24→1 | 端到端 168→6 | 冻结 168→6 |
|---|---|---|---|---|
| pairwise + delta（**输入端**注入） | +0.49% (3/3) | +2.44% (2/3) | +0.11% (2/3) | **+2.25% (3/3)** |
| pairwise + delta（预测端） | +2.70% (3/3) | +2.79% (3/3) | +1.08% (2/3) | +0.46% (3/3) |
| sparse + delta（预测端） | +2.69% (3/3) | +2.69% (3/3) | **+1.56% (3/3)** | +0.47% (3/3) |
| sparse + station-bias（预测端） | +2.61% (3/3) | **+3.28% (3/3)** | +1.46% (3/3) | +0.67% (3/3) |

  即：**在 168→6 上，最优注入位置随训练协议翻转**（端到端→预测端最好；冻结→输入端最好），而 24→1 上两种协议都是预测端略优。
- 这条观察目前**没有理论解释**，也从未作为独立课题被筛查过。它可能指向一个真实机制（"冻结表征需要不同的注入位置"），也可能只是容量/优化噪声（3 种子、且当年那次评估用的是 test 划分，只能算探索性）。
- 注意：该观察来自 test 划分的探索性运行。**任何候选的选择必须改用训练段/验证段重新建立证据**，不得直接引用 test 结果做结构选择。

## 2. 本轮问题

**在中心站＋固定邻站 PM2.5 历史（同信息集）、冻结主干＋退化初始化的生产协议、estimand 不变的前提下，是否存在一个可分离的、非容量驱动的"邻站信息注入"机制？**

候选必须满足下列之一才算有意义：

1. 能解释并利用上述"注入位置随协议/任务变化"的现象，且预测可被证伪；
2. 或给出一个与现有 `st_pairwise_delta` / `st_pairwise_delta_forecast` / `st_sparse_station_bias_delta_forecast` 都**不同构**的注入机制，并能在等容量对照下显示净收益。

## 3. 允许筛查的候选族

| 代号 | 候选族 | 说明 |
|---|---|---|
| A | **注入位置自适应** | 按预测时已可观测的信号（如历史长度、任务、邻站相关性结构）在输入端注入与预测端注入之间选择或加权 |
| B | **双通道结构化分工** | 同时使用两种注入，但两类信息分工明确（例如只让输入侧承载"均值偏移"、预测侧承载"残差修正"），必须有等容量对照 |
| C | **冻结适配的输入侧算子** | 把邻站信息编码为可学习的输入侧前缀/偏置/低秩修正，改变冻结主干的输入表示，但**不重新学习邻站权重选择**（不得构成第二套空间门） |
| D | **表示层适配目标** | 冻结主干下，用辅助目标或对比目标把邻站信息写入可训练部分（必须与主线残差槽共享参数） |

**不在本轮范围**：新增可观测通道（气象/其他污染物，需显式放宽信息集）、解冻主干（PIVOT-C）、任何已止损族（频域/多尺度、日历、重变换、层级一致性、检索、迁移支持域、事件状态、缺测状态）。

## 4. 硬约束（违反即 NO-GO）

1. 信息集与 BASE 完全一致（中心站＋固定 Top-5 邻站的历史 PM2.5）。
2. 不得新增第二套空间门：候选不得重新学习"选哪些邻站/邻站权重"；若必须，只能复用已固定的 Top-5 门控输出。
3. estimand 不变（物理尺度观测 PM2.5 条件均值）；H=1 与 H=6 均非退化。
4. 必须与最强同信息集现成算法**不同构**（给出估计方程层面的对照），否则只能降级为基线。
5. **NC13 等容量特异性门**：必须同时胜过"同信息集基线"和"容量匹配但去除所声称结构"的对照臂。
6. 训练协议固定为生产配置（冻结主干＋退化初始化）；若要比较协议，必须两种协议都跑并分开报告，不得合并。
7. 本轮筛查只能使用**训练段/验证段**选择结构与超参数；测试段仅在确认阶段一次性使用。
8. 3 种子仅作筛查证据，不得声称显著性；确认需要新的 5 种子（若资源允许）。
9. 每轮筛查结束必须同步 `docs/研究路线总表.md` 与本研究目录；候选单独成节，便于按候选检索。
