# 冻结主干的邻站信息注入：先例与等价性审查

## 1. 审查范围、材料与判定口径

本审查只使用 `00_探索边界.md`、仓库当前 Markdown、当前 `ST_PatchTST_model.py` 与 `run_st_patchtst_ablation.py`，以及公开的一手论文。未读取 `01_*`，未读取 CSV、JSON、checkpoint、站点数据或旧实验产物，未训练模型，也未修改 `plan/*`。检索于 2026-09-15 完成，关键词覆盖 frozen backbone、input/output injection、prompt/prefix、adapter、LoRA、FiLM、side-tuning、mixture-of-experts、routing、residual/concatenation、linear probe、representation similarity 与 Jacobian/gradient flow。引文计数不参与原创性或机制判定，故未采集；文末逐条给出正式论文页、DOI 或 arXiv 标识。

这里把两个问题严格分开：

1. 函数类分离：在明确限制可见变量、参数量、算子位置和输出范围后，两个估计器能否互相表示。
2. 方法分离：即使函数类不同，该差异是否已经属于 prompt、adapter、FiLM、side-network、MoE、残差或拼接等现成方法的一个实例。

只有两层都通过，才可称为本轮的可分离机制。仅观察到两个位置的验证误差不同，不构成分离证明；它也可能来自参数量、梯度条件、正则化、初始化或训练难度。

## 2. 当前代码对应的估计方程

记中心站历史为 $x\in\mathbb R^n$，复用既有 Top-5 门控汇聚后的邻站信息为 $z$，冻结 PatchTST 主干为 $f:\mathbb R^n\to\mathbb R^m$。当前输入端实现为

\[
\hat y_I=f\!\left(x+\alpha d_\theta(x,z)\right),
\]

对应 `ST_PatchTST_model.py:365-367`。预测端实现为

\[
\hat y_O=f(x)+\alpha\,c_\phi(x)\odot\tanh r_\phi(x,z),
\]

对应 `ST_PatchTST_model.py:373-400`；不开置信门时 $c_\phi\equiv1$。这里把成对门对中心站的依赖计入 $r_\phi(x,z)$；邻站差值、成对门、站点偏置和 Top-k 在两式之前产生共享空间上下文，见 `ST_PatchTST_model.py:272-328`。运行器只冻结 `model.patch_tst`，空间分支仍可训练，见 `run_st_patchtst_ablation.py:464-466`。

这两个现有臂并非纯粹的“位置替换”：预测端还增加时序卷积、池化和输出头，而输入端使用 `neighbor_out` 生成与历史等形的修正。因此，若不匹配训练参数、激活宽度、FLOPs、初始化尺度与正则化，位置差异和容量差异不可辨识。

## 3. 输入修正与输出修正的函数类

### 3.1 一般情形不等价

给定允许的输入修正集合 $D_{x,z}$ 和输出残差集合 $R_{x,z}$，两类相对基线的可达集合为

\[
\mathcal A_I(x,z)=\{f(x+\delta)-f(x):\delta\in D_{x,z}\},\qquad
\mathcal A_O(x,z)=R_{x,z}.
\]

两类全局等价的充要表述是：对每个 $(x,z)$，两集合相等，且两边的参数共享关系也能互相实现。只比较单个样本上的数值相等不够，因为一个参数化网络必须同时实现全部样本的映射。

当 $f$ 可微且修正较小时，

\[
f(x+\delta)-f(x)=J_f(x)\delta+O(\lVert\delta\rVert^2).
\]

输入端的一阶修正被限制在 $\operatorname{Im}J_f(x)$ 中；输出残差若可取该子空间外方向，就严格更广。若 $J_f(x)$ 行满秩且输入修正不受约束，输入端在该点附近可局部覆盖全部输出方向。若主干存在降维、饱和、裁剪或不可逆预处理，行满秩条件可能失败，输入端还受 $f$ 的像集约束，而加性输出端可以离开该像集。

反方向也存在分离。若输出头只能读取 $z$，它通常不能表示 $f(x+\delta(z))-f(x)$ 中由 $J_f(x)$ 乃至高阶项产生的中心状态依赖；当 $f$ 为仿射映射、Jacobian 为常数，或输出头同时读取 $x,z$ 且表达力充足时，这一差异消失。特别地，只要输出残差族允许

\[
r(x,z)=f(x+\delta(x,z))-f(x),
\]

它就逐点包含输入端函数类。反过来，若局部逆存在且输入修正族允许

\[
\delta(x,z)=f^{-1}(f(x)+r(x,z))-x,
\]

输出端也可被输入端复现。故“冻结主干”本身既不保证等价，也不保证某一位置更强；结论由 $f$ 的局部几何、两侧可见变量和算子约束共同决定。

### 3.2 梯度路径确有差异，但不是效果排序定理

输入端参数的梯度含冻结主干 Jacobian：

\[
\nabla_\theta L=(\partial_\theta\delta)^\top J_f(x+\delta)^\top\nabla_{\hat y}L.
\]

输出端则为

\[
\nabla_\phi L=(\partial_\phi r)^\top\nabla_{\hat y}L.
\]

输入端学习信号会被主干的奇异值谱旋转、放大或压缩；输出端绕开该过滤。输入端同时能利用主干已有非线性特征，输出端则需在侧网络中自行拟合修正。哪一项占优取决于任务信号与 $J_f$ 有效子空间的对齐、样本量、修正尺度和侧网络容量，不能由上述公式推出跨任务的统一优劣。

### 3.3 本项判定

判定为“数学上条件可分离，方法创新尚未成立”。若候选只写“输入端更适合冻结表示”或“输出端梯度更直接”，没有给出受限 $D_{x,z}$、$R_{x,z}$ 及不可互相表示的见证函数，应驳回。若输出侧允许读取同样的 $x,z$ 并具有通用逼近能力，输入端优势只能解释为归纳偏置或优化差异，而不是可达函数类优势。

## 4. 参数高效适配先例与同构判定

| 方法族 | 一手方法的核心算子 | 与本轮候选的关系 | 判定 |
|---|---|---|---|
| Prompt-tuning / Visual Prompt Tuning | 冻结主干，在输入嵌入前拼接可训练连续提示；VPT 明确在视觉输入空间加入少量参数 | 邻站编码若只形成输入 token、前缀、偏置或低秩输入修正，属于条件化 prompt 的直接推广 | 同构或强覆盖；降级为输入侧基线 |
| Prefix-tuning | 在各 Transformer 层的注意力键值上下文加入连续前缀，原模型参数冻结 | 若“注入位置”扩展为每层前缀，它是 deep prefix，不再是新的位置机制 | 同构；降级为 prefix 基线 |
| Adapter / AdaptFormer | 在冻结块内插入瓶颈残差模块 | 隐层邻站适配若采用降维—非线性—升维并残差相加，即为条件化 adapter | 同构；降级为 adapter 基线 |
| LoRA | 冻结原权重，以低秩 $BA$ 改写层内线性映射 | “低秩注入”若作用于主干权重，实际有效映射已改变；它不是固定函数 $f$，但属于标准 PEFT | 同构；若坚持 $f$ 完全固定则越界，否则作 LoRA 基线 |
| FiLM / SSF | 由条件变量产生逐特征仿射变换 $\gamma(z)\odot h+\beta(z)$ | 邻站信息对输入或隐表示做缩放/平移即为条件 FiLM；只有加性偏置时是其子类 | 同构；降级为 FiLM/SSF 基线 |
| Side-Tuning / LST | 冻结主网，训练侧网；在输出相加或由主干中间层经 ladder 跳连送入侧网 | 当前预测端 `base_prediction + forecast_residual` 是输出级 side-network；多层取特征则为 LST | 同构；降级为 side-network 基线 |
| ControlNet 型控制支路 | 锁定大主干，以零初始化连接把条件支路逐层注入 | “退化初始化＋冻结主干＋条件侧支路”已有非常接近的工程先例 | 强覆盖；零初始化不是独立机制 |

Prompt 理论还给出一个重要边界：某些固定 Transformer 与有限深度条件下，任意长度 prompt 也不能记忆特定数据集，prefix 不能任意改变内容 token 间的相对注意模式；另一些经过构造的固定 Transformer 又能通过 prompt 实现通用逼近。这些结果共同否定了“输入前缀天然弱”或“天然万能”的无条件说法，也没有为本项目的 PatchTST 给出位置排序。

## 5. MoE、路由与“位置自适应”

设输入专家 $e_I(x,z)=f(x+\delta(x,z))$，输出专家 $e_O(x,z)=f(x)+r(x,z)$。按可观测量 $q(x,z,H)$ 自适应加权的位置模型

\[
\hat y=g(q)e_I(x,z)+(1-g(q))e_O(x,z)
\]

就是两专家的软路由；若取 Top-1 或阈值选择，则是硬路由。MoE 的定义正是由输入依赖门控对专家输出做选择或加权，已有工作还直接研究稀疏 Top-k、按样本或 patch 路由以及门与专家的可辨识/优化问题。因此：

- 学习 $g$ 不构成新的“位置机制”，而是以注入位置作为专家身份的 MoE。
- $g$ 只依赖任务常量（如 $H$）时，更接近分任务模型选择，不是样本级适配。
- $g$ 读取邻站结构并重新学习选站时，还违反“不得新增第二套空间门”的边界。
- 复用固定 Top-5 后再做位置门虽不违反选站约束，仍须把标准两专家 MoE 作为同构基线。

本项判定为“被 MoE/条件路由覆盖”。除非候选能提出 MoE 估计方程不能表示的约束与可检验后果，否则降级为路由基线。

## 6. 拼接、残差、跳连与“双通道分工”

双通道若写成

\[
\hat y=f(x+\delta_1(x,z))+r_2(x,z),
\]

它是输入适配器与输出 side-network 的并联残差。若把两通道特征拼接后接线性头，

\[
W[h_1;h_2]=W_1h_1+W_2h_2,
\]

仍等于两支路加性融合；接非线性头只会得到更一般的特征融合网络。ResNet 已系统化加性残差，DenseNet 明确以拼接保留并复用不同层特征，Side-Tuning 与 LST 则直接覆盖冻结主干旁的输出支路和跨层跳连。

“一条通道负责均值偏移、另一条负责剩余修正”只有在分解可识别时才可能比普通双支路更具体。若两个分量最终只按和进入损失，则对任意函数 $a(x,z)$，

\[
(r_1,r_2)\mapsto(r_1+a,r_2-a)
\]

保持总预测不变，分工不可识别。单靠命名、正则项或结构示意图不能证明各支路学到了声称角色。

本项判定为“普通形式被拼接/残差/side-network 覆盖；带可识别约束的特殊形式理论上可分离，但当前证据不足”。可识别约束至少要给出正交子空间、已知投影、互斥频带或其他唯一分解；其中频域/多尺度又受本轮禁区约束，不能借此复活已止损方向。

## 7. 冻结表示下“哪种注入更有效”的理论证据

现有理论与诊断工具能回答局部问题，不能给出本任务的统一排序。

线性探针衡量目标是否能从某层冻结表示线性读出；Head2Toe 说明联合使用多个中间表示可能优于只读末层。CKA 衡量两组表示的相似性。它们都是表示可用性或相似性的诊断，不是“输入修正优于输出残差”的因果判据：探针成功不说明邻站条件能够沿输入扰动写入该表示，CKA 高也不说明预测相关方向被保留。

NTK 和 Jacobian 线性化支持第 3 节的一阶分析，但其结论依赖局部、小扰动或宽网络条件。Prompt 表达力论文证明了特定固定 Transformer 上的通用性与反例；它们没有覆盖任意已训练 PatchTST。关于线性探针与微调的工作表明，冻结特征质量、分布偏移和目标样本量会改变适配策略排序，但比较对象通常是末层探针与解冻微调，也不是本轮的输入/输出邻站注入。

故本次未找到“一般冻结表示下某个注入位置必然更有效”的理论结果。可以使用 Jacobian 谱、探针和 CKA 产生机制预测，但不得把它们当作性能结论：

- 若邻站诱导的目标修正主要落在 $\operatorname{Im}J_f(x)$，输入端不受一阶可达性限制；反之输出端有表达优势。
- 若输入修正后目标相关线性探针改善，而保持容量的伪修正不改善，才支持“利用冻结表示”的解释。
- 若只有验证 RMSE 改善，而 Jacobian 对齐、位置交换或通道归因不随之变化，位置机制解释被否证。

## 8. 可证伪判据与 NC13 等容量对照

任何声称“可分离”的候选都必须先写出以下四项，缺一项即按现成基线处理：

| 必需项 | 可证伪要求 |
|---|---|
| 估计方程 | 明确 $f,D_{x,z},R_{x,z}$、每个模块可见的变量、是否复用既有 Top-5 门控，以及 H=1/H=6 的张量形式 |
| 分离见证 | 给出至少一个候选可表示而最强现成基线不可表示的函数，并证明差异不是通过扩宽输出侧网络即可消除 |
| 机制预测 | 在看验证结果前规定 Jacobian 对齐、路由选择、通道投影或干预响应的方向；预测失败即否证机制 |
| 选择规则 | 只用训练段/验证段，预先固定实际收益阈值；3 种子仅筛查，确认使用新的 5 种子与未消费资源 |

NC13 至少需要下列臂，且数据、固定 Top-5 信息、退化 checkpoint、冻结主干、优化器、训练步数、最佳模型规则和随机种子完全配对：

| 臂 | 作用 |
|---|---|
| B0：退化 $f(x)$ | 无邻站信息的精度锚点 |
| B1：当前输入端 delta | 最强同信息集输入基线 |
| B2：当前预测端残差 | 最强同信息集输出基线 |
| C-cap：容量匹配无结构控制 | 与候选相同训练参数量、深度、激活、FLOPs 和零初始化，但把声称的位置/分工约束替换为普通 MLP 或同位置双头 |
| C-family：同构家族控制 | A 用标准两专家 MoE；B 用无分工的拼接/双残差；C 用同秩 prompt/prefix/adapter；D 用相同辅助损失但打乱或阻断声称的表示写入路径 |
| M：完整候选 | 只能复用固定 Top-5 门控，不得再学习选站 |

放行必须满足 M 同时胜过 B1、B2、C-cap 与 C-family，而不是只胜过退化 B0。还需满足候选预注册的机制预测。参数量相等但计算图深度、输入维数或梯度路径不同，仍不是充分的等容量控制，应同时报告训练参数、前向 FLOPs、峰值激活和每臂实际更新次数。

各候选族的专属否证条件如下：

- 位置自适应：若静态混合、标准 MoE 或打乱位置标签的同容量路由不差于候选，则“位置规律”被否证并降级为 MoE。
- 双通道分工：若交换两支路投影、解除分工约束或用普通拼接头不降性能，则分工解释被否证并降级为残差/拼接。
- 输入侧算子：若可重参数化为同秩 prompt、prefix、adapter、LoRA 或 FiLM，或其对应基线不差于候选，则降级为该 PEFT 基线。
- 表示层辅助目标：辅助目标只改变优化而不改变推理函数类。若打乱辅助标签、stop-gradient 或等权普通正则不差于候选，则“写入冻结表示”的解释被否证；若推理时仍仅为既有输出残差，则不形成新的注入机制。

## 9. 总判定

本轮不能判为“全部同构”，因为在受限可见变量、低秩/有界修正或秩亏 Jacobian 下，输入端与输出端确有可证明的不等价函数类。也不能判为“可分离候选存在”，因为目前可自然提出的三种结构——位置自适应、双通道、输入侧低秩/前缀——分别被 MoE 路由、残差/拼接/side-network、prompt/prefix/adapter/FiLM/LoRA 覆盖；单纯的位置差异不够形成新机制。

因此结论为：证据不足，当前不建议据此进入模型实验。补证所需的最小材料不是更多架构命名，而是：(a) 对 PatchTST 冻结映射给出受限函数类的分离见证；(b) 给出不能由相应 PEFT、MoE 或 side-network 表示的结构约束；(c) 在训练段/验证段上用 Jacobian/干预诊断验证预注册机制预测；(d) 通过第 8 节的 NC13 双重门。若做不到 (a) 或 (b)，候选应直接降级为现成基线，不应作为第二创新。

## 11. 修订复核

复核对象仅为 `01_候选机制.md` 新增的“§6 修订：函数类分离见证与机制重述”，并逐项对照本文件 §8–§9 的四项补证要求。结论为：应改判 NO-GO，不要求进入实验。修订已经形成一个可执行的窄 PTI–PTO 比较，但没有证明 PTI 不能被广义条件 prompt/adapter 或读取同样变量的输出 side-network 表示，因而仍未通过 `00_探索边界.md` 的不同构硬门与 NC13。

### 11.1 四项补证要求的签署结果

| 要求 | 复核判定 | 理由与精确缺口 |
|---|---|---|
| (a) 受限函数类的分离见证 | 部分满足，未通过 | DGP-交互严格分离了 $R_H(T(z+\Delta(c)))$ 与被限定为 $F_H(x)+g_H(c)$ 的 PTO；但允许输出侧读取同样的 $x,c$ 后，$r(x,c)=R_H(T(E(x)+\Delta(c)))-R_H(T(E(x)))$ 可精确复现 PTI。修订没有证明扩宽为最强同信息集 side-network 后仍不可表示，故只证明了对一个刻意受限 PTO 的分离。 |

### 11.2 混合差分是否是有效见证

混合差分

\[
I_f=f(x_a,c_a)-f(x_a,c_b)-f(x_b,c_a)+f(x_b,c_b)
\]

是检验二元函数是否具有加性可分形式 $F(x)+g(c)$ 的有效见证。在 DGP-交互的笛卡尔支持上，真值确为 $q_Hb(z_a-z_b)(c_a-c_b)$，而严格加性 PTO 的混合差分为零；这一代数结论成立。DGP-加性又把入口和出口都能达到的同一加性方向列为反向控制，修正了“PTI 失败可能只是入口不可达”的一部分混淆。

它仍不是所声称机制的充分见证。第一，见证的零假设只是狭窄的 $F(x)+g(c)$，不是一般输出残差 $F(x)+r(x,c)$；后者可有非零混合差分。第二，冻结非线性 $T$ 会让任何入口平移产生算子交互，$I_f\neq0$ 本身不说明这种交互对应真实条件均值或带来泛化收益。第三，现有加性 DGP 只覆盖一个共同可达方向，没有加入“出口可达、入口不可达但仍纯加性”的 DGP；因此尚未验证诊断流程能把可达性受限明确归为 accessibility failure，而不会误写成机制失败或交互证据。

若仅把 $I_f$ 用作窄 PTI–PTO 实现测试，它有效；若把它作为“不同于 side-network 的新机制”见证，则无效。最低补项应包含允许 $x,c$ 交互但参数/FLOPs 匹配的 PTO-X 控制，以及一个已知入口不可达的纯加性 DGP。即便补齐，这也只能建立条件 prompt 相对特定输出控制的归纳偏置，不能解决 (b) 的方法族覆盖。

### 11.3 DGP 阈值、容差与误判风险

“10/10 同向＋平均 RMSE 降幅至少 20%”“混合差分归一化 RMSE 不超过 5%”以及加性 DGP 的 ±0.5%/±1% 等价界都具有明确失败事件，形式上可证伪。当前仍缺少决定这些门是否可达的噪声标准差 $\sigma$；交互 DGP 的 RMSE 相对优势随 $\sigma$ 变化，未固定噪声便无法预注册 20% 门。H=6 的 RMSE、目标标准差和混合差分误差按 lead 分别计算还是池化也未定义。

PTO 的 $10^{-6}\times\mathrm{sd}(y)$ 数值容差适合作为确定性代数单元测试，却依赖 dtype、设备和运算顺序；应固定 float64 参考计算，或用预先校准的绝对误差＋相对误差组合。真实数据中的“缩至原值 20% 以内或反向”在原值接近零时比值不稳定；“|I| 较大组贡献正改善”也缺少固定分位点、样本数和聚合统计量。上述缺口使 DGP 门虽可执行，却还不是不可后调的完整判据。

### 11.4 PTI–PTO 参数同一性

同一 $32\to4\to16$ 生成器、同一 $\alpha$、213 个新增参数、张量形状、初始化值和优化器状态一一对应，并要求入口/出口 token 经无参数可逆置换严格对齐，这比只匹配总参数量严格得多，足以排除大部分显式容量差异。213 的计数可理解为两层生成器的 212 个权重/偏置参数加 1 个全局 $\alpha$。

它仍不足以完成 NC13。PTI 为了对生成器求梯度必须反向穿过冻结 $T$，PTO 不需要；两者的梯度条件、峰值激活和反向计算量天然不同。“相同停止规则”还可能产生不同更新次数，不能替代固定更新预算或配对报告实际更新次数。必须固定训练/评估模式、dropout 随机流、精度与梯度裁剪，并报告前向 FLOPs、反向 FLOPs、峰值激活和更新步数。更关键的是，逐项同一只保证 PTI 与窄 PTO 公平，不能替代 PTO-X、B1/B2 和 PEFT C-family 对照。

### 11.5 真实数据终点与最终决定

§6.5 明确规定只用训练段拟合、验证段判定，3 个配对筛查种子，且交叉诊断不读取目标来重算空间门；就结构选择和主终点而言，没有使用测试段，满足 `00_探索边界.md` 的数据边界。后续独立确认的测试段与新 5 种子安排没有在本修订中展开，但这不影响理论筛查阶段的切分合规性。

最终仍应改判 NO-GO，理由有二。其一，(b) 是当前边界下的原创性硬门，而修订主动承认 PTI 属于广义条件 prompt/adapter，输出 side-network 也能表示其见证函数；这个缺口不能靠更多 DGP 重复或更严阈值修复。其二，(d) 缺少 B1、PTO-X/C-cap 与 PEFT C-family，对真实数据的 NC13 尚未闭合。若未来把研究问题改成“固定参数预算下，条件 prompt 借用冻结主干非线性是否比特定输出残差更参数高效”，它可以作为 PEFT 内部的基线研究重新立项；在本轮“必须与现成方法不同构”的边界内，不应进入实验。
