# 冻结表征注入候选机制

日期：2026-09-15。本文只做理论筛查，不使用测试段、站点原始数据、checkpoint 或历史性能表。结论针对冻结 PatchTST 主干、退化初始化、北京中心站 1013、中心站与固定 Top-5 邻站 PM2.5 历史这一既定信息集；预测目标仍为物理尺度 PM2.5 条件均值。

## 1. 记号与共同约束

记中心站历史为 \(x\in\mathbb R^L\)，第 \(i\) 个邻站历史为 \(x_i\)，差值为 \(d_i=x_i-x\)。现有且唯一的 Top-5 空间门输出记为 \(w_i(x,x_i)\)，含空邻站时 \(\sum_iw_i\leq1\)。所有候选与对照必须共用同一个 \(w_i\)、同一组邻站和同一邻站投影，不允许候选另算站点分数。共享邻站隐藏上下文为

\[
c_t=\sum_{i\in\mathrm{Top5}}w_i\,\phi(d_{i,t})\in\mathbb R^{q},\qquad q=32.
\]

为比较注入位置，将冻结 PatchTST 写成 \(F_H=R_H\circ T\circ E\)：\(E\) 是中心序列到 patch token 的映射，\(T\) 是保持 token 宽度 \(d=16\) 的冻结编码器，\(R_H\) 是冻结预测头。该分解在当前 `ST_PatchTST` 包装层中未暴露；进入实现前必须确认实际 PatchTST 能在不复制、不改变参数和随机数路径的条件下暴露 \(E,T,R_H\)。不能做到即止损。

现有三类估计式是：

\[
\begin{aligned}
\texttt{st\_pairwise\_delta}:&\quad \hat y=F_H(x+\alpha C(c)),\\
\texttt{st\_pairwise\_delta\_forecast}:&\quad \hat y=F_H(x)+\alpha\tanh G_H(c),\\
\texttt{st\_sparse\_station\_bias\_delta\_forecast}:&\quad
\hat y=F_H(x)+\alpha\tanh G_H(c^{\mathrm{Top5+bias}}).
\end{aligned}
\]

主指标统一为验证段物理尺度 RMSE，MAE 为共同方向的次指标。三种筛查种子只用于决定是否值得进入独立消融，不能支持显著性表述；若放行，确认阶段另用 5 个未消费种子。

## 2. 候选 A：冻结编码器入口的 patch-token 平移（PTI）

### 2.1 机制、信息集与两个预测任务

将 \(c\) 按 PatchTST 的既定 patch 边界汇总为 \(c_p\in\mathbb R^{32}\)。同一个低秩生成器逐 patch 产生 token 平移：

\[
a_p=\operatorname{GELU}(W_1c_p+b_1),\qquad
\Delta z_p=\alpha\tanh(W_2a_p+b_2),
\]

其中 \(W_1\in\mathbb R^{r\times32}\)、\(W_2\in\mathbb R^{16\times r}\)，固定 \(r=4\)，\(W_2,b_2\) 零初始化。候选估计量为

\[
\hat y^{\mathrm{PTI}}_H=R_H\!\left(T\!\left(E(x)+\Delta Z(c)\right)\right).
\]

信息集仍只有 \(\{x,x_i:i\in\mathrm{Top5}\}\)，patch 划分、\(w_i\) 和 \(\phi\) 均与共同基线共享。\(H=1\) 时，\(R_1\) 把经冻结编码器传播后的全部 token 映射为一个标量；\(H=6\) 时，同一份 \(\Delta Z\) 只经过一次 \(T\)，再由固定 \(R_6\) 同时产生 \((\hat y_{t+1},\ldots,\hat y_{t+6})\)。候选没有逐预测步可训练分支，因此两个任务均非退化，且 H=6 的六步耦合完全继承冻结主干。

机制假设是：冻结编码器已经形成有用的时间表征，但原始中心输入不能沿邻站提示的方向移动其 patch token；在编码器入口做小幅平移，可以让固定的注意力和前馈变换传播该信息。这里检验的是“进入冻结编码器之前”这一位置，而不是再增加一个预测器。

### 2.2 与现有变体的公式差异

PTI 不等于输入端 delta。若存在某个原始序列修正 \(C\) 使两者恒等，至少要对全部 \(x,c\) 满足

\[
E(x+C(c))=E(x)+\Delta Z(c).
\]

Patch 嵌入还包含既定的归一化、patch 化和位置处理；除非 \(\Delta Z\) 被限制在 \(E\) 对原始输入可达的像空间且与这些操作交换，上式一般不成立。PTI 直接改变 token，现有输入端变体只改变物理历史值。这一可分离性必须用实现阶段的数值测试确认：随机 \(x,c\) 上求最优输入扰动后仍不能把 token 误差降到预设容差，否则 PTI 降级为输入端基线。

PTI 也不等于两个预测端变体。预测端式允许 \(G_H(c)\) 绕过 \(T\) 后直接加到输出；PTI 的邻站效应为

\[
R_H(T(E(x)+\Delta Z))-R_H(T(E(x))),
\]

它依赖中心状态 \(x\) 及冻结编码器的非线性传播，且 H=6 的步间结构受同一个 \(T,R_6\) 约束。只有当 \(R_H\circ T\) 对全部相关 token 都是同一个仿射映射，且 \(G_H\) 被相应约束时，两式才可能重合。Top-5 与站点偏置只改变 \(c\) 的来源，不改变这一注入位置差异。

### 2.3 参数量与 NC13 等容量对照

PTI 新增的有效可训练参数为

\[
P_{\mathrm{PTI}}=r\times32+r+16\times r+16+1=213,
\]

末项的 1 是有界全局幅度 \(\alpha\)。参数量与 H 无关。若把当前成对门、站点偏置、空邻站和共享投影计入，共享上下文为 \(P_{ctx}=642+N\)，其中 \(N\) 是进入门控的邻站数；候选有效可训练总量为 \(855+N\)。当前类中未被该前向路径使用的 `center_gate`、`neighbor_out`、`spatial_temporal_encoder`、`spatial_forecast_out` 和 `forecast_confidence` 必须冻结并从有效参数计数中排除。

NC13 对照臂为编码器出口 token 平移（PTO）：

\[
\hat y^{\mathrm{PTO}}_H=R_H\!\left(T(E(x))+\Delta Z(c)\right).
\]

PTO 使用逐元素完全相同的 \(W_1,W_2,b_1,b_2,\alpha\)、输入、初始化和优化器，参数也是 \(213\)，只是把同一 \(\Delta Z\) 从 \(T\) 前移到 \(T\) 后。它去掉了所声称的“邻站扰动经冻结编码器传播”结构，同时保留邻站信息、token 空间、低秩生成器和容量。若实际编码器入口与出口 token 形状不一致，只允许使用固定、无参数的 reshape/裁剪；需要可学习投影则无法严格等容量，候选止损。

### 2.4 可否证筛查

正对照采用不接触真实数据的合成 DGP。固定一个带非线性且入口、出口不交换的冻结编码器 \(T_0\)，令

\[
y=R_H(T_0(E(x)+B c))+\varepsilon.
\]

PTI 应在 H=1 和 H=6 都优于 PTO，并恢复 \(Bc\) 的方向；若在三个合成种子中不能全部满足，说明实现或机制本身不具识别力，不进入真实数据筛查。结构负对照有两项：把 \(c\) 在样本间固定置乱后，PTI 相对中心基线的收益应消失；把 DGP 改成 \(y=R_H(T_0(E(x)))+A_Hc+\varepsilon\) 后，PTI 不应继续稳定胜过出口/预测端对照。否则观察到的只是容量或泄漏。

真实数据只用训练段拟合、验证段判定，固定 H=1 与 H=6、\(r=4\) 和唯一入口位置，不扫层、不扫秩。每个任务同时运行退化 PatchTST、三种现有变体、PTI 和 PTO。PTI 放行须在每个任务上同时满足：相对 `st_sparse_station_bias_delta_forecast` 和 PTO 的配对验证 RMSE 均为 3/3 改善；两项平均相对改善均至少 0.5%；MAE 不出现 2/3 以上反向；邻站样本置乱后，相对退化基线的 RMSE 收益缩至原收益的 20% 以内或转负。任一任务失败，则不能用“按任务选择位置”保留另一任务，整项止损。

### 2.5 排除换名解释与效应量

PTI 没有把邻站作为新通道拼接给主干，主干输入通道数不变；它只在既有 patch token 上做低秩平移。它没有候选专家、离散路由或样本级位置选择，因此不是 MoE。入口、秩和幅度上界在实验前固定，不以验证结果挑选，因此不是超参数选择。空间权重只来自共同的 \(w_i\)，没有第二套空间门。

匹配消融中的位置差异处于百分比量级，因此对 PTI 相对最强现有变体只预期 0.5%–1.5% 的验证 RMSE 改善；更大的结果应优先排查实现和尺度。3 个配对种子足以按上述硬阈值做低成本筛查，但不足以估计显著性；通过后需要 5 个新种子做方向一致性确认。没有未读方差估计，不能声称 5 种子具有给定统计功效。

### 2.6 候选判定

条件 GO。PTI 在公式上同时区别于原始输入扰动和输出加性残差，并存在参数逐项相同、只删除编码器传播结构的 PTO 对照，满足 NC13。GO 的前提是实现阶段先证明 token 分解可无侵入暴露、入口与出口形状可零参数对齐，以及 PTI 不落入原始输入映射的可达像；任一前提不成立即自动 NO-GO。

## 3. 候选 B：冻结预测头伪逆回写（NO-GO）

### 3.1 机制及 H=1/H=6 形式

设冻结预测头在末端隐藏表示上为 \(R_H(z)=W_Hz+b_H\)。先由同一邻站上下文生成期望修正 \(u_H(c)\)，再用最小范数伪逆把它写回末端隐藏层：

\[
\Delta z=W_H^+u_H(c),\qquad \hat y=R_H(z+\Delta z)
=F_H(x)+W_HW_H^+u_H(c).
\]

H=1 时 \(W_1W_1^+\) 在非零头下为标量 1；H=6 时它是到 \(W_6\) 行空间的投影。信息集与候选 A 相同，且没有新空间门。

### 3.2 同构证明、容量对照与否证

当 \(W_H\) 满行秩时，\(W_HW_H^+=I_H\)，故该估计量严格化为

\[
\hat y=F_H(x)+u_H(c),
\]

即 `st_pairwise_delta_forecast`；把 Top-5 与站点偏置放进 \(c\) 后就是 `st_sparse_station_bias_delta_forecast`。不满行秩时也只是给输出残差加一个固定线性投影，不产生新的注入机制。它与 `st_pairwise_delta` 的位置不同，却未与现有预测端族不同构。

若 \(u_H\) 使用一层 \(32\to H\) 线性映射，参数为 \(33H\)，H=1 为 33，H=6 为 198；NC13 臂直接在输出端使用同一个 \(u_H\)，参数逐项相同，而且在满行秩时预测逐元素相等。最小正对照本应构造“只有隐藏回写有效”的 DGP，但线性头下不存在这种 DGP；真实数据训练也不能推翻代数恒等。结构置乱只会让两臂同时失效，不能识别伪逆结构。

这不是特征拼接、空间门、MoE 或超参数选择；但它是现有预测残差的重参数化。预期特异效应严格为 0，不需要任何种子。判定为 NO-GO，不进入实验。

## 4. 候选 C：按冻结敏感度混合输入端与预测端（NO-GO）

### 4.1 机制及 H=1/H=6 形式

可定义冻结主干对邻站输入扰动的局部敏感度

\[
s_H(x,c)=\lVert J_{F_H}(x)C(c)\rVert_2,
\qquad \lambda_H=\sigma(a\log(s_H+\epsilon)+b),
\]

再令

\[
\hat y=\lambda_H F_H(x+\alpha C(c))
+(1-\lambda_H)\{F_H(x)+\beta G_H(c)\}.
\]

H=1 使用标量 Jacobian 范数和标量 \(\lambda_1\)；H=6 使用六维输出 Jacobian 的整体范数和一个共享 \(\lambda_6\)，避免逐步路由。信息集没有增加，空间门仍复用 \(w_i\)。

### 4.2 差异、NC13 与否证

该式在数值上可区别于任一单独现有变体，却没有新的可分离估计结构：它正是输入端专家与预测端专家的样本级路由。即使 \(\lambda_H\) 由 Jacobian 而非 MLP 计算，\(a,b\) 仍在选择两个已有专家；固定 \(\lambda\) 又退化为“两者加权”，正是本轮禁止的解释。

新增路由只有 2 个参数，但两条专家分支的有效容量之和远大于任何单分支。可构造参数相同的负对照，把 \(s_H\) 替换为固定随机正交投影的范数并保留 \(a,b\)；然而该对照只检验路由信号，不可能去掉“双专家容量”同时保持同一函数类，因而不满足 NC13。正对照 DGP 只能人为指定不同样本来自两个专家，这会把结论预先写进数据；负对照中置乱 \(s_H\) 后的收益消失也只证明路由，不证明新的注入机制。

它不是普通通道拼接，也没有第二套站点门，但属于 MoE 路由换名，并把注入位置变成验证驱动的选择问题。无法给出独立于两条现有分支容量的效应量；任何非零收益都不能归因于所声称结构。所需种子数因此不是 3 或 5，而是“不应启动”。判定为 NO-GO。

## 5. 能否进入实验

本轮不是整体 NO-GO：三个候选中只有 PTI 具有可检验的非同构位置假设，并能给出严格等容量、同信息集且只移除冻结编码器传播的 PTO 对照。候选 B 与预测端残差代数同构，候选 C 是双专家位置路由，均不应消耗训练或验证资源。

最终判定为“候选 A 条件进入实验，B/C 止损”。实验分支只允许实现一个固定的 PTI（\(r=4\)、编码器入口、共享 Top-5 门）及 PTO；不得扫描层位、秩或路由方式。若 PatchTST 内部不能无侵入暴露等形状的编码器入口/出口，或数值可达性测试表明 PTI 等价于原始输入扰动，则在训练前把本轮改判为 NO-GO。

## 6. 修订：函数类分离见证与机制重述

### 6.1 修订后的机制主张

候选 A 的主张不再是“某个注入位置本身更优”，而是邻站信息的类型决定两类函数是否可分离。令 \(z=E(x)\)，并令共享 Top-5 门控上下文生成 \(\Delta(c)\)。PTI 与 PTO 的函数类分别为

\[
f_{\mathrm{PTI}}(x,c)=R_H\!\left(T(z+\Delta(c))\right),\qquad
f_{\mathrm{PTO}}(x,c)=R_H(T(z)+\Delta(c)).
\]

当 \(R_H\) 对出口 token 为线性映射时，PTO 可写成 \(F_H(x)+g_H(c)\)，其中心表征与邻站上下文之间没有交互项。对任意两组 \(x_a,x_b,c_a,c_b\)，PTO 的混合差分恒为零：

\[
\mathcal I_f=f(x_a,c_a)-f(x_a,c_b)-f(x_b,c_a)+f(x_b,c_b)=0.
\]

若冻结编码器 \(T\) 非线性，PTI 可以通过 \(T(z+\Delta(c))\) 产生非零 \(\mathcal I_f\)，因而能表示“邻站提示的作用随中心序列表征变化”的交互型效应。若真实邻站效应是 \(F_H(x)+A_Hc\) 这类纯加性项，并且 \(A_Hc\) 位于入口平移和出口平移的共同可达子空间，则 PTI 与 PTO 均可表示，二者应落入预注册等价容差。共同可达条件不可省略；若入口映射无法表示该加性方向，PTI 变差只能说明可达性受限，不能作为交互机制的反证或支持证据。

### 6.2 双向合成见证

两个 DGP 共用同一个固定、无可训练参数且输入输出同为二维的非线性编码器、嵌入和预测头：

\[
E(x)=(z,0),\quad T_0(u_1,u_2)=(u_1,u_2+u_1u_2),\quad
R_H(v)=q_H(v_1+v_2),
\]

其中 \(z,c\overset{ind}{\sim}\mathrm{Unif}[-1,1]\)，\(q_1=(1)\)，\(q_6=(1,0.9,0.8,0.7,0.6,0.5)^\top\)，观测噪声为独立零均值高斯噪声。每次重复使用 4096 个训练样本和 2048 个验证样本；H=1 与 H=6 各做 10 次独立的数据及初始化重复，所有臂逐次配对。

DGP-交互令真实入口平移为 \(B_{int}c=(0,bc)\)，\(b=0.5\)：

\[
y_H=q_H\{z+bc+bzc\}+\varepsilon
=R_H\!\left(T_0(E(x)+B_{int}c)\right)+\varepsilon.
\]

PTI 取 \(\Delta(c)=B_{int}c\) 即精确表示条件均值。PTO 只能写成 \(q_Hz+g_H(c)\)；由于 \(z,c\) 独立且均非退化，任何 \(g_H\) 都无法消去 \(q_Hbzc\)，其最优加性投影仍保留正的 \(\operatorname{Var}(q_Hbzc)\)。这给出 PTI 可表示、PTO 不可表示的构造性反例。判定要求 PTI 相对 PTO 的验证 RMSE 在 10/10 重复中降低，平均相对降幅至少 20%；PTI 的混合差分与真值 \(q_Hb(z_a-z_b)(c_a-c_b)\) 的归一化 RMSE 不超过 5%，PTO 的混合差分绝对值不超过数值容差 \(10^{-6}\) 乘验证目标标准差。

DGP-加性令真实入口平移改为 \(B_{add}c=(ac,0)\)，\(a=0.5\)：

\[
y_H=q_H(z+ac)+\varepsilon
=R_H\!\left(T_0(E(x)+B_{add}c)\right)+\varepsilon.
\]

PTI 取 \(\Delta(c)=B_{add}c\) 可精确表示条件均值；PTO 取出口平移 \((ac,0)\) 也可精确表示。因此该 DGP 是“纯加性不应产生 PTI 特异优势”的反向见证。判定要求两臂相对无噪声条件均值的归一化 RMSE 均不超过验证目标标准差的 2%，并且 10 次重复的平均配对 RMSE 相对差绝对值不超过 0.5%、至少 9/10 落在 ±1% 等价界内。PTI 若在该 DGP 上仍稳定胜出，优先判为容量、优化或实现不公平，候选止损。

这两个见证必须使用逐项相同的生成器、参数初始化、优化器、批次顺序和停止规则。交互 DGP 只改变真实平移方向，不增加 PTI 参数；加性 DGP 也不为 PTO 提供额外输入。任一预测步系数非零，故 H=1 与 H=6 均非退化。

### 6.3 与 FiLM、prompt、prefix 和 adapter 的边界

PTI 不是自由参数 prompt 或 prefix：它不为每个 token 保存一组与样本无关的可训练向量，而是由同一份共享 Top-5 门控上下文逐样本生成平移。它也不是 FiLM，因为不存在对冻结 token 的逐通道乘性 scale；操作只有 \(z_p\mapsto z_p+\Delta z_p(c)\)。它与广义 adapter 都含小型可训练网络，但常规 adapter 变换中心 token 本身，PTI 的生成器只读取邻站上下文，输出还受 \(\tanh\)、全局幅度上界和固定秩 \(r=4\) 约束，并且只作用于冻结编码器入口。

这些命名和结构差别本身不足以构成创新性证据，PTI 仍可被归入广义的条件 prompt/adapter 家族；但它们结合上面的混合差分见证，足以避免与本轮 PTO、自由前缀和逐通道 FiLM 的公式同构判定。实验阶段允许的主张仅是“共享邻站上下文生成的低秩入口平移能够表达 PTO 所不能表达的中心—邻站交互”。若实现后的 PTI 不能在 DGP-交互通过函数类见证，或必须放宽为自由 prefix、乘性 FiLM、第二套空间门或不受限 adapter 才能通过，则该差别不足，直接 NO-GO。

### 6.4 参数同一性与止损条件

PTI 和 PTO 必须共用同一个 \(32\to4\to16\) 生成器、同一个有界 \(\alpha\) 以及同一共享空间上下文，新增参数逐项均为 213；不仅总参数量相等，参数张量的形状、初始化值和优化器状态也要一一对应。PTO 仅把该生成器的输出接到冻结编码器出口，不允许另设输出头。

真实 PatchTST 的入口和出口 token 必须同为 \([B,P,16]\)，或能通过固定、无参数、可逆的 reshape/permutation 对齐。若二者的 token 数、通道数或语义布局不同，以致任一臂需要可学习投影、补充参数、丢弃 token 或复制 token，NC13 的逐项同一性即不成立，必须在读取训练数据和启动训练之前止损。固定但不可逆的裁剪也不再允许作为对齐办法。

### 6.5 重定后的真实数据终点

真实数据仍只用训练段拟合、验证段判定，使用 3 个配对筛查种子。主要性能终点改为每个任务内 \(\Delta_{PP}=\mathrm{RMSE}_{PTI}-\mathrm{RMSE}_{PTO}\)：H=1 与 H=6 均须 3/3 为负，且平均相对 RMSE 降幅至少 0.5%。主要机制终点是在固定验证样本四元组上计算 \(\mathcal I_f\)：诊断接口先按原样本计算并缓存 \(c_a,c_b\)，再把缓存上下文分别外部传给 \(x_a,x_b\)，不得重新计算跨配对的空间门或读取目标。PTI 的中位绝对混合差分除以验证目标标准差后须至少为 0.01、至少为 PTO 数值残差的 10 倍，并且 \(|\mathcal I_{PTI}|\) 较大的样本组必须贡献正的 PTI–PTO 损失改善；只有非零交互而没有预测收益不算通过。

PTI 相对 `st_sparse_station_bias_delta_forecast` 的配对验证 RMSE 改为次要性能判据，但 NC13 仍要求它胜过同信息集基线：两个任务的平均相对改善均须为正，且每个任务至少 2/3 种子方向一致；不以该比较选择层位、秩或幅度。邻站上下文跨样本置乱后，PTI–PTO 差和 PTI 的有效混合差分都应缩至原值的 20% 以内或反向，作为结构破坏负对照。

重审判定仍为条件 GO。只有双向 DGP、参数逐项同一性、真实验证段 PTI–PTO 主终点、交互机制终点和同信息集次要门全部通过，候选 A 才能进入独立确认；任何一项失败均改判 NO-GO。B/C 的 NO-GO 不变。
