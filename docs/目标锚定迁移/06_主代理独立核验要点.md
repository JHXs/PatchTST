# 主代理独立核验要点（实现前推导）

日期：2026-09-09。不是测试通过记录；下列推导用于之后独立检查代码，不能替代执行结果。

## 生成器的V/F条件

AR以单位平稳高斯初值开始，因此每个坐标Var(X0)=1；源输入X_s=X0+c_s+0.1xi_s满足Var(X_s,j)=1.01，且同一站不同坐标独立。源输入同期相关，不等于观测噪声也相关；本次生成器的观测噪声独立是明确的合成简化。

若a=(a0,a1,a2)，V组条件偏差随机部分的方差为1.01*(a1²+a2²)。F组的v_s使用独立坐标3..10且作系数范数归一化，故Var(v_s)=1.01*(a1²+a2²)，它与X1/X2独立。

由0.7²+(sqrt(1−0.7²))²=1，F组条件偏差随机部分方差与V相同。两组偏差均值不必相同，不得把“随机部分方差一致”误写成全部分布一致。

在高斯总体下，F遗漏分量对任何只依赖(X1,X2)的函数均不可表示；其条件方差为(1−0.7²)*1.01*(a1²+a2²)>0。有限样本线性拟合仍可能偶然拟合掉部分遗漏分量，所以不能把总体投影残差直接当作某次validation偏差的硬下界。

## 坐标转换

假设源真值偏差定义为a0+a1*x1+a2*x2，而zj=(xj−mu_j)/sd_j。其在phi=(1,z1,z2)下的真系数应为：

`[a0+a1*mu1+a2*mu2, a1*sd1, a2*sd2]`。

这个变换只用于合成真值核验，不可把真系数交给estimated方法。oracle单独标注且不参与可部署方法排名。

## 联合估计的独立原式检查

应从保存的beta、预测截距和a_s直接回算目标/各源RSS/n、rho*||a||²/S、eta*||beta||1。这样可以发现profile求解器遗漏source权重、误惩罚截距或把rho漏乘S的错误。

profile低维nuisance与直接station-linear-head是同一个凸优化目标的两种实现，比较预测等价用于工程验证，不作为两种创新竞争。lambda=0在相同eta和相同目标训练样本下必须退化；不能通过改变validation选择去比较两组不同模型。

## TransFusion独立检查

- 第一步逐观测系数1/(2N)，不能错误使用等任务权重。
- 中间w必须是所有任务系数按n_k/N加权平均，不能直接取beta0。
- 第二步是固定w后的目标残差Lasso，最终w+delta。
- 公平截距扩展的所有截距无L1/fused；截距方向的梯度也必须验收。
- 两个TF版本分别验证12个c，完整报告，竞争门同时对两版检查。
