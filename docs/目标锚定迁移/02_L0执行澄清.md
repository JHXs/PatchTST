# L0执行澄清：数据访问前修订

日期：2026-09-09。本文由主代理在任何合成运行之前制定；与01有冲突时以本文及03的精确优化式为准；03描述原文无截距版本，本文以下公平截距对照补充具有执行优先级。01的GO是设计者建议，正式放行须有最终复核和主代理签署。

## 1. 只验证机制，不制造标签稀缺优势

保留01的30个固定种子、128维输入、5个源、V/F两类生成式及768/128/256连续时点划分。每个种子从同一批底层随机变量产生四格：V/96标签、V/768标签、F/96标签、F/768标签。

- 96标签格仅使用训练索引0,8,...,760对应的目标输入/标签来拟合标准化、支持域和目标损失；它是人工少标签压力测试。
- 768标签格使用全部目标训练输入/标签。不能把少标签格胜利直接外推到本项目完整标签任务。
- 同种子不同方法/标签格/V-F共用生成器底层变量。每种子用NumPy Generator(PCG64(SeedSequence(seed)))，一次产生全部输入和噪声，方法自身不再抽样。
- AR初值X[-1]独立N(0,I)，然后依次生成1152步。坐标数学编号j=1..128、站点s=1..5；c与d公式严格采用该编号（代码下标j-1）。
- V/F共享目标Y、所有X及噪声；F只替换源条件均值的偏差项。不重新抽样使不同格不可比。随机调用顺序固定为初值[128]、u[1152,128]、xi[5,1152,128]、epsilon0[1152]、epsilon_s[5,1152]，均为standard_normal。
- 合成X在所有站点含义与维数相同，传输映射为恒等；高斯噪声非退化，完整X支持为R^128。真实数据是否满足完整X|z可迁移条件尚未判断，不能从二维筛选自动推出。
- 最终式（2）是全训练集联合nuisance估计，不是早期讨论的交叉拟合残差校正；本轮不声称进行了cross-fitting。

## 2. 支持域、缩放与权重

所有完整X坐标用该格目标训练输入的均值与总体标准差ddof=0缩放；sd<=1e-12视为工程生成异常。状态z为变换后X的前两维，phi=(1,z1,z2)。生成式的真实偏差始终在原始X坐标定义，计算bias诊断时用原始真值减去拟合nuisance在缩放后phi上的输出。

k=12近邻距离为二维欧氏距离。目标LOO排除自身，不排除不同索引的相等值；tau为这些距离的95%分位数，NumPy method='linear'。源训练/源validation的距离参照同一目标训练集合和tau，不重新拟合阈值。

S始终为预先固定的5，空接纳源贡献0，不重新除以活跃源数；每个非空源内按接纳样本数归一化。全部为空时退化为target-only。报告各源接纳率，不按结果改变支持阈值。

## 3. 目标函数与数值约定

原01中的n_eff不是由原始行数即可确定的有效独立样本数。此符号不再用于调参。所有非TransFusion方法统一采用同一目标样本数n0确定L1尺度：eta=c*sqrt(log(128)/n0)，c=logspace(-2,1,12)。TransFusion用03冻结的原方法尺度。

非TransFusion目标统一为01式（2）的平方损失（无1/2）加eta*||beta||1，预测截距不惩罚。nuisance的rho=0.001惩罚包括其常数项。非候选基线对相应nuisance置0或只保留常数列；oracle从源Y中减去真实完整model shift后做matched global，不估计nuisance。oracle在F组也减去完整真值，明确标为不可部署上限。

额外加入 **Unmatched conditional-bias head**：与TACBR完全相同的三维nuisance及目标归一化，仅将所有r置1。否则只有station-intercept不能分离“受限条件偏差”与“支持筛选”的贡献。

TACBR线性L0在数学上就是带源站三维加性头的受限联合回归；不声称同参数化的station-linear-head不能表达它。工程验收必须由独立优化实现核验与matched global + station-linear-head完全同目标函数的预测等价性；该等价臂不是要求被击败的性能基线，而是防止虚报新估计量的核验。即使L0通过，也不能把该线性重参数化本身称为新算法。新的研究问题是目标支持限制与受限偏差估计这组具体训练约束的收益；若无筛选对照表现相同，必须将支持筛选作用降级，不能归因为已证实的创新。

每个方法12个c，按目标validation MSE最小选；与最小分数之差<=1e-12视为平局，优先较大c。求解器必须报告收敛证书；lambda=0恒等测试在**相同c/eta**下比较预测，不能让两方法各自选不同超参数。

不把48个train时间块（长度16）称为ESS估计。只报告行数、跨度和块数，30个独立合成种子才是本次重复实验单位。

### TransFusion公平截距对照（必须）

03的paper_exact无截距版本保留，但不允许仅凭击败它说明优于强迁移对照。另**必须**实现TF-intercept：第一步每个任务有独立非惩罚截距alpha_k，损失为||y-X beta-alpha_k||²/(2N)，所有L1/fused仅作用于128个斜率；第一步beta和alpha均按n_k/N聚合，第二步拟合目标残差时有非惩罚截距delta_alpha。最终预测为X(w_beta+delta_beta)+w_alpha+delta_alpha。

两个TF版本各自独立使用同一12点c网格，分别报全部结果，不在两版之间择优隐藏另一版。本协议所有“不得差于TransFusion”的竞争门均须同时满足两个版本。该扩展不冒称原论文无截距公式或理论保证。

03的KKT条件在TF-intercept版本增加每个非惩罚截距的损失梯度为0检查，其他数值门相同。任何一个固定c重算后仍数值失败，整格标记ENGINEERING_FAILURE，不允许删掉困难c后缩小验证网格继续宣布PASS。

## 4. 修改F门：不能要求方法一定失败

删去01中“F组至少保留25%偏差且收益不超过V组50%”的硬门。假设失效后仍有净收益不构成方法失败；原数值门混淆了分解与最终风险。

F组只作机制边界诊断：利用生成真值检查在完整高斯总体下，遗漏X3..X10的偏差部分对phi不可表示且非零；报告有限样本B、目标误差与oracle差距，不根据F结果选择状态或偏差类。V组真值可由phi精确表示，F组不可以，须有独立代数/数值生成器测试。

## 5. 明确性能判定

令g_s(M)=1−MSE_s(M)/MSE_s(Target-only)，s为30个合成种子；所有“中位收益”是median_s g_s，不是中位MSE的比值。令b_s=1−B_s(TACBR)/B_s(Matched global)，若分母<=1e-12则该格诊断不定义，报告为协议诊断失败而非通过。

少标签V格沿用机制/竞争要求，但精确定义为：

1. median(b_s)>=0.5；median(g_s(oracle))>0；median(g_s(TACBR))>=0.5*median(g_s(oracle))。
2. 至少24/30种子TACBR同时优于target-only、global-full、matched-global及station-intercept。
3. median_s MSE_s(TACBR)<=median_s MSE_s(TransFusion)。无筛选三维头作为额外必要归因诊断，逐种子报告差值，不藏失败结果。

完整标签V格须单独报告所有方法。要继续制定本项目完整标签的真实消融协议，还须median(g_s(TACBR))>0，且其中位MSE不高于global-full、matched-global、station-intercept、TransFusion；若仅少标签格过门，则只说明稀标签条件可行，**不放行当前完整标签任务**。
