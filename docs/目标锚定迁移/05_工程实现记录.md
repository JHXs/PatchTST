# TACBR L0 工程实现记录

日期：2026-09-09。范围：当前 `experiment/target-anchored-transfer-ablation` worktree 的纯合成 L0；`synthetic=true`。本记录不包含真实站点数据、checkpoint、旧指标或性能选择。

## 实现边界

- `tacbr_l0.py` 只生成冻结的 V/F DGP、按目标训练样本拟合标准化与二维支持域、实现非 TF 凸目标及两版 TransFusion 两步目标，并提供原式目标值、KKT、预测 SHA-256 与重建检查。
- 生成器采用 `Generator(PCG64(SeedSequence(seed)))`，调用顺序固定为 `X[-1]`、`u`、`xi`、`epsilon0`、`epsilon_s`。V/F 仅替换源条件均值，四个标签格共享同一底层随机变量。
- 非 TF 方法严格使用目标项 `1/n0`、每个非空源项 `lambda/(S*n_s^A)`、`rho/S` 和 `eta=c*sqrt(log(p)/n0)`；源空集贡献为零。`tacbr` 的 nuisance 为标准化状态上的三维 `(1,z1,z2)`，不做 cross-fitting。
- 非 TF 同时保留直接联合 CVXPY 实现和低维 Gram/profile 实现。后者只用于 `tacbr`、station-intercept 和 unmatched head 的等价性核验，不作为新方法或竞争结果。
- TransFusion `paper_exact` 无截距；`transfusion_intercept` 的第一步任务截距和第二步残差截距均不受惩罚。两版分别使用完整 12 点 `c` 网格，不互相择优隐藏结果。
- `run_tacbr_l0.py` 的正式模式只接受 30 个固定种子、V/F、96/768 两个标签格，要求 clean tree 且拒绝已有输出目录；`--fixture` 使用非正式种子 8702 和小维度，允许工程验证但不用于性能结论。
- `summarize_tacbr_l0.py` 不信任运行时保存的预测：重新生成合成数据，从保存系数重建 validation/test 预测，并独立复算目标值、KKT、哈希和整格失败状态。

## 数值与依赖

正式隔离环境命令：

```bash
UV_CACHE_DIR=/tmp/tacbr-uv-cache uv run --no-project --isolated \
  --default-index https://pypi.org/simple \
  --with 'numpy==2.4.4' --with 'scipy==1.18.0' \
  --with 'scikit-learn==1.7.2' --with 'cvxpy==1.7.2' --with 'osqp==1.0.4' \
  python -m unittest -v test_tacbr_l0.py
```

代码要求 CVXPY 实际使用 OSQP；没有 OSQP 时拒绝静默切换求解器。所有求解变量为 float64，状态必须为 `optimal`，KKT 无穷范数阈值为 `1e-6`，原式目标相对复算阈值为 `1e-8`，预测重建阈值为 `1e-8`。依赖许可证记录为：CVXPY Apache-2.0、OSQP Apache-2.0、NumPy/SciPy/scikit-learn BSD-3-Clause；TransFusion 仅按 PMLR 论文公式独立实现，不复制来源代码。

实际版本由 `manifest.json` 的 `environment` 字段记录；若与上述冻结版本不一致，应停止正式运行并修正隔离环境。当前实现阶段未运行 30 个正式种子，也未进行性能筛选。
