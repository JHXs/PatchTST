# 第二创新候选：目标锚定条件偏差剥离

日期：2026-09-09

阶段决定：GO 仅限纯合成机制 L0；尚未分配任何真实站点、种子、检查点或结果目录。

## 1. 候选及研究边界

本轮只保留一个候选：目标锚定条件偏差剥离（target-anchored conditional bias removal，TACBR）。它仍用其他站的完整训练样本增加监督，但不再把所有站视作同一个条件分布。源样本只有落在中心站状态支持域内才参与训练；每站相对目标条件均值的差异被限制成低维状态上的线性 nuisance 项，与目标预测器联合估计。部署时丢弃这些 nuisance 项，只保留原目标预测器。

TACBR 不是再做一次空间融合。第一创新的 Top-5 门控、站点身份偏置和空间预测残差结构保持冻结；TACBR 改的是中心时间预测器如何利用训练期辅助监督，不修改空间门、预测头或推理前向图。若 L0 通过，下一阶段也应先在无空间融合的相同主干上独立验证，只有第二创新单独成立后才设计固定结构的 2×2 比较。MC-CVLRA、OARR 的 gamma 调整以及频域、VMD、滤波、分解或多尺度变体均不在本候选内。

## 2. 信息来源与可识别假设

记中心站为 0，辅助站为 $s=1,\ldots,S$。$X_i^s$ 是站点 $s$ 的完整历史输入，$Y_i^s\in\mathbb{R}^H$ 是同一预测语义下的未来目标。目标站只有 $n_0$ 个标注窗口，辅助站各有 $n_s$ 个窗口。多站同期相关使源任务可能共享目标规律，但它本身不能推出条件均值相同。

低维状态 $z=q(X)$ 只决定支持筛选和 nuisance 偏差，最终目标预测器 $f_\theta(X)$ 始终读取完整 $X$。TACBR 明确要求，在目标训练支持域内

\[
m_s(X)-m_0(X)
:=\mathbb{E}[Y^s\mid X^s=X]-\mathbb{E}[Y^0\mid X^0=X]
=b_s(q(X)),
\qquad b_s(z)=a_s^\top\phi(z), \tag{A1}
\]

其中 L0 固定 $\phi(z)=(1,z_1,z_2)^\top$。由（A1）才能把

\[
\widetilde Y_i^s=Y_i^s-a_s^\top\phi(q(X_i^s)) \tag{A2}
\]

视为在输入 $X_i^s$ 上对目标条件均值 $m_0(X_i^s)$ 的带噪监督。低维状态相近不自动保证（A1）；若差异还依赖完整 $X$ 中被 $z$ 丢弃的分量，则校正后的源标签仍有系统偏差。允许每站拥有任意条件函数也不可接受，因为有限目标样本无法区分“共享目标规律”和“任意站点规律”，源样本不再保证携带目标信息。

还需要源状态被目标训练状态覆盖，所有窗口先按时间切分，再计算状态标准化、支持阈值和损失；源与目标须有相同输入语义和预测目标定义。同期窗口可以相关，标签数不能直接当作独立有效样本数，后续必须同时报告原始窗口数和按时间块计的有效样本信息。

## 3. 固定最小估计步骤

状态只用目标训练样本的均值和标准差变换。令 $Z_0=\{z_i^0=q(X_i^0)\}_{i=1}^{n_0}$，$d_k(z,Z_0)$ 为到目标状态集合的第 $k$ 近距离，目标 leave-one-out 距离的 95% 分位数为 $\tau$。源样本的固定接纳权重为

\[
r_i^s=\mathbf{1}\{d_k(z_i^s,Z_0)\leq\tau\},
\qquad z_i^s=q(X_i^s). \tag{1}
\]

这一步只排除目标支持域外的源状态，不根据源标签、验证误差或站点相关性调权。L0 固定 $k=12$。在平方损失下，目标预测器与每站三维 nuisance 参数共同估计：

\[
(\widehat\theta,\widehat a_1,\ldots,\widehat a_S)
=\arg\min_{\theta,a_1,\ldots,a_S}
\frac{1}{n_0}\sum_{i=1}^{n_0}
\left\|Y_i^0-f_\theta(X_i^0)\right\|_2^2
\]
\[
\quad +\frac{\lambda}{S}\sum_{s=1}^{S}
\frac{1}{n_s^A}\sum_{i=1}^{n_s}r_i^s
\left\|Y_i^s-f_\theta(X_i^s)-a_s^\top\phi(z_i^s)\right\|_2^2
+\frac{\rho}{S}\sum_{s=1}^{S}\|a_s\|_2^2
+\Omega(\theta), \tag{2}
\]

其中 $n_s^A=\sum_i r_i^s$；若某站 $n_s^A=0$，整站跳过。L0 固定 $\lambda=1$、$\rho=10^{-3}$，目标项和各站源项分别归一化，避免站点数或长序列直接支配目标锚。推理函数严格为

\[
\widehat Y^0=f_{\widehat\theta}(X^0), \tag{3}
\]

不读取站点身份、$a_s$、邻站历史或邻站未来值。

式（2）不是 ordinary global pooling 加一个可任意表达的站点头。global pooling 等价于强制所有 $a_s=0$；普通 station head 可以为每站学习完整条件函数，而 TACBR 只允许三维加性均值偏差，并只在目标状态支持域内吸收源—目标 model shift。可观测优势应同时出现于两处：相对 matched global，剥离后的源标签目标条件偏差下降；相对 target-only，保留下来的完整源输入帮助估计共享的 $f_\theta(X)$。仅有训练损失下降不算机制证据。

## 4. 四份关键一手近邻与算法差异

检索与核验日期均为 2026-09-09。近邻的存在不构成 NO-GO；这里只判断估计步骤是否已经相同。

| 一手来源 | 已覆盖内容 | 与 TACBR 的具体差异 | 本轮用途 |
|---|---|---|---|
| Montero-Manso 与 Hyndman, [Principles and Algorithms for Forecasting Groups of Time Series: Locality and Globality](https://arxiv.org/abs/2008.00444), 2021 | 形式化 local/global forecasting，并说明共享模型可借多序列样本降低估计复杂度 | ordinary global 以各序列自己的输入和标签训练同一函数；TACBR 只共享目标函数，把受限的站点条件均值差作为训练期 nuisance 剥离 | Global-full pooling 强基线 |
| Huang 等, [Correcting Sample Selection Bias by Unlabeled Data](https://proceedings.neurips.cc/paper_files/paper/2006/hash/a2186aa7c086b46ad4e8bf81e2a3a19b-Abstract.html), NeurIPS 2006 | Kernel mean matching 给源样本加权，使协变量分布接近目标；核心识别条件是 covariate shift 下条件分布不变 | 式（1）只借用其支持域思想；TACBR 不声称匹配后条件分布不变，而用（A1）和式（2）的低维 nuisance 显式处理 model shift | Matched global 强基线与支持筛选依据 |
| He 等, [TransFusion: Covariate-Shift Robust Transfer Learning for High-Dimensional Regression](https://proceedings.mlr.press/v238/he24a.html), AISTATS 2024 | 在高维线性回归中同时处理 covariate shift 与 model shift；联合估计各任务完整参数，以 fused-ℓ1 正则约束源—目标参数差，再做 target local debias | TransFusion 已覆盖“两类 shift”，该口号不是 TACBR 的新意。它为每个任务估计完整高维系数 $\beta^{(s)}$，依赖稀疏线性参数差；TACBR 共享任意既有 $f_\theta$，只允许 model shift 是 $q(X)$ 上的三维加性 nuisance，并按目标状态逐样本筛选 | L0 复现中央式两步方法；若同预算稳定占优则停止 TACBR |
| Zhao、Zheng 与 Leng, [Residual Importance Weighted Transfer Learning for High-dimensional Linear Regression](https://arxiv.org/abs/2311.07972), 2024；JASA 2026 在线版 DOI [10.1080/01621459.2026.2623997](https://doi.org/10.1080/01621459.2026.2623997) | RIW-TL 用一维残差密度构造源样本重要性权重，并以 cross-fitting 估计权重，缓解整源纳入/排除 | RIW-TL 保留源标签而改变其损失权重；TACBR 估计的是状态条件均值偏差并在训练目标中剥离，权重只作无标签支持筛选。若后续改成残差密度权重，应视为另一候选 | 防止把 TACBR 误写成 residual weighting |

当前没有发现与式（1）—（3）完全相同、同时采用目标支持筛选、受限状态条件偏差 nuisance 和部署时纯目标函数的算法。这个窄检索结论只支持开展低成本 L0，不足以支持论文级新颖性声明；若后续扩大检索发现完全相同估计量，再作止损。

## 5. 纯合成机制 L0：冻结生成式和强对照

L0 只检验“（A1）成立时，受限 nuisance 能否阻止 global pooling 的 model-shift 偏差并保留源样本的共享信息；（A1）失效时，优势是否按预期消失”。不读取项目 CSV，不加载 checkpoint，不计算既有真实指标，也不训练 PatchTST。

### 5.1 冻结数据生成

- 重复 30 次，随机种子固定为 20260909—20260938；每次生成 768/128/256 个连续的 train/validation/test 时点。
- 中心完整输入维数 $p=128$，按 $X_t^0=0.7X_{t-1}^0+\sqrt{1-0.7^2}\,u_t$、$u_t\sim N(0,I_{128})$ 生成。目标训练标签只保留每第 8 个时点，共 $n_0=96$；状态固定为 $z=q(X)=(X_1,X_2)$，不学习 $q$。
- 设 $S=5,H=1$。目标稀疏系数前六维固定为 $(1.2,-1.0,0.8,-0.6,0.4,-0.3)$，其余为 0；$Y_t^0=\beta^\top X_t^0+\epsilon_t^0$，观测噪声独立服从 $N(0,1)$。
- 同期源输入为 $X_t^s=X_t^0+c_s+0.1\xi_t^s$，其中 $c_{s,j}=0.3\sin((s+1)(j+1))$，$\xi_t^s\sim N(0,I_{128})$，从而同时存在相关输入和 covariate shift。对应 $\phi(z)=(1,z_1,z_2)^\top$ 的五个偏差系数固定为 $(0.3,0.8,-0.4),(-0.2,0.6,-0.2),(0.4,0.5,-0.5),(-0.3,0.7,-0.1),(0.1,0.4,-0.6)$。
- 假设成立组 V：$Y_t^s=\beta^\top X_t^s+a_s^\top\phi(z_t^s)+\epsilon_t^s$。此时 $m_s(X)-m_0(X)=a_s^\top\phi(q(X))$，严格满足（A1）。
- 假设失效组 F：记 $d_{s,j}=\sin((s+1)(j+1))$，并固定

  \[
  v_s(X)=\sqrt{a_{s,1}^2+a_{s,2}^2}\,
  \frac{\sum_{j=3}^{10}d_{s,j}(X_j-c_{s,j})}
  {\sqrt{\sum_{j=3}^{10}d_{s,j}^2}}.
  \]

  生成 $Y_t^s=\beta^\top X_t^s+0.7a_s^\top\phi(z_t^s)+\sqrt{1-0.7^2}\,v_s(X_t^s)+\epsilon_t^s$。因为各坐标随机方差相同，两组 model-shift 的随机部分方差一致，但 F 组仍含 $z$ 无法表达的完整输入依赖。
- 所有 768 个源训练标签可用；validation/test 只使用中心站未来标签。数据按时间生成和切分后再拟合标准化及支持阈值。

### 5.2 同预算强对照

最终目标函数族统一为带非惩罚截距的线性 Lasso，输入只用中心训练输入的均值和标准差变换。共同的 12 点乘数网格为 $C=\operatorname{logspace}(-2,1,12)$；普通 Lasso 取 $\eta=c\sqrt{\log(p)/n_{\mathrm{eff}}}$，每个 $c\in C$ 只评估一次 target validation MSE。报告 test MSE、支持接纳率、原始窗口数和按 16 时点连续块估计的有效样本数。合成条件偏差固定计算为

\[
B(\widehat a)=\frac{1}{\sum_s n_{s,\mathrm{val}}^A}
\sum_{s,i}r_{i,\mathrm{val}}^s
\left[m_s(X_i^s)-m_0(X_i^s)-\widehat a_s^\top\phi(z_i^s)\right]^2, \tag{4}
\]

其中条件均值由生成器真值给出；Matched global 取 $\widehat a_s=0$。该量不混入有限观测噪声，也不作为真实项目的新指标。

Centralized TransFusion 复现原文式（2）的联合 fused-ℓ1 估计和式（5）的 target local debias。其 fused 权重固定为 $a_s^{\mathrm{TF}}=8\sqrt{n_s/N}$，并令 $\lambda_0=c\sqrt{\log(p)/N}$、$\widetilde\lambda=c\sqrt{\log(p)/n_0}$；同一个 $c\in C$ 同时控制两步，因此也只有 12 个 validation 候选。这里 $n_0=96,n_s=768,N=n_0+Sn_s$。

线性 L0 中式（2）是带五组三维 nuisance 的凸问题，可用块坐标下降或近端梯度在 CPU 上求解；不引入神经网络、GPU 或真实数据准备成本。

| 方法 | 固定差异 | 回答的问题 |
|---|---|---|
| Target-only | 只用 96 个目标样本 | 小样本目标下限 |
| Global-full pooling | 使用全部目标/源样本，$r_i^s=1,a_s=0$ | 最大样本池化是否已足够 |
| Matched global | 使用式（1），但固定 $a_s=0$ | 收益是否只来自支持筛选 |
| Matched global + station intercept | 式（2）中 $\phi(z)=1$ | 简单站点头能否吸收全部偏差 |
| Centralized TransFusion | 原论文中央式两步估计，同一验证预算 | 已有 covariate+model shift 方法是否更强 |
| TACBR-estimated | 严格执行式（1）—（3） | 待检机制 |
| TACBR-oracle | 从源标签减去生成器真值 $b_s(z)$ 后做 matched global；不参与排名 | 区分机制上限与 nuisance 估计误差 |

### 5.3 预注册放行门与停止点

1. 工程恒等性：式（2）令 $\lambda=0$ 时，$f_{\widehat\theta}$ 与 Target-only 的预测最大绝对差小于 $10^{-8}$；测试阶段访问 $a_s$、站点身份、$X^s$ 或 $Y^s$ 均视为失败。
2. 成立组机制门：TACBR-estimated 相对 Matched global 至少消除 50% 的 validation 目标条件偏差平方，并至少获得 TACBR-oracle 相对 Target-only 的 50% 中位 test MSE 收益。
3. 成立组竞争门：30 次中至少 24 次 test MSE 同时低于 Target-only、Global-full pooling、Matched global 和 station-intercept 对照；其中位 test MSE 不得高于 TransFusion。
4. 失效组否证门：F 组剥离后至少保留 Matched global 条件偏差平方的 25%，且 TACBR 相对 Target-only 的中位收益不超过 V 组中位收益的 50%。任一数值关系不成立，都说明 V/F 生成式没有把（A1）的作用清楚分离。

成立组机制门或竞争门失败，即停止进入真实数据，不通过改 $k$、$\lambda$、$\rho$、状态维数、偏差类或损失函数追逐合成收益；只允许一次针对明确数值错误或实现错误的复算。F 组表现差是预期的适用边界，不是理论失败。四项全部满足时，也只放行“制定真实数据消融协议”，不放行读取站点数据、训练正式模型或声称 RMSE 会改善。

## 6. 未决风险与当前结论

最大风险是（A1）对真实跨站空气质量过程仍可能过强：邻站—中心差异可能依赖完整气象历史、传播方向或未观测因素，二维状态不能吸收这些差异。目标 96 个标签也可能不足以稳定锚定高容量 $f_\theta$，源站同期相关会进一步降低有效样本数。TransFusion、station-intercept 或普通 global 在真实数据上可能更强；这是后续可观测竞争结果，不是提前 NO-GO 的理由。

TACBR 已有明确的信息来源、可执行估计式、与 global pooling/TransFusion/原空间融合不同的训练和推理行为，并用 F 组直接否证其识别假设。当前建设性结论是允许立即开展冻结的纯合成 L0，在 L0 结果产生前不判断真实收益。
