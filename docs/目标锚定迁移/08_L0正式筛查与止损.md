日期：2026-09-09。执行代码：experiment/target-anchored-transfer-ablation（正式运行 commit 见 git log，含 SCS fallback 工程修复）。范围：纯合成 V/F × 96/768 四格、30 个固定种子、9 方法、12 点 c 网格；`synthetic=true`，无真实站点数据、无 checkpoint、无历史指标访问。

## 工程与完整性

- 正式 30 种子运行 1080/1080 个候选配置完成；独立 summarize 重新生成数据、重建预测、复算 objective/KKT/系数与数据哈希，结果为 1080 selected、0 verification_failures。
- 工程修复（非性能回调，均记录且不改变 DGP/阈值/方法/门）：
  1. 验收发现并修复 DGP 的 c,d 公式（sin((s+1)(j+1)) 与代码少加 1）；
  2. 验收发现并修复 96 格竞争门漏检 TransFusion median 比较；
  3. OSQP 在正式规模 TransFusion 及 target_only(n0=96) 上 max_iter 打满且非 optimal，经验证 SCS 全网格收敛（KKT<1e-8），改为 TF 锁定 SCS、非 TF 在 OSQP 失败时 SCS fallback；`redo_log.json` 记录 20 个被重算配置。
- 重算只针对求解器数值失败，未按任何性能结果修改协议。
- 理论分支后补的 03 精确化将 KKT 非零坐标阈值写为 1e-10，实现用 1e-7；因全部解 KKT < 1e-6 且该阈值只影响子梯度符号判定，不改变任何候选的 optimal/KKT/排名结果，已如实记录，不重跑。

## 门判定

- 少标签 V/96 机制门：**PASS**。条件偏差平方消除 median 91.52%；oracle 增益 19.83%；tacbr 增益 16.18% ≥ 0.5×oracle。
- 少标签 V/96 竞争门：**FAIL**。仅 11/30 种子 tacbr 同时优于 target-only、global-full、matched-global、station-intercept（要求 ≥24/30）。
- 完整标签 V/768：positive 门 PASS（tacbr 增益 2.27%>0），竞争门 PASS（tacbr median MSE 1.0193 ≤ 全部对照）。
- F 组仅作机制边界诊断，不做硬门；F/96、F/768 中条件偏差消除分别降至 37.65%、48.25%，符合“假设失效后二维状态不能表示完整偏差”的预期。

## 归因诊断（决定 STOP）

协议把“无筛选三维头”`unmatched_conditional_bias_head` 作为必要归因对照。它只去掉目标支持域筛选、其余与 tacbr 完全相同。结果是：

- V/768：unmatched 1.0199 与 tacbr 1.0193 相差约 0.06%；
- F/768：unmatched 1.0475 与 tacbr 1.0474 几乎相同；
- V/96：unmatched 1.1371 优于 tacbr 1.1472；
- F/96：unmatched 1.1704 优于 tacbr 1.1827。

即**目标状态支持域筛选这个唯一的新机制贡献≈0，甚至在少数格中为负**。TACBR 相对 target-only 的微弱增益（若有）主要来自三维偏差头，而该偏差头在上一理论轮已被认定为现成强基线，不能构成第二创新。

## 唯一阶段决定：STOP

- 不进入真实数据消融，不训练 ST/确认，不读取任何站点 CSV。
- 不调整 k、λ、ρ、状态维数、偏差类、损失函数或阈值来挽救 96 格竞争门或放大 V/768 的 2.27%。
- 不把“768 格 positive+competition 过”包装成成立：其收益极小且归因不支持目标支持域筛选机制，且 96 格竞争门明确失败。
- 已消耗的合成种子 20260909–20260938 与 V/F DGP 不返还；真实数据资源（含广州 9027 后 40%、B1 等）继续封存，本候选未消费。
