# 提交记录中文对照表

维护日期：2026-09-15。范围：仓库全部 106 条提交（`git log --all`）。

## 这份文件是什么

- 项目里很多 commit 用英文标题（`docs(research): ...`、`results(experiment): ...`），不好读。
  本表把每条提交翻译成一句话中文说明，方便你回看"哪一步做了什么"。
- **没有改写任何历史提交**：改写会破坏已推送的分支、证据链和外部归档的对应关系。
  所以历史提交保持原样，本表只做外部对照。
- 中文说明由主代理根据提交标题与改动内容归纳；每条都可用 `git show <短哈希>` 复核。

## 怎么用

```bash
git show f4a2871              # 看某条提交改了什么
git log --oneline --graph --all | head -40   # 看分支结构
git log --all --date=short --pretty='%h %ad %s'   # 本表对应的原始清单
```

- 想知道"某个研究方向现在什么状态" → 看 `docs/研究路线总表.md`（唯一索引）。
- 想知道"某个数据集/图表在哪" → 看 `figures/README` 与 `tables/table-schema.md`。
