# VMD 与 PatchTST 项目第二创新点可行性分析

> 当前决策（2026-08-20）：最终Top-5 ST-PatchTST已在北京1013站PM2.5的24→1和168→6任务上通过预注册稳定性门，平均配对RMSE降幅为3.1188%和0.8220%，两任务均5/5新种子改善。因此第二创新点可以进入独立消融阶段；空间结构和训练策略必须锁定，以便将后续收益单独归因于频域模块。

## 1. 结论

变分模态分解（Variational Mode Decomposition，VMD）在技术上可以接入本项目，但不建议直接将“VMD + PatchTST”作为第二创新点。

假设第一创新点是当前的多站点门控 ST-PatchTST，更合适的第二创新点是：

> 无未来信息泄漏、峰值保持的多尺度频域自适应融合模块。

VMD 可以作为该模块的一种实现和消融基线。如果只是对完整数据进行一次 VMD，再将分解结果输入 PatchTST，其方法创新性较弱，并且容易引入未来信息泄漏。

推荐的论文主线是：

1. 通过邻站门控聚合建模空气质量的空间相关性；
2. 通过因果多尺度频域融合建模污染物在不同时间尺度上的动态变化。

这两个创新点分别对应空间建模和多尺度时间建模，逻辑相对独立，又可以在统一的 ST-PatchTST 框架中协同工作。

## 2. 目标论文基本信息

目标论文为蔡天孚的硕士学位论文《基于变分模态分解和图神经网络的空气质量预测模型研究》。

- DOI：[10.27049/d.cnki.ggldc.2025.000737](https://doi.org/10.27049/d.cnki.ggldc.2025.000737)
- 中国 DOI 元数据：[解析页面](https://www.chndoi.org/Resolution/Handler?doi=10.27049/d.cnki.ggldc.2025.000737)
- CNKI 持久入口：[论文页面](https://link.cnki.net/doi/10.27049/d.cnki.ggldc.2025.000737)
- 本地全文：[蔡 - 基于变分模态分解和图神经网络的空气质量预测模型研究.pdf](../蔡%20-%20基于变分模态分解和图神经网络的空气质量预测模型研究.pdf)

论文构建的预测模型称为 VIGNet，主要由 VMD 时频域分解器、Informer 时间特征提取模块和 GCN 空间特征提取模块组成。

## 3. VMD 的基本原理

VMD 是一种信号分解方法，本身不是预测模型。其目标是将原始信号分解为多个具有有限带宽和不同中心频率的模态：

\[
f(t)=\sum_{k=1}^{K}u_k(t)
\]

其中：

- \(f(t)\) 是原始时间序列；
- \(u_k(t)\) 是第 \(k\) 个带限模态；
- \(K\) 是预先指定的模态数量；
- 每个模态对应一个中心频率 \(\omega_k\)。

VMD 通过最小化所有模态的总带宽，并约束所有模态之和能够重构原信号，将分解问题转化为变分优化问题。求解时通常使用交替方向乘子法（ADMM），交替更新模态、中心频率和拉格朗日乘子，直至满足收敛条件。

分解结果通常可以作如下解释：

- 低频模态主要表示长期趋势；
- 中频模态主要表示周期性和中期波动；
- 高频模态主要表示短期突变及噪声。

需要注意，高频模态不一定只是噪声。空气污染突发事件和污染峰值也可能位于高频部分，因此不应默认删除最高频模态。

VMD 的两个关键参数是：

- \(K\)：模态数量。过小可能产生模态混叠，过大可能导致过度分解；
- \(\alpha\)：带宽惩罚参数，用于控制各模态的带宽和分离程度。

VMD 的原始方法参见：Dragomiretskiy, K. and Zosso, D. [Variational Mode Decomposition](https://doi.org/10.1109/TSP.2013.2288675), IEEE Transactions on Signal Processing, 2014。

目标论文中存在“VMD 可以自适应确定模态数量”的表述，但标准 VMD 仍需要预先指定 \(K\)。目标论文实际上也通过扫描不同的 \(K\) 值来选择最终参数。

## 4. 目标论文中的 VMD 使用方式

目标论文的整体流程可以概括为：

```text
空气质量时间序列
        ↓
VMD 分解为多个频带模态
        ↓
各模态通过 Informer 提取时间特征
        ↓
GCN 建模监测站之间的空间关系
        ↓
各模态预测结果求和
        ↓
最终 PM2.5 / SO2 预测结果
```

论文的主要实验设定包括：

- 研究区域为桂林市；
- 使用 10 个空气质量监测站；
- 污染物包括 PM2.5、PM10、CO、NO2、SO2 和 O3；
- 同时使用风速、温度、湿度、气压等气象变量；
- 采用平均包络熵辅助选择模态数量；
- 从 \(K=4\sim11\) 中选择 \(K=9\)；
- 从 \(\alpha=500\sim3000\) 中选择 \(\alpha=2000\)；
- 主要预测 PM2.5 和 SO2；
- 消融实验预测未来 48 小时。

论文表 5-2 报告的监测站 PM2.5 结果为：

| 模型 | RMSE | MAE | SMAPE |
|---|---:|---:|---:|
| Informer-GCN | 3.24 | 2.44 | 18.31% |
| VIGNet | 2.68 | 1.91 | 12.17% |

按照论文结果，加入 VMD 后，模型在该数据集上的预测性能得到改善。但这些参数和结果不能直接迁移到本项目，原因包括数据长度、采样窗口、站点数量和预测任务均不相同。

## 5. 对目标论文的审慎评价

目标论文证明了多尺度分解与时空预测模型结合的可行性，但其方法仍存在以下不确定性。

### 5.1 数据划分与 VMD 顺序不够明确

论文没有充分说明以下两种流程中的哪一种被采用：

```text
流程 A：完整序列 → VMD → 训练/验证/测试划分
流程 B：原始数据划分 → 每个历史窗口独立 VMD
```

如果采用流程 A，VMD 在优化完整序列时会同时使用某一时间点之前和之后的数据，使训练期模态受到测试期数据影响，构成未来信息泄漏。

### 5.2 参数选择的泛化性有限

论文主要根据一个参考站点的 PM2.5 和 SO2 选择 \(K=9\) 和 \(\alpha=2000\)，然后将参数应用到其他站点。不同城市、污染物和时间窗口的频率结构并不相同，因此这些参数不应直接用于北京或广州数据。

### 5.3 复现信息不足

论文没有完整公开：

- 每个变量是否单独进行 VMD；
- 气象变量是否参与分解；
- 模态在不同站点之间如何对齐；
- VMD、标准化和数据划分的严格顺序；
- 完整代码及随机种子。

### 5.4 简单组合的创新性已经有限

空气质量领域已经存在相近研究，例如：

- [Air quality forecasting using a spatiotemporal hybrid deep learning model based on VMD–GAT–BiLSTM](https://doi.org/10.1038/s41598-024-68874-x)；
- [Exploiting Functional Time Series Prediction for PM2.5 Based on Multivariate Variational Mode Decomposition and Anomaly Detection](https://doi.org/10.1002/for.70075)。

因此，仅将 Informer、BiLSTM 或 GRU 替换为 PatchTST，通常只能视为组合式改进。要形成较有说服力的第二创新点，需要在因果分解、模态融合、峰值保持或跨站点频带共享方面提出新的设计。

## 6. 与当前项目的适配情况

当前项目的多站点训练资产实测为：

```text
X.shape = (8736, 228, 24)
y.shape = (8736, 12, 1)
```

其中：

- 19 个监测站；
- 每个站点 12 个变量；
- 总输入通道数为 \(19\times12=228\)；
- 中心站为北京 1013 站；
- 历史输入长度为 24 小时；
- 当前预测长度为 1 小时。

数据参数位于 [`data_preparation.py`](../data_preparation.py)，当前历史窗口和预测长度定义在该文件第 131—134 行附近。

当前 ST-PatchTST 的空间增强方式为：

```text
enhanced_x = center_x + alpha × neighbor_context
```

相关实现位于 [`ST_PatchTST_model.py`](../ST_PatchTST_model.py) 的 `forward` 方法中。

### 6.1 不能直接使用论文的 K=9

本项目当前历史窗口只有 24 个小时。如果将 24 个时间点分解为 9 个模态，每个模态能够利用的有效频率信息非常有限，容易出现：

- 过度分解；
- 模态混叠；
- 边界效应；
- 不同窗口之间的模态编号交换；
- 特征维度增加但有效信息不足。

因此，若使用 VMD，建议首先将历史窗口扩展至 168 小时，并进一步比较 336 小时窗口。

### 6.2 不应对全部 228 个通道同时分解

第一阶段实验不建议对全部站点和变量做 VMD，原因是：

- 计算量和存储量大幅增加；
- `weather` 等离散变量不适合进行 VMD；
- `wind_direction` 是环形变量，不能直接视为普通连续信号；
- 不同站点和变量的模态难以稳定对齐。

首轮实验只分解中心站 PM2.5 历史序列最稳妥。若实验有效，再考虑扩展到中心站的六种污染物，或者使用 MVMD 建立联合模态。

## 7. 推荐的 VMD 接入方案

建议设计一个滚动因果 VMD 模态融合分支：

```text
u1, ..., uK = VMD(center_PM2.5[t-L:t])

frequency_context =
    ModeProjection(u1, ..., uK)
    + CenterFrequencyOrdering
    + AdaptiveModeGating

enhanced_x = center_x
           + alpha × neighbor_context
           + beta  × frequency_context

prediction = PatchTST(enhanced_x)
```

其中：

- 每个样本只分解预测时刻之前的历史窗口；
- 模态按照中心频率排序，避免不同窗口的模态编号交换；
- 使用投影层将 \(K\) 个模态映射到中心站特征维度；
- 使用可学习门控决定不同模态的贡献；
- 保留原始中心站序列作为主分支；
- 使用系数 \(\beta\) 控制频域分支的最大影响；
- 最终直接预测原始 PM2.5，不分解完整目标序列。

初始实验参数建议为：

| 参数 | 建议值 |
|---|---|
| 历史窗口 | 168 小时，进一步比较 336 小时 |
| 预测长度 | 1、6、12、24 小时 |
| VMD 模态数 | 3、4、5 |
| 分解变量 | 中心站 PM2.5 |
| 模态融合 | 可学习 softmax 门控 |
| 频域残差系数 | 有上限的可学习 \(\beta\) |
| 参数选择范围 | 仅训练集和验证集 |

该方案可以命名为：

> 基于滚动因果 VMD 与自适应模态融合的 ST-PatchTST。

## 8. 更推荐的替代方案

| 方案 | 新颖性 | 本项目适配性 | 计算与泄漏风险 | 建议 |
|---|---:|---:|---:|---|
| 可学习的因果多尺度/频域双分支 | 中高 | 很高 | 中低 | 首选 |
| 滚动 VMD + 模态注意力 | 中 | 高 | 中高 | 可以作为保守方案 |
| 风向/风速条件化动态有向图 | 中高 | 高 | 中 | 领域意义强，但与第一创新点重叠 |
| MODWT/小波包 + 尺度门控 | 中 | 很高 | 低 | 最稳妥、最容易复现 |
| CEEMDAN、EWT、SSA、STL | 低至中 | 中 | 中高 | 更适合作为对照实验 |

### 8.1 可学习的多尺度频域双分支

该方案在每个历史窗口内使用以下一种或多种方法提取多尺度特征：

- rFFT 频率分量；
- 可学习的深度可分离卷积滤波器组；
- 指数移动平均趋势—残差分解；
- 可学习的小波或多尺度卷积。

频域分支与原始 PatchTST 时域分支通过门控融合。其优势是：

- 可端到端训练；
- 不需要逐窗口运行 ADMM；
- 不存在 VMD 模态编号交换问题；
- 更容易控制为无未来信息泄漏；
- 与现有空间邻站分支相对正交。

相关思路可参考：

- [FEDformer: Frequency Enhanced Decomposed Transformer for Long-term Series Forecasting](https://proceedings.mlr.press/v162/zhou22g.html)；
- [xPatch: Dual-Stream Time Series Forecasting with Exponential Seasonal-Trend Decomposition](https://doi.org/10.1609/aaai.v39i19.34270)。

本项目的创新不应表述为“首次使用频域 Transformer”，而应具体落在：

- 多站点污染序列的频带共享；
- 气象条件驱动的频带权重；
- 空气污染峰值保持；
- 空间邻站分支与频域分支的协同门控；
- 严格滚动、无未来泄漏的特征构造。

### 8.2 风向和风速条件化动态有向图

空气污染传播受到风速和风向影响，因此可以根据以下信息动态生成站点邻接关系：

- 站点距离；
- 当前历史窗口的风向；
- 风速；
- 站点间历史相似度。

该方案的领域意义较强，但它实际上是对当前空间邻站模块的进一步强化。如果第一创新点已经定义为时空 ST-PatchTST，则不建议再将动态图作为完全独立的第二创新点。

### 8.3 MODWT 或小波包分解

小波分解计算速度快、可解释性强，并且更适合较短历史窗口。空气质量预测领域已经存在基于小波的混合模型，例如：

- [The Forecasting of PM2.5 Using a Hybrid Model Based on Wavelet Transform and an Improved Deep Learning Algorithm](https://doi.org/10.1109/ACCESS.2019.2944755)。

因此，如果使用小波，也应加入尺度注意力、跨站共享尺度或峰值保持机制，而不是仅将小波系数直接输入 PatchTST。

### 8.4 CEEMDAN、EWT、SSA 和 STL

这些方法均可用于时序分解，但不建议单独作为主要创新点：

- CEEMDAN 计算量大、带随机性，跨窗口模态对齐困难；
- EWT 需要根据频谱构造边界，不同窗口的频带可能不稳定；
- SSA 每个窗口都需要奇异值分解，计算成本较高；
- STL/MSTL 通常包含双侧平滑，使用完整序列时容易引入未来信息。

相关空气质量研究包括：

- [Long-term PM2.5 concentrations forecasting using CEEMDAN and deep Transformer neural network](https://doi.org/10.1016/j.apr.2023.101839)；
- [Forecasting air pollutant concentration using a novel spatiotemporal deep learning model based on clustering, feature selection and empirical wavelet transform](https://doi.org/10.1016/j.scitotenv.2021.149654)。

## 9. 必须修正的数据泄漏问题

当前 [`data_preparation.py`](../data_preparation.py) 在划分训练集、验证集和测试集之前，使用完整 PM2.5 序列计算 Pearson 相关系数并筛选相关站点：

```python
r, p = stats.pearsonr(v_list_1, v_list_2)
if r > r_thred:
    station_id_related_list.append(station_id_other)
```

这意味着验证期和测试期已经影响了站点集合，属于前视信息泄漏。正式实验前应调整为：

1. 首先确定原始时间划分；
2. 仅使用训练时间段计算站点相关性；
3. 在验证集和测试集上冻结站点集合；
4. 标准化参数只能在训练集上拟合；
5. VMD、小波、频带阈值和超参数只能使用训练集和验证集确定。

对于所有分解算法，应避免以下流程：

```text
完整时间序列 → 全局分解 → 切分训练/测试集
```

推荐流程是：

```text
原始数据按时间划分
        ↓
训练集拟合预处理参数
        ↓
构造每个预测时刻的历史窗口
        ↓
只变换该历史窗口
        ↓
预测原始未来目标
```

## 10. 第一创新点当前还需要加强

现有北京数据实验记录中，24 小时输入预测未来 1 小时时：

| 模型 | PM2.5 测试 RMSE |
|---|---:|
| ST-PatchTST | 0.303941 |
| PatchTST | 0.302622 |

相关结果见 [`docs/fixed-ST-PatchTST指标记录-北京.md`](fixed-ST-PatchTST指标记录-北京.md)。

现有结果中 ST-PatchTST 尚未稳定优于 PatchTST，而且差异很小。叠加第二创新模块前，需要先保证：

- PatchTST 和 ST-PatchTST 使用完全相同的数据；
- 固定随机种子；
- 使用相同的 PatchTST 主干参数；
- 启用最佳模型保存和早停；
- 在至少 3 个随机种子上报告均值和标准差；
- 将 PM2.5 指标反标准化到真实物理单位；
- 不使用不同数据准备脚本产生并互相覆盖的资产进行对比。

## 11. 推荐消融实验

最低限度的核心消融矩阵为：

| 空间分支 | 频域分支 | 模型 |
|---|---|---|
| 无 | 无 | 中心站 PatchTST |
| 无 | 有 | 频域增强 PatchTST |
| 有 | 无 | ST-PatchTST |
| 有 | 有 | 频域增强 ST-PatchTST |

进一步对比：

- 原始序列与 VMD 输入；
- VMD、小波、可学习滤波器；
- 仅低频模态；
- 仅高频模态；
- 固定求和与可学习门控；
- 不同 \(K\) 值；
- 是否去除最高频；
- 168 小时与 336 小时历史窗口；
- 1、6、12、24 小时预测长度。

每个实验至少使用 3 个随机种子，建议报告：

- MAE；
- RMSE；
- SMAPE；
- 模型参数量；
- 训练和推理时间；
- 均值和标准差或置信区间；
- 高污染峰值或最高 10% 浓度样本上的独立指标。

对高污染时段单独评估非常重要，否则所谓“去噪”可能只是将污染峰值过度平滑，从而降低总体均方误差，却削弱模型对实际污染事件的预测能力。

## 12. 最终建议

VMD 可以应用于本项目，但推荐将其定位为候选分解器或对照方法，而不是单独作为创新本身。

若选择 VMD 路线，建议使用：

> 基于滚动因果 VMD 与自适应模态融合的 ST-PatchTST。

若希望第二创新点更具有方法新颖性和工程可实现性，建议使用：

> 无未来信息泄漏、峰值保持的可学习多尺度频域增强 ST-PatchTST。

该方向能够与现有空间邻站增强模块形成清晰的两条论文主线：

1. 空间层面：利用多站点信息和邻站门控建模污染物空间关联；
2. 时间层面：利用多尺度频域特征和自适应融合建模长期趋势、周期波动及短期突变。

在正式实现第二创新点之前，应优先修正站点筛选泄漏、统一实验资产，并重新建立可靠的 PatchTST 与 ST-PatchTST 基线。
