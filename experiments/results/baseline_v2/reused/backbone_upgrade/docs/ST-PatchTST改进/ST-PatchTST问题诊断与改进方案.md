# ST-PatchTST 问题诊断与改进方案

## 1. 结论

当前 ST-PatchTST 不能稳定优于 PatchTST 的首要原因，不是空间模块位于 PatchTST 之前，而是空间分支在现有初始化方式下几乎没有参与预测。

当前导出模型的诊断结果为：

```text
训练后 alpha                  = 5.80 × 10⁻⁷
邻站残差/中心输入 RMS 比值    = 3.14 × 10⁻⁸
门控归一化熵                  = 0.995
不同样本门控权重平均标准差    = 0.0042
```

这说明当前模型基本退化为：

```text
中心站输入 → PatchTST → 中心站预测
```

建议按照以下顺序改进：

1. 修复空间分支近似失活的问题；
2. 建立严格、公平、可重复的 PatchTST 基线；
3. 将中心站单边门控改为中心站—邻站成对注意力；
4. 对比输入级空间融合与时间表征级空间融合；
5. 最终采用“PatchTST 编码器后、预测头前”的空间融合；
6. 再逐步加入距离、风向、风速和传播时滞等领域先验。

## 2. 当前模型结构

当前模型从多站点输入中分离中心站和邻站：

```text
输入 X:       [B, S×F, L]
重排后:       [B, S, F, L]
中心站:       [B, F, L]
邻站:         [B, S-1, F, L]
```

其中，当前站点数 \(S=19\)，每站特征数 \(F=12\)。空间分支先投影邻站特征，再根据中心站生成邻站权重：

\[
C_s=\sum_{i=1}^{S-1}a_i\phi(X_i)
\]

空间上下文以残差形式加入中心站：

\[
X_{\mathrm{enhanced}}=X_c+\alpha C_s
\]

最后由 PatchTST 预测：

\[
\hat{Y}=\operatorname{PatchTST}(X_{\mathrm{enhanced}})
\]

## 3. 首要问题：空间分支近似失活

### 3.1 双重零抑制

当前训练配置为：

```python
alpha_max = 0.5
alpha_init = 0.0
```

代码将0裁剪到 \(10^{-6}\)，再计算 Logit：

\[
\alpha=\alpha_{max}\sigma(\alpha_{logit})
\]

因此初始值约为：

\[
\alpha\approx0.5\times10^{-6}=5\times10^{-7}
\]

与此同时，邻站分支最终投影层被零初始化：

```python
nn.init.zeros_(self.neighbor_out.weight)
nn.init.zeros_(self.neighbor_out.bias)
```

训练开始时同时满足：

\[
C_s=0,\qquad\alpha\approx0
\]

由此产生以下梯度问题：

- 因为 \(C_s=0\)，\(\alpha\) 初始几乎没有梯度；
- 因为输出投影权重为0，邻站投影层和门控网络初始没有有效梯度；
- 输出投影层的梯度又被接近0的 \(\alpha\) 缩小；
- \(\alpha\) 的 Sigmoid 位于饱和区，很难从接近0的位置恢复。

改变 `alpha_max` 不能解决该问题，因为实际初值仍由 `alpha_init=0` 和裁剪值决定。

### 3.2 最小修复

建议使用：

```python
alpha_max = 0.5
alpha_init = 0.05  # 或 0.1
```

可以继续保留输出投影零初始化。这样训练初期空间上下文仍为0，不会打乱中心站主信号，但输出投影能够获得足够梯度，随后邻站投影和门控网络也能开始学习。

推荐比较：

| 实验 | alpha_init | 输出投影初始化 | 目的 |
|---|---:|---|---|
| A | 0 | 零初始化 | 复现当前退化模型 |
| B | 0.05 | 零初始化 | 小幅打开空间分支 |
| C | 0.10 | 零初始化 | 增强空间分支学习速度 |
| D | 固定 0.10 | 零初始化 | 排除 alpha 自身优化问题 |

不应再同时使用接近0的残差系数和零初始化的空间输出投影。

## 4. 当前门控结构的问题

### 4.1 门控只读取中心站

当前权重生成过程为：

```text
center_x
→ 全局平均池化
→ MLP
→ S-1 个邻站权重
```

权重计算时没有读取相应邻站的状态，无法真正判断当前哪个邻站有用。建议改为中心站—邻站成对打分：

\[
q=Q(H_c),\qquad k_i=K(H_i),\qquad v_i=V(H_i)
\]

\[
e_i=\frac{q^\top k_i}{\sqrt d},\qquad
a_i=\operatorname{softmax}(e_i)
\]

\[
C_s=\sum_i a_iv_i
\]

这样每个权重同时依赖中心站和对应邻站的状态。

### 4.2 平均池化丢失时间信息

全局平均池化会丢失：

- 最近时刻浓度；
- 上升或下降趋势；
- 污染峰值；
- 邻站是否领先中心站；
- 风向与风速的近期变化。

可选改进包括：

1. 拼接窗口均值、标准差、最后值和线性斜率；
2. 使用一维因果卷积提取近期变化；
3. 使用 Patch Embedding 后的时间表征；
4. 在每个 Patch 上独立计算空间权重。

其中，Patch 级权重最适合与 PatchTST 结合。

### 4.3 权重粒度过粗

当前每个邻站只有一个标量权重，并应用于所有污染物、气象变量和全部历史时刻。建议第一步将其细化到 Patch 级：

\[
a_{i,p}=\operatorname{Attention}(H_{c,p},H_{i,p})
\]

其中 \(p\) 表示 Patch。第一版不必直接扩展为每个变量、每个时刻一组权重，以免参数量过大。

### 4.4 Softmax 强制使用邻站

Softmax 使所有邻站权重之和为1。即使当前没有任何邻站有用，模型也必须生成一个邻站加权平均。

可以：

- 加入“无邻站”空节点；
- 使用独立 Sigmoid 门控；
- 保留全局残差系数，允许空间分支整体关闭；
- 使用 Top-k 或稀疏注意力。

推荐保留受约束的全局残差系数，并增加一个空节点。

## 5. 空间数据与任务设置问题

### 5.1 同时刻高相关不等于具有预测价值

当前使用 PM2.5 同时刻 Pearson 相关系数筛选邻站，并设置阈值为0.85。该方法更容易选择与中心站同步变化的站点，而不一定能找到提前反映污染输送的站点。

预测更关心：

\[
\operatorname{corr}(X_i(t-\tau),X_c(t))
\]

建议比较：

- 仅训练集上的同时刻相关性；
- 仅训练集上的最大滞后相关性；
- 地理距离；
- 主导风向下的上下风关系；
- 全部站点输入，由稀疏注意力自动选择。

### 5.2 站点筛选存在未来信息泄漏

当前相关性使用完整 PM2.5 序列计算，然后才进行训练、验证和测试划分。必须调整为：

```text
确定训练、验证和测试时间边界
→ 仅使用训练时间段计算站点相关性
→ 冻结站点集合
→ 分别构造历史窗口
```

### 5.3 24 小时输入预测 1 小时不易体现空间优势

在未来1小时预测中，中心站最近浓度通常已经非常强，高相关邻站的边际贡献有限。建议同时测试：

| 历史窗口 | 预测长度 |
|---:|---:|
| 24 | 1 |
| 72 | 6 |
| 168 | 6 |
| 168 | 12 |
| 168 | 24 |

空间传播信息更可能在多步预测、污染快速变化和风向改变的样本中体现价值。

### 5.4 多目标损失可能稀释 PM2.5 信号

当前模型同时预测12个中心站变量，包括天气类别和风向。需要注意：

- `weather` 不一定适合普通连续回归；
- `wind_direction` 是环形变量，不适合普通线性误差；
- 所有变量等权训练可能稀释 PM2.5 的空间信号；
- 空间投影会混合不同变量，可能向目标通道注入噪声。

建议先以中心站 PM2.5 为唯一目标验证空间模块，再决定是否扩展为多任务预测。

## 6. 训练与评估稳定性

### 6.1 使用验证集最佳模型

当前没有启用最佳模型保存和提前停止，训练完成后导出的是最后一轮模型。建议启用：

```python
SaveModelCallback(monitor="valid_loss", fname="ST_PatchTST_best")
EarlyStoppingCallback(monitor="valid_loss", patience=10)
GradientClip(1.0)
```

最终评估前应加载验证集最优权重。

### 6.2 控制随机性

每组实验至少运行3个随机种子，正式结果建议运行5个随机种子，并固定：

- Python、NumPy 和 PyTorch 随机种子；
- 数据划分；
- DataLoader 顺序；
- 模型初始化；
- 学习率策略。

结果应报告：

\[
\mathrm{mean}\pm\mathrm{std}
\]

当前 PM2.5 测试 RMSE 差值约为0.44%，单次实验不足以证明模型优劣。

### 6.3 保证基线口径一致

PatchTST 和 ST-PatchTST 必须使用：

- 相同中心站和时间范围；
- 相同训练、验证和测试索引；
- 相同历史窗口与预测长度；
- 相同 PatchTST 主干参数；
- 相同标准化器；
- 相同训练轮数和模型选择规则。

单站点和多站点准备脚本目前会写入相同的 `X.npz`、`y.npz`、`splits.pkl` 和 `model_params.npz`。建议建立独立输出目录或在文件名中加入数据集、窗口和预测长度，避免实验资产被覆盖。

## 7. 把空间模块放到 PatchTST 后面

“放到后面”存在两种不同实现。

### 7.1 不推荐：放在最终预测输出之后

```text
各站历史
→ 各站 PatchTST 完整预测
→ 空间融合预测值
→ 中心站最终预测
```

对应公式为：

\[
\hat{Y}_c=
\hat{Y}^{base}_c+
\gamma\operatorname{Spatial}
(\hat{Y}_1,\ldots,\hat{Y}_S)
\]

这种方式实现简单，但存在以下缺点：

- PatchTST 输出已经高度压缩；
- 历史趋势、Patch 结构和局部峰值信息已经丢失；
- 预测长度为1时，每个站只剩少量预测值；
- 邻站预测误差会传播到中心站；
- 如果只监督中心站，邻站预测头缺少直接监督。

因此，不建议把空间模块放在最终预测值之后作为主方案。

### 7.2 推荐：放在 PatchTST 编码器后、预测头前

推荐结构为：

```text
各站历史序列
        ↓
共享 Patch Embedding / PatchTST Temporal Encoder
        ↓
各站时间表征 H₁, H₂, …, Hₛ
        ↓
以中心站为 Query 的空间注意力
        ↓
增强后的中心站表征 H'c
        ↓
PatchTST Forecast Head
        ↓
中心站预测
```

各站首先通过共享时间编码器：

\[
H_i=\operatorname{TemporalEncoder}(X_i)
\]

使用中心站作为 Query，邻站作为 Key 和 Value：

\[
Q_c=W_QH_c,\qquad K_i=W_KH_i,\qquad V_i=W_VH_i
\]

空间得分为：

\[
E_i=
\frac{Q_cK_i^\top}{\sqrt d}
+B_{distance,i}
+B_{wind,i}
\]

中心站增强表征为：

\[
H'_c=H_c+\gamma\sum_iA_iV_i,
\qquad A_i=\operatorname{softmax}(E_i)
\]

最终预测为：

\[
\hat{Y}_c=\operatorname{ForecastHead}(H'_c)
\]

这种结构比较的是时间编码后的趋势、周期、突变和 Patch 模式，而不是直接混合标准化后的原始变量。

## 8. 推荐的新模型架构

建议将改进模型命名为：

> 基于时间表征级动态空间注意力的 ST-PatchTST

第一版建议只使用各站 PM2.5 建立空间分支：

```text
多站 PM2.5 输入:       [B, S, L]
Patch 切分后:           [B, S, P, patch_len]
共享 Patch Embedding:  [B, S, P, D]
共享时间编码器:         [B, S, P, D]
空间注意力:             [B, P, S-1]
中心站增强表征:         [B, P, D]
预测头输出:             [B, H]
```

其中 \(P\) 为 Patch 数量，\(D\) 为隐藏维度，\(H\) 为预测长度。

中心站其他污染物和气象变量可以继续通过中心站分支，或作为空间门控条件。第一版不建议同时对19个站点的12个变量执行完整空间注意力，以免计算量和过拟合风险过大。

### 8.1 Patch 级动态空间权重

空间权重随样本和 Patch 变化：

\[
A\in\mathbb{R}^{B\times P\times(S-1)}
\]

模型可以表达不同历史阶段由不同邻站提供信息，以及风向变化后空间权重发生转移。

### 8.2 受约束残差系数

表征级空间融合继续使用受约束残差：

\[
\gamma=\gamma_{max}\sigma(g)
\]

推荐初值为：

```text
gamma_max  = 0.5
gamma_init = 0.05 或 0.1
```

不能再将 \(\gamma\) 初始化到接近0并同时零初始化整个空间输出，否则会重复当前的失活问题。

## 9. 距离、风向与传播时滞

在数据驱动注意力稳定后，可以逐步加入空气污染传播先验。

### 9.1 距离偏置

\[
B_{distance,i}=-\lambda_d d_i
\]

距离越远，初始注意力偏置越小，但数据仍可以修正这一先验。

### 9.2 风向和风速偏置

设邻站指向中心站的方位角为 \(\phi_i\)，当前风向为 \(\theta_t\)，构造：

\[
r_{i,t}=\cos(\theta_t-\phi_i)
\]

再结合风速 \(v_t\)：

\[
B_{wind,i,t}=\lambda_wv_tr_{i,t}
\]

实现前必须确认数据中的风向表示“风从哪个方向来”还是“风吹向哪个方向”。

### 9.3 传播时滞

可设置 0、1、2、3、6 小时等候选滞后，并让模型学习不同邻站的滞后权重。第一版建议先依靠 Patch 级注意力建模领先关系，再判断是否需要显式时滞模块。

## 10. 分阶段实施方案

### 阶段一：证明当前空间分支能够学习

1. 将 `alpha_init` 改为0.05或0.1；
2. 保留输出投影零初始化；
3. 启用验证集最佳模型保存；
4. 固定随机种子；
5. 记录空间分支诊断指标；
6. 对比中心站 PatchTST 和修复后的 Pre-ST。

必须记录：

```text
alpha
RMS(alpha × neighbor_context) / RMS(center_x)
gate entropy
gate sample std
neighbor_out weight norm
```

如果训练后空间残差比仍小于 \(10^{-4}\)，应先检查梯度，不能只根据最终 RMSE 判断空间信息无效。

### 阶段二：改为成对邻站注意力

```text
中心站时间摘要 → Query
每个邻站时间摘要 → Key / Value
Query-Key 相似度 → 邻站权重
```

第一版时间摘要可以使用窗口均值、标准差、最后值和最近3～6小时斜率。该版本仍在 PatchTST 前融合，用于单独验证成对门控。

### 阶段三：实现时间表征级空间融合

将 PatchTST 拆分为：

```text
Patch Embedding
Temporal Encoder
Forecast Head
```

对所有站点共享 Patch Embedding 和 Temporal Encoder，在编码器输出上执行空间注意力，最后只使用增强后的中心站表征预测。第一版只处理所有站点的 PM2.5。

### 阶段四：加入领域先验

按以下顺序逐个加入并消融：

1. 站点距离偏置；
2. 风向条件偏置；
3. 风速调制；
4. 候选传播时滞；
5. 空节点或稀疏 Top-k 注意力。

## 11. 对照与消融实验

| 编号 | 模型 | 目的 |
|---|---|---|
| A | 中心站 PatchTST | 基础基线 |
| B | 当前 ST-PatchTST，alpha 近似0 | 退化检查 |
| C | 修复初始化的 Pre-ST | 验证空间分支能否学习 |
| D | 成对门控 Pre-ST | 验证动态中心—邻站比较 |
| E | PatchTST Encoder + Latent-ST + Head | 验证表征级后置融合 |
| F | E + 距离偏置 | 验证距离先验 |
| G | F + 风向/风速偏置 | 验证污染输送先验 |
| H | G + 候选传播时滞 | 验证滞后传播建模 |

还必须进行以下真实性检查：

### 邻站时间打乱

保持中心站不变，打乱邻站时间。如果模型确实利用正确时空关系，性能应下降。

### 邻站置零

测试时将邻站输入置零，与正常输入比较。

### 空间残差关闭

将 \(\alpha\) 或 \(\gamma\) 设为0，确认模型能退化为同一骨干的中心站 PatchTST。

### 站点元数据打乱

打乱邻站与距离、方向数据的对应关系。若模型真正利用领域先验，性能应下降。

### 邻站数量对照

比较单一邻站、Top-k 邻站和全部邻站，判断19站输入是否存在明显冗余。

## 12. 评价指标

整体结果至少报告：

- RMSE、MAE 和 MSE；
- 3～5 个随机种子的均值与标准差；
- 高污染样本 RMSE 和 MAE；
- 污染快速上升时段误差；
- 不同风速区间误差；
- 不同预测步长误差。

空间模块诊断至少报告：

- 空间残差相对幅度；
- 邻站注意力熵；
- 不同样本的权重变化；
- 邻站打乱后的性能下降幅度。

只有当邻站打乱或关闭空间分支造成可重复的性能下降，才能较有说服力地说明模型真正利用了空间信息。

## 13. 推荐的最小可行版本

在大规模重构前，先完成：

```text
1. alpha_init = 0.05
2. 输出投影保持零初始化
3. 使用验证集最优模型
4. 固定5个随机种子
5. 只预测中心站 PM2.5
6. 比较 24→1、168→6、168→12
7. 记录 alpha 和空间残差相对幅度
8. 进行邻站时间打乱实验
```

继续进入 Latent-ST 重构的条件为满足以下至少一项：

- 修复后的 Pre-ST 平均性能优于中心站 PatchTST；
- 邻站打乱后性能稳定下降；
- 多步预测或高污染样本明显改善；
- 空间残差达到合理幅度且门控权重随样本变化。

如果修复初始化后空间分支仍没有贡献，应优先检查数据中是否存在可利用的领先空间信息，而不是立即增加复杂图网络。

## 14. 最终推荐架构

不推荐：

```text
ST 原始输入融合 → 完整 PatchTST
```

也不推荐：

```text
完整 PatchTST 预测 → ST 预测值融合
```

最终推荐：

```text
各站共享 PatchTST 时间编码器
        ↓
Patch 级中心站—邻站动态空间注意力
        ↓
受约束残差增强中心站时间表征
        ↓
中心站预测头
```

该结构具备以下优点：

- 每个站点先形成有意义的时间模式表示；
- 空间权重基于中心站与邻站的动态关系；
- 权重能够随样本和时间 Patch 变化；
- 可以自然加入距离、风向、风速和传播时滞；
- 保留中心站残差路径，避免无效邻站破坏基线；
- 可以通过关闭空间残差退化为公平的 PatchTST 基线。

在实现第二创新点之前，应先完成空间分支初始化修复和表征级空间融合验证。否则加入多尺度频域模块后，将难以区分性能变化来自空间模块、频域模块还是训练随机性。
