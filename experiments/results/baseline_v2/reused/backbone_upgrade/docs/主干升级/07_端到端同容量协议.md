# 端到端同容量空间对照协议

> 协议版本：v1.0  
> 锁定日期：2026-09-27  
> 实验分支：`experiment/backbone-upgrade-ablation`

## 1. 研究问题与声明边界

上一轮 `trainable_matched` 将冻结的单站主干＋空间头与端到端单站 GRU/LSTM 比较，但两者的训练自由度不同。本轮只回答：

> 对于同一个小容量 GRU/LSTM 主干，在相同数据、初始化种子、优化器、训练循环和最佳验证检查点规则下，端到端训练的空间头能否改善该主干？

本协议中“同容量”指两臂使用完全相同的中心站主干 `b`。O 臂必然比 B 臂多出预注册空间头参数，因此不得宣称两臂“总参数完全相同”；必须逐臂登记 `O = B + spatial_head`。本轮不新增机制，不使用测试集选主干、改超参或决定重跑。北京 1013 与种子 2047–2051 均已消费，本轮是方法学补充对照，不是新的独立确认。

## 2. 数据、任务与输入

- 数据固定由 `run_beijing_leakfree_coverage.prepare_datasets_leakfree` 构造：筛站只使用训练窗口覆盖的时间段，缺失值只做因果前向填充，按时间 70%/10%/20% 分为 train/valid/test。
- 中心站为北京 1013，目标为 PM2.5。B 臂在模型边界只取中心站单通道；O 臂读取按站点优先排列的 18 站输入。
- 覆盖 20 个配置：`history ∈ {24,48,72,168}` 与 `horizon ∈ {1,3,6,12,24}` 的笛卡尔积。
- 24→1 和 168→6 使用种子 2047–2051，其余配置使用 2047–2049，共 64 个配置—种子组。

## 3. 预注册模型与运行数

主干集合在运行前固定为：

`gru_h8, gru_h16, gru_h32, gru_h64, lstm_h16, lstm_h32`。

每个主干 `b` 有两个配对臂：

1. **B(b)**：`SingleStationAdapter` 只读中心站，主干全参数端到端训练。正式结果直接读取 `experiments/results/trainable_matched/raw_metrics.csv`，不重跑。
2. **O(b)**：与 B 相同且同种子初始化的主干，挂载到 `ST_PatchTST` 的 `patch_tst` 位置；复用预测端有界残差、中心—邻站成对门控、邻站差值、Top-5 门控和站点身份偏置。主干与空间头的所有参数都以同一学习率训练，不从 B 检查点初始化。

空间头固定为 `neighbor_hidden_dim=32`、`spatial_pool_bins=4`、`forecast_alpha_init=0.1`、`forecast_alpha_max=0.5`、`neighbor_dropout=0.2`（与当前 `build_model` 将 `config.dropout` 传入空间头的实现一致）。正式矩阵只训练 O 臂：6 主干 × 64 组，共 384 次。

## 4. 训练与评估语义

B 与 O 必须调用从 `run_trainable_matched_baselines.py` 逐行复用的同一训练核心：AdamW（`lr=1e-3`、`weight_decay=1e-4`）、`ReduceLROnPlateau(mode="min", factor=0.5, patience=3)`、MSELoss、全局梯度范数裁剪 1.0、以验证 MSE 与 `1e-7` 改善阈值早停并恢复最佳检查点。`history≤48` 使用 40 epochs / patience 8 / batch 256，其余使用 30 / 6 / 512。

每次训练期间只使用 train 和 valid。测试预测仅在最佳验证检查点回载后生成一次，不影响任何选择。损失出现 NaN/Inf 时，同一运行仅允许将学习率降为原值的 1/10 重试一次，仍失败则记为 `nonfinite`；CUDA/HIP OOM 记为 `infeasible_oom`。失败身份不得从完整性统计中删除。

## 5. 公平性强制门

正式矩阵启动前，`test_endtoend_spatial.py` 必须完成并落盘以下五项审计：

1. **零空间等价门**：对 24→1 和 168→24、seed 2047、`gru_h8`，在 CPU 确定性路径上分别从同一种子构造 B 与空间旁路 O；两者使用相同训练核心和相同轮数，避免 ROCm RNN 的跨次运行非确定性污染实现等价性判断。最佳验证损失、测试预测和 RMSE 的相对差必须不高于 `1e-6`。该审计运行不进入正式科学结果。
2. **参数量登记门**：对 6 个主干和代表 horizon 独立重建 B/O，确认两臂全部参数可训练，且 `O_trainable = B_trainable + spatial_head_trainable`。
3. **输入边界门**：B 登记 `input_channels=1`，改动邻站不得改变输出；O 登记 `input_channels=18`，且实际模型站点数为 18。
4. **不偷看门**：配置、主干、早停和失败处理均由本协议预先固定；运行记录的 `selection_split` 必须为 `valid`，`evaluation_split` 必须为 `test`，汇总器不得根据测试值排除 completed 运行。
5. **独立复算门**：对所有 completed O 预测文件重算物理尺度 RMSE，与 `raw_metrics.csv` 的绝对差必须小于 `1e-9`。

单配置冒烟覆盖 24→1 和 168→24、seed 2047 的六个 O 臂，每臂两轮，与正式目录隔离，不得进入结果汇总。

## 6. 主对照、分层与预注册判据

对每个 `(history, horizon, seed, backbone)` 将 O 与 B 配对，主指标为测试集物理尺度 RMSE。相对变化定义为：

`100 × (O_rmse - B_rmse) / B_rmse`，负值表示 O 更优。

主表报告全体 384 个配对的平均相对变化、O 更优数与有效配对数，并分别按 horizon、history 和 backbone 汇总。

- **成功**：总体平均相对变化 `< 0`，且 O 更优比例 `≥ 60%`。
- **部分成功**：总体不通过，但至少一个预注册 history 或 horizon 分层同时满足平均相对变化 `< 0` 与更优比例 `≥ 60%`。
- **失败**：总体平均相对变化 `≥ 0`，且无任一预注册 history/horizon 分层通过；结论写为“同主干容量、同训练自由度下空间头无增益”。

与上一轮冻结版 C1 的对比只作训练自由度差异的描述性参考；固定参考值为“冻结主干时空间头相对自身主干平均改善 1.43%”，不参与 C1_endtoend 成败判定。

## 7. 产物与完整性
