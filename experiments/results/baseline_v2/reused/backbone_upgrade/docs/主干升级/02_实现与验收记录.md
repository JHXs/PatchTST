- P1 共登记 13 个协议候选，全部可用；仅按验证损失选择 `center_lstm_matched`（`best_valid_loss=0.097575`）。
- 升级 ST RMSE：`20.691814 μg/m³`；自身冻结主干：`20.812637 μg/m³`；C1 相对降低 `0.580527%`。
- S3 最强单站点口径同为 `center_lstm_matched`；C2 相对降低 `0.580527%`。
- 当前冻结 ST RMSE：`20.988380 μg/m³`；C3 相对降低 `1.413001%`。
- 诊断：`alpha=0.101095`，空间残差 RMS 比 `0.008708`，`best_epoch=2`。两轮 smoke 只能验证链路，不用于正式成功判定。
- P3 七项合规自检全部通过。

选择分布：`center_lstm_matched: 1`。

完整矩阵共 112 个 P2 运行（北京 64，广州 48）。既有相同 head-only 矩阵台账合计训练 `1113 秒`（18.6 分钟）；考虑强主干前向、数据准备、检查点 I/O 与汇总，预计本实验单卡约 **20–30 分钟**。该估计不包含 OOM/非有限重试。
