# 单站点基线对比 · 实现工作单（W1）

> 冻结依据：`docs/单站点基线对比/00_协议.md` v1.0（用户 2026-09-22 纠正对比设计）
> 分支/工作区：`experiment/baseline-single-station`（worktree `~/.herdr/worktrees/PatchTST/experiment-baseline-single-station`，基于 `main`）
> 解释器：`.venv/bin/python`（用仓库根目录的 `.venv`）
> 环境：`OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 MPLBACKEND=Agg`，并 **`unset DISPLAY WAYLAND_DISPLAY`**
> （tsai 在导入期调用 `plt.gcf()`，DISPLAY 失效会抛 `TclError`）

## 1. 设计要点（与前一版的唯一区别）

| | 前一版（已放弃） | **本版** |
|---|---|---|
| 基线输入 | 全部站点（多站点，同信息集） | **仅中心站（单站点）** |
| 我们的模型输入 | 全部站点 | 中心站 + 邻站（多站点，不变） |
| 回答的问题 | 同信息集下机制是否更优（结论：否） | **引入邻站信息带来多少提升** |

## 2. 复用既有测量（关键：不要重烧 GPU）

前一版（分支 `experiment/baseline-comparison-ablation`）已经跑完的**单站点臂**测量可直接复用，
因为那些臂的定义（`center_*`）本来就是"仅中心站单通道"，与本次设计**完全一致**，且数据/划分/种子/训练预算相同：

| 城市 | 已有测量（`experiments/results/baselines/`，位于仓库主检出） |
|---|---|
| 北京 | `center_gru`/`center_lstm`/`center_tcn`：20 配置 × 3 种子；`center_mlp`/`center_resnet`/`center_tst`：头条 2 配置（24→1、168→6）× 5 种子 × 2 容量档；传统 5 臂：20 配置各 1 行 |
| 广州 | `center_gru` + 4 条传统：2 配置 × 8 站 × 3 种子 |

要求：
1. 新 runner 提供 `--ingest-source <旧结果根>`：**只读**读取上述单站点臂的行，校验
   `(city, L, H, arm, seed, capacity_tier)` 与本次配置一致，并附加列
   `provenance="ingested from experiment/baseline-comparison-ablation (same arm definition, same config/seed/data)"`。
2. 校验必须包含**通道数断言**：被 ingest 的行其 `input_channels == 1`（单站点）；不满足则拒绝 ingest 并报错。
3. ingest 后缺失的 `(arm, seed, tier)` 组合才需要真跑；**先打印计划（要补多少、跑什么）再由调用方决定是否执行**。

## 3. 臂清单（本版）

### 3.1 基线（严格单站点：输入仅中心站单通道）

## 4. 输出表（`tables/single_station_baselines/`）

| 表 | 内容 |
|---|---|
| **S1** | 各（城市, L, H）下：每条单站点基线的均值 RMSE/MAE/SMAPE（含容量档标注） |
| **S2** | 容量对照（default vs matched） |
| **S3** | **主表**：`ST`、`ST+频域` vs **最强单站点基线（best-of-single-station）**：逐种子配对差、相对百分比、同向计数、获胜臂标注 |
| S4 | 传统基线明细（逐配置） |
| S5 | 频域臂与其**等容量时域对照**并列（诚实报告） |
| S6 | 合规自检（含"基线输入通道数恒为 1"的断言结果） |
| S7 | 与被排除/异常行的计数（`nonfinite`、`infeasible_oom`） |

要求：
- 每张表都要有 `.csv`，主表另出 `.md`（人可读）。
- **必须**在主表显著位置写入信息集差异声明（协议 §2）：基线仅用中心站，我们的模型额外使用邻站，
  因此提升归因于新增信息。

## 5. 测试（`test_single_station.py`）

| # | 测试 |
|---|---|
| T1 | 单站点断言：所有基线臂的输入通道数 == 1（构造期与 ingest 校验两处） |
| T2 | 形状：各臂输出 `[B,1,H]`（神经）/ `[N,1,H]`（传统） |
| T3 | 防泄漏：`climatology`/`ar`/`ridge` 只用训练段拟合；ridge 的 alpha 只用验证集 |
| T4 | 训练循环一致性：与既有 `run_st_patchtst_ablation.train_one_run` 位级一致（复刻上一版的 T1 门） |
| T5 | ingest 校验：通道数不匹配或配置不匹配必须报错 |
| T6 | 汇总器独立复算：由 `predictions/*.npz` 重算 RMSE，与记录一致（≤1e-9） |
| T7 | best-of-single-station 选择正确性（合成数据验证取最小 + 配对方向） |
| T8 | 异常状态处理：`nonfinite`/`infeasible_oom` 行不进入主表配对，但计入 S7 |
