# 基线对比（单站点基线版）协议 v1.0

> 分支：`experiment/baseline-single-station`（worktree：`~/.herdr/worktrees/PatchTST/experiment-baseline-single-station`，基于 `main`）
> 状态：**待用户确认后冻结**。用户 2026-09-22 明确纠正对比设计。

## 0. 为什么重做（纠正记录）

前一版实现（分支 `experiment/baseline-comparison-ablation`）把**基线也做成多站点、与我们的模型同信息集**，
用它们回答"空间机制在同信息集下是否更优"。用户 2026-09-22 明确纠正：

| 角色 | 应当使用的数据 |
|---|---|
| **所有基线** | **仅中心站点**（单站点，只有中心站的 PM2.5 历史） |
| **我们的 ST / ST + 频域** | **中心站 + 其余站点**（多站点） |

因此本版对比回答的问题是：

> **引入邻站（多站点）信息，相对于只用中心站单站点数据，能带来多少提升？**

前一版分支**整体放弃、不并入 `main`**，仅作为工程经验（健壮性/合规/异常登记机制）留在远端。

## 1. 对比设计

### 1.1 基线（全部为单站点：仅中心站 PM2.5 单通道历史）

| 层 | 臂 | 说明 |
|---|---|---|
| 传统 | `persistence` | 复制最近观测；多步同值 |
| 传统 | `daily_naive` | 昨日同一小时 |
| 传统 | `climatology` | **训练段**按小时均值 |
| 传统 | `ar` | 中心站自身滞后 p=min(L,24) 项，逐步回归 |
| 传统 | `ridge` | 中心站窗口展平 → H 输出；alpha 仅用验证集选 |
| 神经 | `mlp` / `gru` / `lstm` / `tcn` / `resnet` / `tst` | tsai 1.0.1；**两档容量**：库默认 + 与主干同量级（≈21k） |
| 自身主干 | `patchtst_center_frozen` | 中心站单通道 PatchTST（冻结主干）＝ 我们论文里的 `degraded_patchtst` |
| 自身主干 | `patchtst_center_e2e` | 同上但不冻结（端到端） |

### 1.2 我们的模型（多站点：中心站 + 邻站）

| 臂 | 说明 |
|---|---|
| `st` | 冻结主干 + Top-5 稀疏门控 + 站点身份偏置 + 预测端空间残差（论文主模型） |
| `st_plus_frequency` | 在上面的冻结 ST 检查点之上加**频域残差适配器**（含等容量时域对照，一并报告） |
| `st_e2e`（参考） | 同结构但不冻结，用于说明"结构 vs 训练制度" |

## 2. 解释边界（必须写进论文，不得省略）

1. **信息集不同**：我们的模型额外使用邻站数据，而所有基线只用中心站。
   因此提升应归因于**新增信息（跨站信息）的价值**，**不得**表述为"我们的机制优于其他机制"。
2. 若论文想主张"机制更优"，必须在**同信息集**下与常规多变量模型比较——这属于**另一个独立实验**，
   需单独预注册；前一版已做过该实验，结论为负面（我们的结构平均落后同容量多变量 GRU 约 4–6%），
   该结论作为已知事实记录，不因本版重做而消失。
3. 本版**不删除**任何不利结果记录；重做只改变对比的问答形式，不改变任何已测得的事实。

## 3. 公平性规则（硬性）

| # | 规则 |
|---|---|
| R1 | **基线严格单站点**：输入仅中心站通道；不得喂入任何邻站通道（实现层需有测试断言） |
| R2 | **我们的模型多站点**：输入为中心站 + 该配置筛出的邻站（沿用无泄漏训练段筛站） |
| R3 | 数据、划分、种子、训练预算、评估划分与既有主实验完全一致 |
| R4 | 容量两档并列（库默认 / ≈21k 同量级），达不到 ±20% 的显式标 `matched_nearest` |
| R5 | 防泄漏：所有拟合只用训练段；气候均值只用训练段小时均值；`ridge` 的 alpha 只用验证集 |
| R6 | 主对手 = **逐配置最强单站点基线**（best-of-single-station），并标注获胜臂 |
| R7 | 指标：RMSE（主）/ MAE / SMAPE；逐种子配对；报告同向计数 |
| R8 | 异常统一规则：CUDA OOM → 登记 `infeasible_oom` 后继续；非有限损失 → lr/10 重试一次，仍发散登记 `nonfinite`；均不得静默丢弃 |
| R9 | 诚实条款：任何基线的有利结果照实写；不得为迎合结论调整协议 |
